## Phase Goal

**As a** 관리자(사용자 본인), **I want to** 배포 스크립트 한 번으로 회사 GCP 프로젝트에 띄운 서울 리전 Cloud Run 앱에 직원 계정으로 로그인해 비밀번호를 바꾸고 로그아웃할 수 있기를, **so that** 기능보다 먼저 "배포된다"가 증명된다.

(ROADMAP Phase 1 `**Goal:**` 줄의 세 요소 — 행위자·능력·결과 — 를 그대로 옮긴 것이다. Goal 줄 자체는 산문형이므로 정식 "As a / I want to / so that" 문장으로 바꾸려면 `/gsd-mvp-phase 1`을 실행한다.)

<objective>
