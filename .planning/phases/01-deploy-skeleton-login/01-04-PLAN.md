eslint/index.mjs:
```javascript

```
규칙 계약:
- plant8/require-action-client — Program.body[0]이 "use server" 디렉티브인 파일에서, `export const X = <expr>`의 expr 루트 식별자(CallExpression/MemberExpression 체인을 따라 내려간 가장 안쪽 callee 객체)가 옵션 `clients`(기본 ["authedActionClient"])에 없으면 report; `export function`/`export async function`/`export default`는 항상 report. 메시지 "use server export must be wrapped by an approved action client".
- plant8/repository-viewer-param — 파일 경로가 `/repositories/`를 포함할 때, exported FunctionDeclaration 및 `export const x = (…) => / function` 의 params[0]이 Identifier `viewer`가 아니면 report(타입 export·상수 export는 무시).
- plant8/money-boundary — 파일 경로가 `/domain/money/`를 포함하지 않을 때, BinaryExpression(+ - * / %)·AssignmentExpression(+= -= *= /=)·UpdateExpression(++ --)·UnaryExpression(-)의 피연산자 타입 문자열(`checker.typeToString(checker.getTypeAtLocation(tsNode))`)이 `\bMoney\b`에 매치하면 report. `parserServices.program` 없으면 규칙은 아무것도 하지 않고 `context.report` 대신 조용히 통과하지 않는다 — 설정 오류를 알리기 위해 파일당 1회 "money-boundary requires type information" report.
