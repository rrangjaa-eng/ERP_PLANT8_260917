  <decision>
행동 로그를 「Excel로 내보낸다」를 어떤 수단으로 구현할지 확정한다. **CLAUDE.md가 「새 의존성은 이유 한 줄 + 승인 후」를 규정하므로 이 결정은 사람이 해야 한다.**

**A. UTF-8 BOM을 붙인 CSV (권장, 신규 의존성 0)**
- Excel이 BOM이 있는 CSV를 UTF-8로 인식해 한글이 깨지지 않고 더블클릭으로 바로 열린다
- 구현: 문자열 조립 + `Response`로 내려보내기. 03-RESEARCH.md가 확인한 「이 페이즈는 새 런타임 의존성이 필요 없다」를 지킨다
- Pro: 의존성 0, 구현·테스트가 순수 함수 하나, 파일 크기가 작아 수만 행도 문제없다
- Con: 셀 서식·열 폭·여러 시트가 없다. 진짜 `.xlsx`가 아니라 확장자가 `.csv`다 — 사용자가 「Excel 파일」을 기대했는데 CSV를 받는다
- 쉼표·줄바꿈·따옴표가 든 값의 이스케이프를 직접 구현해야 한다(표준 CSV 규칙: 따옴표로 감싸고 내부 따옴표는 둘로)

**B. `.xlsx` 생성 패키지 추가 (예: `exceljs`)**
- 진짜 Excel 파일. 열 폭·서식·헤더 고정이 가능하다
- Pro: 사용자 기대와 정확히 일치하고 Phase 9의 손익 내보내기가 서식을 쓸 여지가 생긴다
- Con: 신규 런타임 의존성 하나(용량이 작지 않다) + 승인 절차 + Cloud Run 이미지 크기 증가. 03-RESEARCH.md의 「이 페이즈는 새 의존성 0」 판정이 깨진다

**함께 확정할 것: 반환 형태**
어느 쪽이든 `exportActionLog(viewer, filter)`가 `{ filename, contentType, body }`를 돌려주고 액션이 그것을 그대로 내려보낸다. 이 형태가 내보내기 레지스트리의 계약이 되어 Phase 6·7·9가 물려받는다.
