<objective>
**As a** 견적 줄을 입력하는 기획 PM, **I want to** 마우스를 잡지 않고 Tab·Enter·방향키·복사·붙여넣기·저장으로 스무 줄을 끝내고 싶다, **so that** 엑셀에서 하던 일을 이 시스템에서 더 느리게 하지 않는다.

§7-3 편집용 표를 **자체 구현한다**(D-45, 새 의존성 0). 04-08의 `column-fold.ts`를 상속하고 편집 기계장치만 더한다. **화면 배선은 04-12가 한다** — 이 플랜은 컴포넌트만 만든다.

Purpose: D-45의 근거 셋이 라이브러리를 기각했다 — ① 함정 10의 결론이 「계약을 컴포넌트로 만들어라」인데 라이브러리를 쓰면 계약이 설정·CSS 오버라이드라는 산문으로 돌아간다 ② §7-3이 요구하는 폰 칸 접기·서버가 아예 안 보내는 열·다른 셀을 편집해도 남는 고정 오류 셀·외화 2행 셀은 어느 라이브러리에도 없어 어차피 직접 만든다 ③ 열 집합이 서버 고정이라 동적 열 모델이 필요 없다. canvas 기반 그리드는 이 프로젝트가 UI를 DOM 실측으로 검증하므로 애초에 후보가 아니다.

**계약의 무게를 순수 모듈로 옮긴다.** 이 저장소에 React 렌더 테스트 러너가 없으므로(RTL 미설치, `environment: "node"`), 키 이동 계산·TSV 변환·붙여넣기 계획을 **`.ts` 순수 모듈로 뽑아** 진짜 단위 테스트를 붙인다. 컴포넌트에 남는 것은 DOM 배선뿐이고 그쪽은 04-12의 `test/e2e/quote-grid-keyboard.spec.ts`가 `CI=true`로 검증한다.
