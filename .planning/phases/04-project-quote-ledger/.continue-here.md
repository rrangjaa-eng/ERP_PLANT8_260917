## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| 한 세션에 여러 단위 | 게이트 리뷰 두 개를 끝낸 세션에서 /gsd-plan-phase까지 이어 감 | blocking | 세션 A의 hook 보강(게이트 리뷰 종료 = 세션 경계) + 위 제약 |
| 확인 없는 커밋 | 문서 커밋·완료 보고 전에 verification-before-completion 미호출 | blocking | 세션 A의 hook 보강(문서 커밋도 스킬 관문) |
| 기록된 결정 오판 | 리뷰 서브에이전트가 이미 확정된 U-2를 미결로 올림 | advisory | 사용자 확인 목록을 만들기 전에 CONTEXT·UI-SPEC·OPEN-ITEMS·HANDOFF를 먼저 검색 |
| 의존 전 실행 | 04-03을 wave 2라서 먼저 돌렸으나 기대 스키마가 없어 중간에 멈춤 | advisory | 플랜의 전제 조건을 실행 전에 확인 |
