## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| 한 세션에 여러 단위 | 게이트 리뷰 뒤 같은 세션에서 plan-phase까지 이어 감 | blocking | hook(세션 경계) + 위 제약 |
| 확인 없는 커밋 | 커밋·완료 보고 전 verification-before-completion 미호출 | blocking | hook(문서 커밋도 관문) |
| 말없이 판단 | 강제 푸시 회피 방식·PR 선생성·정지 감시 중단을 사용자에게 먼저 알리지 않음(세션 C) | blocking | 워크플로와 다르게 하거나 기록 밖 판단을 하면 그 자리에서 한 줄로 알린다 |
| 정지 감시 거짓 양성 | gsd_stall_watch가 출력 JSONL(프롬프트 포함)에서 완료 마커 문구를 잡음 | advisory | 프롬프트에 마커 문자열을 넣지 않거나 완료 알림에 의존하고 그 사실을 알린다 |
| 테스트 환경만 보는 검토 | 임시 저장소 테스트가 초록이어도 실제 저장소(표시 없는 마이그레이션)에서 스크립트가 죽음(세션 D) | blocking | 에이전트 diff를 실제 저장소에 대입해 재현 — 빈 입력·기본 상태 경로 확인 |
| 기록된 결정 오판 | 이미 확정된 결정을 미결로 올림 | advisory | 묻기 전에 CONTEXT·UI-SPEC·OPEN-ITEMS·HANDOFF 검색 |
