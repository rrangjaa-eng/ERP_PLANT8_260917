① **`ui/table/paging.ts`(순수, React 없음).** `splitPages(displayOrderIds, { pageSize, pinned })` — 표시 순서 id 배열을 쪽 크기로 자르되 `pinned`(id → 쪽 번호, 새 줄 고정)에 든 id는 그 쪽에 남긴다(그 쪽이 잠시 넘칠 수 있다). `pageOfRow` · `crossPageTarget(page, pageCount, direction, col)`(↓ 끝 → 다음 쪽 첫 줄 같은 열 / ↑ 처음 → 이전 쪽 마지막 줄 / 표 끝이면 null). 단위 테스트(`behavior` 앞 셋)를 먼저 쓴다.
