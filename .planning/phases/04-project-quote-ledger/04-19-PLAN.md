① **순수 대상 계산.** `paging.ts`의 `crossPageTarget`은 **줄 id**로 정한다(C-18): 표시 순서 id 배열에서 `fromId`의 앞·뒤 id를 찾고 `pageOfRow`로 그 쪽을 돌려준다 — 쪽 번호 산술로 「다음 쪽 첫 줄」을 고르지 않는다(새 줄 고정으로 쪽 경계가 움직여도 맞다). `nextEditableCell`(편집 가능 판정 함수를 받는다 — `cellEditability`가 `edit`인 셀만). `resolveFocus({ displayIds, pageIds, colKeys, focus: { rowId, colKey }, removedFallback })` — 기억한 id의 지금 쪽 인덱스(없으면 `{ page: pageOfRow(…) }` 또는 삭제 시 표시 순서상 다음·이전 줄)를 돌려주는 순수 함수(훅이 렌더마다 부른다 — 엔지 리뷰 C §1 P2). 단위 테스트(`behavior` 앞 셋과 포커스 유지·2쪽 Delete 대상 줄)를 먼저 쓴다.
