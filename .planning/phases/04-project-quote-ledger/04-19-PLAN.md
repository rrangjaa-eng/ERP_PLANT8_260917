(d) 편집 중이 아닐 때 `Ctrl+A` → `onSelectAll` + `preventDefault`. **`Ctrl+C`는 가로채지 않는다**(C-19 — 브라우저가 `copy` 이벤트를 쏘게 둔다; `<probe_fallback>`의 확인에서 쏘지 않으면 이 자리에서 `document.execCommand("copy")`). 편집 중이면 두 키 모두 입력의 기본 동작. **보존:** 04-28의 충돌 셀 전이(`conflictFocusTransition` — 충돌 셀에서 Enter → 두 3차 버튼, ←/→, Esc)와 그룹 A의 저장 중 잠금(`saveLocked` — 편집 진입 무반응, 이동·선택·복사는 된다)은 포커스를 id로 바꾼 뒤에도 같은 동작이어야 한다 — 두 기능의 기존 E2E가 초록으로 남는다. `Ctrl+A` 판정은 `isCtrlCombo(event, "a")`(04-08 `lib/shortcut.ts` — 04-28이 저장·새 줄·복제에 쓰는 같은 함수, 자동 반복·한글 조합 중 무시)다 — 이 훅에 Ctrl 판정을 따로 두지 않는다(엔지 리뷰 C §2 P2).

③ **`Table` — 네이티브 복사(C-19).** `TableColumn.copyText?: (row) => string`과 `TableProps.copyMeta?: (rows) => string`을 더한다. 선택 상태가 「전체(모든 쪽)」를 표현할 수 있게 하고(`onSelectAll`), 격자 요소의 `onCopy` 이벤트 처리기가 편집 중이 아니고 선택이 있을 때 선택 범위(전체면 모든 쪽 표시 순서의 모든 줄 · `copyText`가 있는 모든 열, 아니면 지금 쪽 범위)를 `toTsv`로 만들어 `event.clipboardData.setData("text/plain", tsv)` 하고, 화면이 넘긴 `copyMeta`가 있으면 그 결과(선택된 줄의 앱 형식 JSON 문자열)를 `application/x-plant8-quote-lines+json`으로 함께 싣고 `preventDefault`한다. 클립보드 권한 API를 쓰지 않으므로 격자 복사에는 실패 문구가 없다(C-19). 전체 선택은 보이는 쪽의 셀에 선택 모양(기존 범위 선택 모양 그대로)을 그린다.
