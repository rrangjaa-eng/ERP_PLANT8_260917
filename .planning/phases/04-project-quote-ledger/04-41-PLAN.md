**2026-09-23 CEO 리뷰 신설 플랜(04-16 분할 — T14 · 사용자 D9 · OV-6 · B-09).** 옛 04-16(17파일)의 Task 2(계약 쓰기 경로 제거 + 컬럼 삭제 마이그레이션)를 이 플랜으로 옮겼다. 04-16이 계약 금액의 **읽는 쪽**(파생 · 화면 입력 제거 · 불변식)을 끝냈고, 이 플랜이 **서버 쓰기 경로와 컬럼**을 지운다. 사용자 D9 「지금 삭제 + 가드」가 더한 것: DROP 전 RAISE 가드(값이 있으면 멈춤) · ARCHITECTURE §5 예외 기록 · 「Phase 4는 PR #38 한 번에 배포」 전제.
