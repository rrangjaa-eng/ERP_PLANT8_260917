- 클라이언트는 프로젝트명 아래가 아니라 앞 별도 열(사용자 추가 지시, D-87)

## Claude's Discretion

- D-78의 「정산 중 줄 추가·삭제·새 차수 잠금」은 「실행가만」 답에서 Claude가 해석한 것 — 계획 검토 때 사용자 확인
- 기간 미정 행의 합계 제외(D-90)는 사용자가 고른 표시 방식 옵션의 설명(합계 제외)을 따름
- 상태 코드 값 문자열·`settled` 재매핑·자동 정산 실행 방식·조정 줄 종류 모델링·계약 금액 컬럼 정리 방식은 계획이 정함
