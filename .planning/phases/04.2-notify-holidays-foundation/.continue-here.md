| Real gcloud/curl against GCP | Deploy tests use fakebin stubs | advisory | Never call real GCP from a session |
| Shared .planning/HANDOFF.json | Belongs to Phase 4 | advisory | Decimal phases hand off only via this file |
| Unlocked holiday writes | repositories/holidays.ts write fns default `tx = db` | advisory | 04.2-11/12 callers only inside `withHolidayCalendarLock` |
| Runtime-TZ-dependent time rendering | getHours() caused SSR(UTC)/browser(KST) mismatch in 04.2-07 | advisory | Intl.DateTimeFormat timeZone "Asia/Seoul" |
