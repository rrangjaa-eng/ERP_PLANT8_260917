## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Second executor spawn in one session | Session-boundary hook blocks a 2nd gsd-executor in the same session — even a continuation of the SAME plan (hit 2026-09-25 00:10Z on 04.2-09 run B) | advisory | Split points (review before commit, DOM audit) mean each continuation is a new session; do the review in session N, apply fixes + next task in session N+1 |
| Auto-approving a blocking-human gate | 04.2-15 Task 1 is `gate="blocking-human"` (nodemailer package identity) | advisory | Install only after the user's own answer on the card (「승인」) |
| Codex call while out of quota | Codex quota exhausted until 2026-09-29; user decision 「Opus」 | advisory | Don't run codex exec; Opus review; record "한도 풀리면 Codex 재확인 필요" |
| Plan needs code not on main | 04.2-03 requires Phase 4 04-32's `recordAction(viewer, entry, { tx })` on origin/main; it is only on PR #40 branch (domain/action-log/record.ts:97) | advisory | Before running 04.2-03/08/11/12, check `git show origin/main:domain/action-log/record.ts \| grep "tx?: DbOrTx"` |
| Real gcloud/curl against GCP | Deploy tests use fakebin stubs | advisory | Never call real GCP from a session |
| Shared .planning/HANDOFF.json | Belongs to Phase 4 | advisory | Decimal phases hand off only via this file |
| Unlocked holiday writes | repositories/holidays.ts write fns default `tx = db` | advisory | 04.2-11/12 callers only inside `withHolidayCalendarLock` |
| Runtime-TZ-dependent time rendering | getHours() caused SSR(UTC)/browser(KST) mismatch in 04.2-07 | advisory | Intl.DateTimeFormat timeZone "Asia/Seoul" |
