## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Parallel repo writers during /cso | /cso(gstack-cso helper) failed `start` twice with SNAPSHOT_RACE because a design-fix agent was committing in the same working tree | advisory | Run /cso only when no agent/hook writes to the repo; sequence fix agents and snapshot-based audits |
| gstack-cso submit schema | Coverage records need `evidence: []` and `exclusions: []` arrays even for not_assessed; missing them → INVALID_SCHEMA and an unpersisted run | advisory | Run `gstack-cso schema` and validate the JSON before `submit` |
| Local E2E on a 4-core container | Running Playwright alongside lint/vitest caused timeouts and a whole-suite run instead of the chosen files | advisory | Use CI (CI=true production build) as the E2E evidence; for local DOM audits use a scratch playwright config and `--list` first, alone |
| Push cancels in-flight CI | ci.yml has `cancel-in-progress: true`; pushing a docs commit mid-E2E wastes ~15 min of Actions minutes | advisory | Hold docs-only commits until the running integration-e2e finishes |
| Session-boundary hook false positive | Stale local branch pointer + pull → hook blocks executor | advisory | Start with `git fetch origin <b> && git checkout -B <b> origin/<b>` |
| Codex quota | Codex unavailable until 2026-09-29 | advisory | Opus substitute; record "9/29 뒤 Codex 재확인 필요" |
