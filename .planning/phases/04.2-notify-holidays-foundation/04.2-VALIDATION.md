## Sampling Rate

- **After every task commit:** Run `pnpm test:unit` (+ 해당 통합 테스트 파일)
- **After every plan wave:** Run `pnpm test` (+ 새 마이그레이션이 있으면 `pnpm lint:sql`)
- **Before `/gsd-verify-work`:** Full suite must be green with `CI=true`
- **Max feedback latency:** 60 seconds (unit)
