## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| STATE.md 건드리기 | 현재 페이즈 값은 Phase 4(다른 세션)가 쓴다. 04.4는 STATE.md와 루트 `.planning/HANDOFF.json`을 바꾸지 않는다 | blocking | 커밋 전 `git diff --stat origin/main -- .planning/STATE.md .planning/HANDOFF.json`이 비어 있어야 한다. 구조화 인계는 페이즈 폴더의 `HANDOFF.json` |
| 게이트 기록이 phase-04.log로 감 | 스킬 관문 훅은 이 세션에서 부른 GSD 페이즈 스킬 인자가 없으면 STATE.md(4)를 쓴다 | blocking | 게이트 리뷰 전에 `/gsd-progress 04.4` 등 04.4 인자를 가진 GSD 스킬을 먼저 부르고, 끝난 뒤 `git status`로 기록 파일 이름을 확인한다 |
| 고정 마이그레이션 번호 | 예약 범위·고정 번호 금지. `pnpm db:generate` 번호, 병합 직전 재생성(플랜 06) | blocking | 플랜 grep 0건 유지 |
| 영어 사용자 문구 | 답글·상태 줄·카드 모두 한국어 | blocking | 카드 필드까지 한국어로 |
| --reviews 모드 전제 | 04.4에는 REVIEWS.md가 없어 `/gsd-plan-phase --reviews`가 바로 끝난다. eng 지적은 리비전 루프(플래너 revision 모드)로 반영했다 | advisory | 검토 보고서 지적은 플래너 revision 프롬프트에 파일:줄로 넘긴다 |
| 관문 기록 파일 | `/gsd-progress 04.4`를 먼저 불러도 훅이 phase-04.log에 적었다 | blocking | 관문 뒤 `git diff .claude/gates/`로 확인, 잘못 들어가면 줄을 phase-04.4.log로 옮겨 커밋 |
