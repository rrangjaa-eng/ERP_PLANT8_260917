| Pattern | Description | Severity | Prevention Mechanism |

| 고정 마이그레이션 번호 | 예약 범위·고정 번호 금지. `pnpm db:generate` 번호, 병합 직전 재생성(플랜 06) | blocking | 플랜 grep 0건 유지 |
| 영어 사용자 문구 | 답글·상태 줄·카드 모두 한국어 | blocking | 카드 필드까지 한국어로 |

| 관문 기록 파일 | `/gsd-progress 04.4`를 먼저 불러도 훅이 phase-04.log에 적었다 | blocking | 관문 뒤 `git diff .claude/gates/`로 확인, 잘못 들어가면 줄을 phase-04.4.log로 옮겨 커밋 |
