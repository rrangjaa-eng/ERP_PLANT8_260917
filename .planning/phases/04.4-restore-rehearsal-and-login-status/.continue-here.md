## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| STATE.md 건드리기 | 현재 페이즈 값은 Phase 4(다른 세션, 브랜치 claude/gsd-progress-e1nzgu)가 쓴다. 04.4는 STATE.md와 루트 `.planning/HANDOFF.json`을 바꾸지 않는다 | blocking | 커밋 전 `git diff --stat origin/main -- .planning/STATE.md .planning/HANDOFF.json`이 비어 있어야 한다. 이 페이즈의 구조화 인계는 페이즈 폴더의 `HANDOFF.json`에 둔다 |
| 고정 마이그레이션 번호 | 예약 범위(0030~0034 등)나 고정 네 자리 번호를 쓰지 않는다. 브랜치는 `pnpm db:generate`가 준 번호, 병합 직전 origin/main 병합 → 자기 마이그레이션 삭제 → 재생성 → main 마지막+1 확인(플랜 06) | blocking | 플랜·ROADMAP·REQUIREMENTS grep 0건(마지막 확인 2026-09-24 02:25 KST) |
| 영어 사용자 문구 | 사용자에게 보이는 답글·상태 줄·결정 카드는 모두 한국어 | blocking | 카드 필드까지 한국어로 처음부터 쓴다 |
| 세션 경계 훅 오탐 | main 머지로 들어온 다른 스레드의 퀵 작업 SUMMARY(260924-hgx)에 훅이 "플랜 종료"로 반응했다. 04.4 플랜은 아직 실행되지 않았다 | advisory | 머지 뒤 훅 경고가 나오면 어느 SUMMARY 때문인지 확인한다 |
