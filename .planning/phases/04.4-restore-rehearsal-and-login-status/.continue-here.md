## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| STATE.md 건드리기 | 현재 페이즈 값은 Phase 4(다른 세션)가 쓴다. 04.4는 STATE.md와 루트 `.planning/HANDOFF.json`을 바꾸지 않는다 | blocking | 커밋 전 `git diff --stat origin/main -- .planning/STATE.md .planning/HANDOFF.json`이 비어 있어야 한다. 구조화 인계는 페이즈 폴더의 `HANDOFF.json` |
| 게이트 기록이 phase-04.log로 감 | 스킬 관문 훅은 이 세션에서 부른 GSD 페이즈 스킬 인자가 없으면 STATE.md(4)를 쓴다 | blocking | 게이트 리뷰 전에 `/gsd-progress 04.4` 등 04.4 인자를 가진 GSD 스킬을 먼저 부르고, 끝난 뒤 `git status`로 기록 파일 이름을 확인한다 |
| 고정 마이그레이션 번호 | 예약 범위·고정 번호 금지. `pnpm db:generate` 번호, 병합 직전 재생성(플랜 06) | blocking | 플랜 grep 0건 유지 |
| 영어 사용자 문구 | 답글·상태 줄·카드 모두 한국어 | blocking | 카드 필드까지 한국어로 |
| --reviews 모드 전제 | 04.4에는 REVIEWS.md가 없어 `/gsd-plan-phase --reviews`가 바로 끝난다. eng 지적은 리비전 루프(플래너 revision 모드)로 반영했다 | advisory | 검토 보고서 지적은 플래너 revision 프롬프트에 파일:줄로 넘긴다 |
| 관문 기록 파일 | `/gsd-progress 04.4`를 먼저 불러도 훅이 phase-04.log에 적었다 | blocking | 관문 뒤 `git diff .claude/gates/`로 확인, 잘못 들어가면 줄을 phase-04.4.log로 옮겨 커밋 |
| 세션 훅 미로드 | 저장소 없이 시작한 세션은 SessionStart·Skill 훅이 돌지 않아 gstack 미설치·게이트 기록 누락 | blocking | `CLAUDE_CODE_REMOTE=true bash scripts/install-gstack.sh`로 설치, 게이트 뒤 `git status`로 `.claude/gates/phase-04.4.log` 확인, 없으면 손으로 한 줄 |
| Codex 호출 | Codex 한도 2026-09-29 오전까지 막힘 | blocking | 교차 검토는 Opus 독립 검토, Fable은 최종 전체 검토 한 번만(사용자 결정 「Opus」). 기록에 "한도 풀리면 Codex 재확인 필요" |
| 플랜 여러 개 연속 실행 | 코디네이터 지시는 세션당 플랜 하나 → 커밋·푸시 → 「[완료 보고]」 → pause | blocking | 플랜 SUMMARY 커밋 뒤 바로 푸시·보고·pause |
| 추천안으로 사용자 결정 임시 진행 | 2026-09-26 코디네이터 공통 규칙 — 제품 범위·기본값·정책·새 의존성·되돌리기 어려운 설계는 PR에 「[사용자 결정 요청]」(무엇을·선택지·추천·근거 각 한 줄) | blocking | 결정이 필요하면 댓글 남기고 그 결정에 의존하지 않는 일만 한다 |
| 점 파일 인계 놓침 | `ls`는 `.continue-here.md`를 안 보여 준다 — 04.4-01 세션이 처음에 이 파일을 못 읽었다 | blocking | 시작할 때 `cat .planning/phases/04.4-*/.continue-here.md`로 직접 읽는다 |
| Skill 도구에 GSD·Superpowers 스킬이 없음 | 이 클라우드 세션에서는 `/gsd-*`·`test-driven-development` 등이 Skill 목록에 안 뜬다 | advisory | `.claude/commands/gsd-*.md`·`.claude/skills/*/SKILL.md`를 직접 읽고 따른다. 훅(pre-push lint·typecheck)도 안 돌므로 푸시 전 두 명령을 exit code로 직접 확인 |
