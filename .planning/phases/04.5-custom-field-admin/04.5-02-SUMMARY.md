# Phase 04.5 Plan 02: 선택형 선택지 편집기 · 버전 조건부 수정 모드 · 선택지 보관 파생 Summary

**선택형 화면 항목을 등록하고, `?editId=` 수정 폼에서 이름·필수·정렬·선택지를 `WHERE id AND version AND archived_at IS NULL` 한 문장 조건부 UPDATE로 고치며(보관 먼저 · 그다음 버전), 지운 선택지는 서버가 `(저장 options ∪ archived_options) − 제출 options`로 `archived_options`에 파생해 어떤 저장 경로로도 유실되지 않게 함**
