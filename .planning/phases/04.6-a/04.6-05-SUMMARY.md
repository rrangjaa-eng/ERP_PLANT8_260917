## 뒤 플랜에 넘기는 API

**`StaticTable`** (`ui/table/StaticTable.tsx`, 서버 컴포넌트 — 04.6-11·14·15·16·22가 인용)

```ts
type StaticTableColumn = { key: string; header: string; priority: ColumnPriority; align?: "left" | "right"; rowHeader?: boolean };
type StaticTableRow = { key: string; headerId?: string; cells: ReactNode[] };   // cells = 열 순서대로 미리 렌더한 칸
<StaticTable caption="…" columns={StaticTableColumn[]} rows={StaticTableRow[]} />
```

- `rowHeader: true`(한 열) → 그 칸이 `<th scope="row" id={row.headerId}>`, 접힌 줄 `<td colSpan headers={headerId}>`(rowHeader 열이 있을 때만).
- 접힌 줄: P2 값만, 값마다 `<span class="sr-only">{header} </span>` + 값, 「 · 」는 보이는 값 사이에만, 빈 값(null·undefined·false·"")은 빠짐, `aria-hidden` 없음. 가린 열은 호출부가 `columns`와 `cells` 양쪽에서 뺀다.
- 정렬 머리글·편집·붙여넣기·페이지·빈 상태는 없다(빈 목록은 호출부가 `ListEmpty`). `detail`은 04.6-15가 더한다.
- 클래스는 `Table.module.css`(`table headerCell cell prio-pN alignRight collapsedRow collapsedCell`). 04.6-07이 값만 바꾸면 된다.

**`RowAction` button 형** (`ui/row-actions/RowActions.tsx`, `"use client"` — 04.6-16 공휴일 삭제·되돌리기)

```ts
<RowAction onClick={(e) => …} pending? autoFocus? danger?                 children />
<RowAction onClick … disabled disabledReason="이유"                       children />  // disabled는 이유와 함께만(타입)
<RowAction href="/x" danger?                                              children />  // href 형에는 pending/disabled 없음(04.6-10이 LinkPending)
```

- 네이티브 `disabled` 없음, `aria-disabled="true"`(탭 순서 유지). 비활성·대기 중 클릭은 `rowActionClickHandler`가 `preventDefault`하고 `onClick`을 부르지 않는다.
- 대기 중: 라벨 뒤 `<span aria-hidden>…</span>` + `<span class="sr-only">처리 중</span>`(Button과 같은 글자).
- 이유 글자: 버튼 바로 뒤 `<span id>`(`aria-describedby`), `pending` 중에는 렌더 안 함. 이유가 있으면 버튼+이유를 `withReason` 래퍼 span 하나로 묶고 danger 여백은 래퍼에 붙는다.
- `RowActions`는 `danger` 항목을 어디에 적었든 DOM 맨 끝으로 옮긴다(`data-ui="row-actions"`).

**기타:** `Num` props `{ value: number | null; unit?: "krw"|"count"|"quantity"|"percent"; currency?; fx?: { currency; amount; rate } }` · `TableSkeleton` `{ columns: {key,label,align?}[]; withFooter? }`(`data-ui="table-skeleton"`) · `StatusTag` `{ status: StatusWord }`.
