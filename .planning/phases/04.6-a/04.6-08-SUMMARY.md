## Deviations from Plan

**1. [Rule 3 - Blocking] page-chrome 「전역 포커스 링」 테스트가 단독 실행에서 실패(기존 결함)**

- **Issue:** `/projects` EMPTY의 「프로젝트 등록」 링크는 거래처가 있어야 나온다(quick 261001-85g `canCreateProject`). 깨끗한 DB에서는 링크가 없어 `link.focus()`가 30초 뒤 시간 초과 — 베이스(4b2b9ec)에서도 같은 결함(다른 스펙이 먼저 거래처를 만든 순서에 기대던 테스트).
- **Fix:** 테스트 안에서 `createVendor(SYSTEM_VIEWER, …)`로 거래처를 먼저 만든다.
- **Files modified:** test/e2e/page-chrome.spec.ts · **Commit:** 6aa56e9

**2. [Rule 3 - Blocking] `app/globals.css` `line-height: inherit` → `var(--lh-body)`**
- **Issue:** 새 stylelint 규칙의 `line-height` 허용 목록이 `var(--lh-*)`만 받아 `inherit`를 거부.
- **Fix:** 컨트롤(button·input·select·textarea) 행간을 본문 값 `--lh-body`로 고정. 표 셀(`--lh-table` 1.5) 안 컨트롤은 부모 행간을 상속하던 것이 1.6이 된다 — 컨트롤 높이는 `.input`/`.btn` 명시 높이가 정해 영향 없을 것으로 보지만 합본 DOM 감사에서 확인.
- **Commit:** 6aa56e9

**3. [Rule 3 - Blocking] 현재 메뉴 밑줄: `box-shadow: inset … var(--bar-leaf)` → 투명 `border-bottom` 자리를 `--bar-leaf`로**
- **Issue:** stylelint가 box-shadow를 `--shadow-*`/`--inset-*`만 허용(`--inset-tab`은 `--accent` 색이라 딥그린 바 위에서 안 보임). tokens.css는 이 플랜 소유가 아님.
- **Fix:** `.navLink { border-bottom: var(--underline-w-hover) solid transparent }` + `[aria-current="page"] { border-bottom-color: var(--bar-leaf) }`. 링크가 바 높이를 채우도록 `align-self: stretch`. 시각 결과(바 바닥 2px 잎색 밑줄)는 SYSTEM §6-0 그대로. page-chrome의 `box-shadow contains inset` 단언은 border 단언으로 바꿈.
- **Commit:** 6aa56e9

**4. [Rule 3 - Blocking] TopBar 배지 `font-variant-numeric: tabular-nums` 제거**
- **Issue:** `font-variant-numeric`은 `ui/num`·`ui/input`·`app/print` 밖 금지인데 `ui/num`이 아직 없다. 배지는 1~2자리 건수라 정렬 영향은 미미.
- **Fix:** 선언 삭제 · 아래 넘김.
- **Commit:** 6aa56e9

**5. [계획 해석] 더보기 시트 `--dur-sheet` 모션 미적용** — key-decisions 참조. 시작 위치(`transform`)가 도중 측정을 어지럽혀 `mobile-shell` 두 테스트(터치 44 · 아래 끝 붙음)가 깨짐을 실제로 확인한 뒤 되돌림.
