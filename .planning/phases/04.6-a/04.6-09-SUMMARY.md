### Auto-fixed Issues

**1. [Rule 3 - Blocking, 계획 충돌] 일곱 폴더 `--audit` 「아무 줄도 출력하지 않는다」를 이 플랜만으로는 못 맞춘다**
- **Found during:** Task 1 acceptance
- **Issue:** `ApprovalRoute.tsx:59` · `HistoryList.tsx:245·249` · `NextTurn.tsx:44`의 `StatusTag kind=` (c) 항목. `StatusTag`의 `status` 낱말 prop은 같은 웨이브 04.6-05가 만들고(`kind`는 04.6-05가 사용 중단으로 남긴다) 이 트리에는 없다. 세 TSX는 이 플랜 `files_modified` 밖이다.
- **Fix:** CSS 항목 (a)(d)는 0으로 맞췄다. TSX 네 줄은 건드리지 않고 아래 「넘김」으로 보낸다(`status` 낱말은 05가 합쳐진 트리에서만 타입이 선다).
- **Files modified:** 없음

**2. [Rule 3 - Blocking] `font-variant-numeric: tabular-nums` 세 줄을 걷었다**
- **Found during:** Task 1 stylelint(표시 뗀 뒤)
- **Issue:** 새 규칙이 `font-variant-numeric`을 `ui/num` · `ui/input`에만 허용한다. `HistoryList .num` · `ApprovalRoute .at` · `NextTurn .amt`가 걸렸다. `Num`(`ui/num`)은 04.6-05가 만들며 이 트리에 없다. stylelint 설정은 이 플랜 소유가 아니다.
- **Fix:** 세 선언을 걷었다(이 트리에서 자리 맞춤 tabular가 잠시 빠진다 — 이 세 값은 E2E 단언이 없다). `Num`으로 감싸는 일은 아래 「넘김」.
- **Commit:** f10e0c2

**3. [Rule 1 - 계약 맞춤] `.errorCell` 전체 1px 링 → `--inset-error`(왼쪽 2px)**
- **Issue:** stylelint가 `box-shadow`를 `--shadow-*` · `--inset-*`만 허용한다. 기존 `inset 0 0 0 1px var(--danger)` 링에 해당하는 역할 토큰이 없다.
- **Fix:** 역할 토큰 `--inset-error`(오류 셀 좌측, 04.6-01)로 바꿨다. 모양이 링에서 왼쪽 막대로 바뀌지만 SYSTEM §7-3 오류 셀 언어와 같다. 오류 셀 단언 E2E 없음. 감사에서 오류 상태 대비 확인.
- **Commit:** bed29bf

**4. [Rule 2 - 층 겹침] 격자 모서리 `z-index: calc(var(--z-sticky) + 1)` → `--z-bar` + `.wrap { isolation: isolate }`**
- **Issue:** stylelint가 `z-index`를 `var(--z-*)` 한 값만 허용해 `calc(+1)`을 못 쓴다. 그냥 `--z-bar`로 올리면 상단 바(`--z-bar`)와 같은 층에서 다툰다.
- **Fix:** `.wrap`을 격자 안 층 가름(`isolation: isolate`)으로 만들고 모서리를 `--z-bar`로 — 기하는 그대로(`permissions-grid.spec.ts` sticky 실측 초록).
- **Commit:** bed29bf

**5. [오케스트레이터 기본값 · 계획 해석] 머리글 「편집 가능한 표」 신호 토큰**
- 편집 표 머리글색 역할 토큰은 04.6-12 소유(SYSTEM §7-3). 권한 격자는 새 토큰을 만들지 않고 `--surface-selected` + `--text-strong`으로 옮겼다(대비 높음). 04.6-12가 다른 이름을 정하면 이 두 선언만 이름을 바꾼다 — 사용자 확인 대기 사항 아님(값 동일 계열).
