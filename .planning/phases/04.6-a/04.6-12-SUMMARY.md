**1. [Rule 1 - 계획 가정 오류] 네 숫자 줄 · 계산 불가 N건 배지가 코드에 없다**

- **Fix:** 새 숫자·권한 노출 경로를 만들지 않았다(T-04.6-35 취지 — 조회·노출표 diff 0). `DetailScreen.numbers`는 비워 둔다. 네 숫자 `tabular-nums` · 배지 단언은 만들지 않았다.

**2. [Rule 3 - 구조] DetailScreen 루트가 page.tsx가 아니라 QuoteLedger에 있다**
- **Found during:** Task 1
- **Issue:** `actions.primary`(「일괄 저장」)는 클라이언트 상태(dirtyCount · 저장 요청)에 달려 서버 page.tsx가 만들 수 없다. 플랜 수용 기준 `grep -c DetailScreen page.tsx ≥ 1`과 `screen-frames` 래칫(page.tsx의 틀 import)이 page.tsx를 기대한다.
- **Fix:** page.tsx가 `import type { DetailScreenProps }`로 `frame = { title, meta } satisfies Pick<DetailScreenProps, "title" | "meta">`를 만들어 `QuoteLedger`에 넘기고, 차수 섹션(`RevisionSection`)은 서버가 `QuoteLedger`의 children으로 넘긴다. QuoteLedger가 `<DetailScreen>`을 그린다(PageHeader 직접 렌더 제거). screen-frames · mark-legacy 래칫 초록.
