## Table API (04.6-19이 합본에서 `notifications/inbox-list.tsx`에 쓴다)

`ui/table/Table.tsx`에 더한 두 가지(둘 다 선택 — 기존 호출부 동작 그대로):

```ts
groupHeader?: (row: Row) => ReactNode;   // 이전: string 반환. 이제 노드(예: 글자 + <span>초과 N건</span>)
groupHeaderScope?: "rowgroup";           // 주면 그룹 머리 셀이 <th scope="rowgroup" colSpan=…>, 없으면 기존 <td colSpan=…>
```

- `groupAside` 는 같은 머리 셀 안에 그대로 그려진다(th여도).
- `Table.module.css`에 `th.groupHeader { text-align: left; }` 한 줄 — `<th>` UA 기본이 가운데 정렬이라 필요.
- 속성 순서가 `scope` 먼저라 기존 단위 테스트의 `<td colSpan="1" class=…>` 정규식이 그대로 맞는다.
- 단위 테스트: `test/unit/ui/table-group-aside.test.ts` 4건 추가(th scope · 노드 머리글 · td는 scope 없음 · th 안 groupAside), RED 확인 후 GREEN, 7건 통과.
