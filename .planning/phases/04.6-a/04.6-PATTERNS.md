## Pattern Assignments

### `ui/side-panel/SidePanel.tsx` (component, event-driven)

**Analog:** `ui/confirm-dialog/ConfirmDialog.tsx` (네이티브 `<dialog>.showModal()` + 포커스 복귀). 패널 열림은 URL 파라미터가 결정하므로 `open`은 항상 true로 마운트되고, 닫기 = `router.replace(closeHref, {scroll:false})`.

**열기/닫기 + 포커스 복귀** (lines 97-140):
```tsx
useEffect(() => {
  const dialog = dialogRef.current;
  if (!dialog) return;
  if (open && !dialog.open) {
    previouslyFocusedRef.current = document.activeElement as HTMLElement | null;
    dialog.showModal();
    /* 첫 입력 focus */
  } else if (!open && dialog.open) dialog.close();
}, [open]);
function closeNow() { dialog.close(); closedByUsRef.current = true; finishClose(); }
function handleDialogClose() { if (closedByUsRef.current) { closedByUsRef.current = false; return; } finishClose(); }
function finishClose() { onClose(); const trigger = previouslyFocusedRef.current;
  if (trigger && document.contains(trigger)) trigger.focus(); else document.querySelector<HTMLElement>("h1")?.focus(); }
```
**JSX 골격** (lines 189-197): `<dialog ref className aria-labelledby={titleId} onCancel onKeyDown onClick={handleBackdropClick} onClose={handleDialogClose}>` + `useId()` 제목 id, 머리 `.hd` > `h2 id=titleId`.
**주의:** 트리거 요소는 서버 렌더로 마운트되기 전이므로 「등록」 링크가 포커스 복귀 대상 — `document.activeElement`가 아니라 닫을 때 `a[href*="new=1"]`/행 「수정」을 찾는 폴백 필요(연 요소 복귀 계약). `<dialog>` showModal은 뒤 `inert`를 브라우저가 처리(별도 `inert` 불필요할 수 있음, RESEARCH 확인). 모션/`::backdrop`은 `MoreSheet.module.css`·`ConfirmDialog.module.css`의 `--dur-sheet` 선례 복사. `app/**`에서 `<dialog>` 직접 금지 → 이 컴포넌트만.
**Ctrl+Enter:** `ConfirmDialog` `handleKeyDown`의 `isCtrlCombo` (`@/lib/shortcut`) 재사용.

### `stylelint.config.mjs` (config)
**Analog:** 자기 자신. 현 패턴: `declaration-property-value-allowed-list`(키 → `["/^var\\(--x\\)$/"]` 정규식 문자열 배열), `declaration-property-value-disallowed-list`(정규식 키 + 정규식 값), `function-disallowed-list`, `property-disallowed-list`. export는 `{ rules }` 객체 하나(overrides 없음) — 경로별 규칙(`app/**`는 `--text-(body|aux|tag)`만)은 stylelint `overrides` 사용(17.x 지원 확인, RESEARCH). 추가: `"font-size": ["/^var\\(--text-[\\w-]+\\)$/"]`, `"border-radius": ["/^(0|var\\(--radius-[\\w-]+\\))$/"]`, `"font-weight": ["/^var\\(--fw-/"]`, `unit-disallowed-list: ["px", {ignoreMediaFeatureNames:{px:["width","min-width","max-width"]}}]`, 미이관 파일은 중앙 목록(`ignoreFiles`)이 아니라 파일 첫 줄 이관 전 표시로 드러낸다(COMMON §3) — 설정이 표시 파일을 훑어 옛 D-20 규칙 override를 마지막에 두고(R3), 페이즈 끝 「표시 0」은 04.6-28이 단언한다. `package.json` lint 글롭: `stylelint "ui/**/*.module.css" "app/globals.css" "app/**/*.module.css"` — `docs/design/tokens.css`는 스캔 밖이라 원시 값 허용.
