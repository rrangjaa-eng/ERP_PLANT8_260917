## Spacing Scale (SC 6) — 값 = [UQ-1]

계약(어느 안이든): 여백·간격 속성(`margin*` `padding*` `gap` `row-gap` `column-gap` `inset` `top/right/bottom/left`)은 `var(--s-<n>)`, 그 척도를 참조하는 역할 간격 토큰(`--pad-page` `--cell-pad-x/-y` `--field-gap` 등), `0`, `auto`, 그리고 이것들로만 된 `calc()`만 쓴다. 척도 밖 값은 stylelint가 막는다. 역할 간격 토큰은 `tokens.css`에서 `var(--s-*)`로만 정의한다(단위 테스트가 확인).

| 토큰 | 권장안(UQ-1 A) 값 | 쓰는 곳 |
|---|---|---|
| `--s-1` | 4 | 라벨-입력 사이 · 태그 안쪽 |
| `--s-2` | 8 | 버튼 사이 · 그룹 줄 위아래 |
| `--s-3` | 12 | 합계 면 위아래 안쪽 · 합계 면 위 여백 |
| `--s-4` | 16 | 칸 사이 · 표 첫·끝 칸 좌우 · 패널 행동 줄 위아래 · 행동 링크 사이 |

예외(척도 밖 허용): `1px` 선 두께는 `--line-w` 토큰으로만 · 포커스 `--focus-w`/`--focus-offset` · `--underline-offset`(2) · 미디어 쿼리 폭 조건. UQ-1 A를 고르면 기준 CSS의 6·10·14·28과 폰 페이지 여백 14는 척도 값으로 맞춘다(6→4 · 10→12 · 14→16 · 28→32 · 폰 14→16).

## Typography (SC 7) — 크기 = [UQ-2], 굵기 = [UQ-3]

계약(어느 안이든): `font-size`는 역할 토큰만. **화면 CSS(`app/**`)는 `--text-body` `--text-aux` `--text-tag`만** 쓸 수 있고, 제목·부제 크기는 **화면 틀 컴포넌트(`ui/`)만** 쓴다(stylelint가 경로별로 막음). 한 화면의 본문 위계 = 제목·부제·본문 3단계, 보조 크기(라벨·머리글·오류 줄·태그)는 따로.

| 역할 | 권장안(UQ-2 A) | 굵기 | 행간 | 쓰는 곳 |
|---|---|---|---|---|
| `--text-title` 제목 | 22 (폰 22) | 700 · 자간 -0.02em | 1.3 | 화면 제목 1개 [L:overlay-a] |
| `--text-subtitle` 부제 | 18 | 700 | 1.4 | 옆 패널 제목 · 모달 제목 · 상세 섹션 제목 [L:_common 패널 머리] |
| `--text-body` 본문 | 14 (폰 15) | 400 | 표 1.5 · 산문 1.6 | 표 셀 · 입력 · 본문 (버튼 글자는 크기만 이것 — 굵기는 아래 목록) |
| `--text-aux` 보조 | 13 | 600 | 1.5 | 표 머리글 · 폼 라벨 · 행동 링크 · 메타 줄 · 오류 줄 [L:_common 13/600] |
| `--text-tag` 태그 | 11 | 600 | 1.4 | 상태 배지 · kbd · 행 번호 |
| `--text-kpi` | 32 | 700 | 1.3 | 손익 대시보드 KPI 타일만(기존 예외 그대로) |

- 굵기 토큰(권장안 UQ-3 A): `--fw-regular` 400 · `--fw-medium` 600 · `--fw-bold` 700 · `--fw-mark` 800(워드마크만). `font-weight`는 이 토큰만(stylelint).
- 버튼 글자: 크기 `--text-body` · 굵기 `--fw-medium`(권장안에서 600 — 기준 CSS `_common.css` 31·61행과 현재 `ui/button/Button.module.css`가 600이다. 400 아님, DF2).

- 숫자: 자간 0, `tabular-nums`는 숫자 컴포넌트만(아래).

## 공용 컴포넌트 계약

**숫자 `Num`** (SC 8) — `<Num value unit? currency? fx? />`. 형식은 `lib/format-number.ts`(SYSTEM §2-4) 하나로. CSS: `tabular-nums` · 자간 0 · 줄바꿈 없음 · 표 칸에서는 오른쪽 정렬(`Table`의 숫자 열이 `Num`만 받는다). 쉼표·단위·음수 기호 위치 고정. 외화 2행(`USD 4,400.00 @1,318.18`)도 `Num`의 `fx` 변형. `font-variant-numeric`은 `ui/num` 밖에서 stylelint로 금지(현재 20개 파일 44곳을 옮긴다).

**상태 배지 `StatusBadge`**(= `StatusTag` 개정, SC 9) — 호출부는 `status` 낱말만 넘기고 색은 `ui/status-tag/status-map.ts`의 **한 표**가 정한다(`kind` prop 삭제 → 타입이 막음). 표: `--status-danger` = 막힘·증빙 없음·반려 / `--status-warning` = 오늘·마감 임박·마감 중·정산 / `--status-accent` = 내 차례·결재 중·`{단계} 결재 중`·편집 중·진행·현재·내 결재 / `--status-success` = 승인·연결·저장됨·완료 / `--status-muted` = 대기·미착수·임시·미수주·취소·회수·첫 로그인 전·임시 비밀번호 사용 중. 표에 없는 낱말은 타입 오류. 모양: `variant="tag"`(테두리 1px currentColor · r4 · `--text-tag` 600) / `"text"`(표 상태 열, 색 글자만).

**빈 화면 `EmptyState`**(= `ListEmpty` 개정, SC 10) — 표 본문 자리에 한 줄 `무엇이 없다`(`--text-body` `--text-muted`) + **첫 행동 버튼 하나**(2차 버튼 모양, [L:_common `__emptyAction`]). 행동이 없는 화면(권한 없음 등)만 명시적으로 생략(기존 유니언 유지). 일러스트 없음. 목록 머리에 1차 「{대상} 등록」이 있는 화면에서 그 등록 행동을 빈 화면에도 둘지·머리 1차를 숨길지는 **DR5 답 대기**.

**불러오는 중 `TableSkeleton`**(SC 10) — 실제 `Table`의 머리글(진짜 열 이름)과 표 면 + `--surface-muted` 행 3개, 편집 표는 합계 줄 뼈대 포함. 애니메이션 없음, 300ms 지연 표시(§7-7 유지). 라우트 `loading.tsx`는 이것만 쓴다(`approvals/loading.module.css` 등 화면별 뼈대 CSS 삭제).

**행동 링크 `RowActions`**(「수정숨기기삭제」 붙음 버그 수정) — `<RowActions><RowAction href>수정</RowAction><RowAction onClick>숨기기</RowAction><RowAction danger …>삭제</RowAction></RowActions>`. 링크·버튼이 같은 모양: `--text-aux` 600 · `--text-link` · 밑줄 1px · 오프셋 `--underline-offset`, 사이 `--s-4`, `danger`는 맨 끝 · 앞 간격 `--s-8` · `--status-danger` 글자 [L:_common ②·③]. `white-space: nowrap`. 폰 누르는 영역 44. `DeleteToArchive`(기록된 예외)의 여는 링크도 `RowAction danger`로.
