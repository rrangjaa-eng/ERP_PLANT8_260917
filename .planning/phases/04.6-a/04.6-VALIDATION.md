## Sampling Rate

- **After every task commit:** Run quick run command(건드린 글롭·테스트만)
- **After every plan wave:** Run full suite command + `pnpm build` + 건드린 화면 E2E(한 번에 하나 — 공유 `erp_test`)
- **Before `/gsd-verify-work`:** ready PR 전체 CI 녹색 → 독립 DOM 감사(`CI=true`) → `/design-review` → `/qa` → `/cso`
- **Max feedback latency:** 60 seconds(태스크 단위)
