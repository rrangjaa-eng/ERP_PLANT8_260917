## Phase Goal

ROADMAP 원문 Goal: 「기획 PM이 견적 줄에서 지출결의를 한 화면에서 증빙 첨부까지 끝내 제출하면 결재자가 폰에서 승인·반려하고, 같은 결재 모듈로 연차도 승인된다」 — user story 형식이 아니다(MVP 모드, 계획은 이야기를 지어내지 않았다 — `/gsd mvp-phase 5` 권고).

<objective>

Purpose: 뒤 플랜(05-05~05-11)이 같은 낱말(B2) · 같은 표 행동 열(B4) · 같은 골라내기(B5) · 같은 업로드 표시(B6)를 쓴다. 문서가 먼저 서지 않으면 화면마다 색 · 낱말이 갈린다(「화면 하나만 예외 금지」).

Output: DECISIONS 일곱 항목 → SYSTEM 일곱 절 개정. 코드 변경 0 · DB 없음 — 그래서 05-01과 같은 웨이브에서 나란히 돈다.
</objective>
