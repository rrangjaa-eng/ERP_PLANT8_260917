## UA-6106 판정 (05 결재 중 첨부 규칙 — `domain/evidence/index.ts` `OWNER_RULES.expense`, main 54113761)

- ⒜ **결재 중 삭제 = 누구도 불가.** `drafterRemoves`(`expenseDrafterRemoves`)는 작성 중(번호 · 상태 없음) · 반려 · 회수(`EXPENSE_RETURNED_STATUSES`)에서만 참이고, `removeEvidence`는 기안자가 아니면 `notFound`, 기안자라도 `inReview`면 `EvidenceLockedError("결재 중 · 증빙 잠김")`.
- ⒝ **결재 중 추가 = 기안자가 아닌 `expenses.evidence_attach` 쓰기 권한자만.** `adderOf`의 `attacher`는 `!isDrafter && can(attachMenu, "write")`, `addOpen`은 `attacher && inReview(submitted · in_review)`. 기안자의 `drafterAdds`는 결재 중에 거짓.
- ⒞ **승인 뒤 = 기안자 추가(완료 프로젝트 아님) · 붙이기 권한자 추가(완료 프로젝트) · 삭제 대신 무효 처리.** `drafterAdds = … || (approved && !projectCompleted)`, `addOpen`의 `attacher && approved && projectCompleted`, 삭제는 `EVIDENCE_REMOVE_LOCKED_APPROVED`로 막히고 `voidEvidence`는 `expenses.evidence_void` 쓰기 + `approved`일 때만(사유 필수).
