> **기준 문서:** `docs/design/SYSTEM.md`(스킨 A, HEAD `1eee70b5`) · `docs/design/tokens.css`(같은 판). 「§」 번호는 SYSTEM.md 기준이다.
>
> 이 문서는 **새 시각 언어를 만들지 않는다.** 새 색·서체·radius·그림자·간격·토큰 0개. 시스템 수준 규칙이 필요한 곳은 전부

>
> **잠긴 입력(다시 묻지 않음):** CONTEXT 「이미 확정된 입력」 10개 · D-6101~D-6113. 특히 D-6110(결재 중 규칙이 05 파일을 포함한

- **여러 파일:** 한 번에 여러 개를 놓으면 **파일 하나당 서버 액션 하나**(1MB 본문 한도 — RESEARCH Pitfall 4)를 차례로 부르고, 파일마다 결과 행 하나. 업로드 중에는
  그 행 아래 2px 진행 바(§7-10), 끝나면 2행 결과로 바뀐다. 결과 행은 **다음 끌어 놓기 때 통째로 바뀐다**(누적 안 함).
- **결과 행 글자:** 1행 `--text-body`, 2행 이하 `--text-aux` 400. 숫자만 상태 색(등록=success, 이미 등록=muted, 이름 다름=warning, 카드 미등록=danger). 0인 조각은 쓰지 않는다
  (`짝 없음 0`을 쓰지 않음). 건수 조각(`카드 사용에 붙음 12` · `짝 없음 3` · `카드 미등록 1` · `등록 162`)은 3차 링크 — 누르면 S2 필터가 그 값으로 바뀐다
  (`?state=attached|unmatched|card-unknown|private&batch={id}`).
- **거절 행:** 오류 셀 모양(§7-3 — `--status-danger-weak` 면 + `--status-danger` 글자), Copywriting 「거절」 행 글자 그대로. 줄 오류는 5줄까지 + `외 n줄`. 파일 하나라도 거절되면
  **그 파일의 줄은 하나도 등록되지 않는다**(전부-아니면-전무, CONTEXT :83) — 다른 파일 결과와는 무관.
- **같은 승인번호 줄:** 형식 오류가 아니면 건너뛰고 `이미 등록 n`에 센다(CONTEXT Claude's Discretion 기본안).
- **사업자번호 서식:** 거래처 생성·되살림·이름 다름은 결과 행 줄로만 알린다(이름 다름은 고치지 않는다 — CONTEXT :81). 카드 서식은 거래처를 만들지 않는다.
- **카드 서식:** 대사 1·2단계(승인번호 → 결제일+합계+끝 4자리 단일 후보)는 등록과 함께 서버가 끝낸다. 붙은 줄은 결과의 `카드 사용에 붙음 n`. 2건 이상 후보는 자동으로 붙이지 않고
  `짝 없음`에 센다(사람이 S4에서 고름 — 3단계). 파일 금액이 카드 사용 금액과 다르면 **파일이 덮는다**(D-6111) — 결과 행에 따로 쓰지 않고 그 카드 사용의 이력에 전·후가 남는다.
- **현금영수증·계산서:** 같은 영역·같은 결과 행. 읽기 규칙이 없는 동안(D-6102 견본 대기)은 `모르는 서식` 거절 줄.
- **1024 미만:** 영역·결과 행을 렌더하지 않는다(편집 폭 P-7). 320에서 가로 넘침 0.

  전부). 팀장 대리 불가(CONTEXT :76) — 작성자가 아닌 팀장에게는 렌더하지 않고 서버도 404.

  바뀌는 행에 2행 `합계 a → b` · `카드 a → b` + 결과 줄 `고르면 카드 사용 합계 · 카드가 파일 값으로`(D-6111 — O-6104).

- **문서 안 붙은 증빙(읽기 행, `StaticTable`):** `{종류} · {거래처}` · 날짜 · 합계 · 행 끝 3차 `떼기`(조건은 S7). 증빙 금액 칸은 **입력이 아니라** 붙은 증빙들의 공급가 합(서버 계산) + 2행
  `등록 증빙 {1}건`(작성자는 금액을 다시 적지 않는다, D-6106). 06 S4 문서 증빙 상태(`없음`→`확인 전`/`확인됨`)는 서버 한 함수가 정한다(UA-6108, O-6101).
- **폰 375·320:** 하단 시트, 행 높이 ≥44, 검색 칸 40, 1차는 시트 아래 고정 행동 줄 전폭 44. 금액은 행 오른쪽 `nowrap`, 거래처는 두 줄까지 줄바꿈 — 320에서 가로 넘침 0.
