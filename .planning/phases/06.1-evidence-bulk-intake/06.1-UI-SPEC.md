> (지출결의 문서 화면 「증빙」 섹션 06 S4 · 카드 사용 폼 06 S9 · 구매 요청 목록 06 S11 · 지급 대상 필터 06 S1) 위에 얹힌다.
> main에 없는 것에 기대는 요소마다 **`UA-61xx`**(이 문서의 UI 가정)를 붙였다. `/gsd-plan-phase 06.1` 실행 첫 단계에서 아래

>
> **기준 문서:** `docs/design/SYSTEM.md`(스킨 A, HEAD `1eee70b5`) · `docs/design/tokens.css`(같은 판). 「§」 번호는 SYSTEM.md 기준이다.
>
> 이 문서는 **새 시각 언어를 만들지 않는다.** 새 색·서체·radius·그림자·간격·토큰 0개. 시스템 수준 규칙이 필요한 곳은 전부
> 「시스템 변경 제안」(SP-6101~SP-6106)으로 올렸고 화면 하나만의 예외는 0건이다. G-4 「고르기 목록」(SP-6106)은 새 시각 언어가 아니라
> SYSTEM.md:482 「바꾸기」에 이미 있는 골격을 공용 컴포넌트로 구현하는 것이다(사용자 답 Q-D1 A). 이 문서는 `SYSTEM.md`·`DECISIONS.md`·`tokens.css`를
> 고치지 않는다 — 제안은 계획의 첫 태스크가 `DECISIONS.md` → `SYSTEM.md` 순서로 옮긴다(CLAUDE.md §6).
>
> **잠긴 입력(다시 묻지 않음):** CONTEXT 「이미 확정된 입력」 10개 · D-6101~D-6117. 특히 D-6110(결재 중 규칙이 05 파일을 포함한

- **저장:** `공개 범위 저장 {N}`은 **전부-아니면-전무**(§7-3 「일괄 저장」). 결과는 합계 행 라벨 뒤 `공개 범위 저장 · 162줄 · 14:02`(토스트 없음). 실패면 오류 셀 + 합계 행 `오류 {n}칸 · 전부 거부`
  (DA-18 · SYSTEM.md:835). 잠긴 줄(붙음 · 확인 필요 · 카드 미등록 · 음수 · 보관됨)을 실은 요청은 서버가 다시 거부한다(E32).
  저장된 줄은 **다음 불러오기 전까지 자리에 남고** 상태 글자만 바뀐다(줄이 사라지며 표가 뛰지 않게 — 기본값).
- **행 행동(`RowActions`, P3):** `붙이기`(→ S4) · `대리 등록`(→ S8) — 짝 없는 카드 줄은 **붙일 수 있는 후보 ≥1이면 `붙이기`만, 완화 후보(막힌 후보 포함) 0이면 `대리 등록`만, 완화 후보가 있으나 전부 막혔으면 둘 다 없고 그 자리에 막힌 이유 한 줄**(Copywriting — 둘이 같이 서지 않는다, DB-9 · E5 · PA-ALLBLOCKED).
  끝에 떨어뜨린 `RowAction danger`(`--status-danger` 글자) 하나: `붙음` 줄 = `떼기`(→ S7 — 누가 · 언제는 S7 표, 승인 뒤 낱말은 UA-6109) / 안 붙은 줄 = `보관`(`evidence.intake`만 — DA-7).
  **`떼기`와 `보관`은 한 행에 같이 서지 않는다.** `확인 필요`·`카드 미등록` 줄의 `붙이기`는 `aria-disabled` + 이유(block — Copywriting). 비카드 줄의 붙일 수 있는 후보 문서가 0이면
  `붙이기`를 렌더하지 않는다. `보관됨` 보기의 행 행동은 3차 `되살리기` 하나.
- **보관 · 되살림(DA-7 · E41):** `보관`은 확인 모달 없이 곧바로 보관하고 표 위 결과 줄 `증빙 보관됨` + 3차 `되돌리기`(`--text-aux --text-muted`, `role="status"`, 포커스는 `되돌리기` — SYSTEM.md:1008
  04.2-09 꼴, 마지막 한 건만). 보관 줄은 다른 보기 · 작성자 풀 · 자동 대사 · `증빙 {N}`에 들지 않는다. 되살리기는 `보관됨` 보기의 3차 `되살리기`.
- **행 열기 · `Enter`(DA-17):** `Enter` = 공개 셀이면 편집, 그 밖의 셀이면 S3 패널을 연다(셀 `aria-haspopup="dialog"`). 행동 칸 안에서는 그 링크의 동작. 행(행동 칸 밖) 클릭도 S3 패널.
- **1024 미만:** 같은 표를 보기 전용(힌트 줄·select·1차 없음). 행 탭 → `RowSheet` 읽기 시트(폰 하단 시트) — `KvList` 줄만, 행동 없음.
- **키보드만으로:** `Tab`으로 필터 → 1차 → 표 → 페이지 줄. 표 안 방향키 이동, `Enter` 공개 셀 편집 / 그 밖 셀 패널, `Esc` 편집 취소, `Ctrl+S` 저장, `Ctrl+U` 파일, `Delete` 무반응. 모든 행동이 마우스 없이 된다.
- **DOM 감사(06.1-05 — design T9):** 1024 · 1280에서 `scrollWidth <= clientWidth` · 행 행동이 한 줄 · 거래처 한 줄 말줄임(UI Considerations backstop).

### G-4. 고르기 목록 `ui/pick-dialog/PickDialog` (S4 · S5 공용 — 사용자 답 Q-D1 A · C4 · DB-1)

S4 · S5는 `ConfirmDialog` 목록형을 쓰지 않는다(목록형은 1차가 없고 행이 곧 행동 — SYSTEM.md:1215). SYSTEM.md:482 「바꾸기」 골격을 공용 컴포넌트 하나로 올린 G-4를 쓴다.

- **골격:** PC 모달 480 · 폰 하단 시트(§7-8 · §7-17 셸 — 네이티브 `<dialog>` · 포커스 트랩 · `Esc` · 닫기 x `aria-label="닫기"`). 새 색 · 서체 · radius · 간격 0.
  슬롯 = 제목(`--text-subtitle` = 실제 동작) · 부제(`--text-aux --text-muted`, 대상 한 줄 + `후보 {n}`) · 검색 한 칸(`Input` + 검색 아이콘, 폰 40) · 행 목록(1행 `--text-body` + 오른쪽 `Num` ·
  2행 `--text-aux --text-muted`) · 막힌 행(`aria-disabled="true"` + 2행 이유, 목록 맨 뒤) · 결과 줄 0~1(행동 줄 위) · 막힘 자리(행동 줄 왼쪽 — §7-17) · 2차 `취소 Esc` · 1차 + kbd `Enter`.
  `selection: "one" | "many"`는 호출 화면이 문서 종류로 정한다 — 사용자가 고르지 않는다.
- **열림(DB-4 · DB-5):** **첫 포커스 = 검색 칸**(SYSTEM.md:482 · :1006). 점수 1위 행은 **미리 고른 상태**다 — 단 **1위가 결재 중 문서이면 미리 고르지 않는다**(1차 `aria-disabled` info `고른 후보 없음` —
  `Enter` 한 번에 결재 끝까지 못 떼는 붙임이 생기지 않게). 카드 사용 값 바뀜(`합계 a → b`)은 기록이 남아 미리 고른다. 검색 칸에서 `Enter` = 1차라 대개 `Enter` 한 번으로 끝난다.
- **하나(`one`) = combobox(DB-4 · DB-18):** 검색 칸 `role="combobox"` + `aria-controls` → `role="listbox"`, `aria-activedescendant` = 고른 행, `↑↓`가 고른 행을 옮긴다. 고른 행 = 현재 행 표시
  (700 + 왼쪽 2px `--accent`, SYSTEM.md:482) — ●○ 라디오 글리프 없음.
- **여럿(`many`) = 체크박스(DB-2 · DB-18 · E45):** `role="listbox" aria-multiselectable="true"`, 행 `role="option" aria-selected`, 2행은 `aria-describedby`. 체크박스는 §7-13과 같은 네이티브 체크박스(새 크기 없음),
  누르는 영역은 행 전체(≥44). 키: `↓`/`Tab` 검색 칸 → 목록 · 목록은 탭 정지 하나에 로빙 `↑↓` · `Space` 체크 토글 · `Enter`(검색 칸이든 목록이든) 1차 · `Esc` 닫기.
  고른 행은 검색어가 바뀌어도 목록 맨 위에 체크된 채 남고 검색 결과는 그 아래에 붙는다(`LIMIT 20` 밖의 후보도 검색으로 더한다). 결과 줄 `고른 {n}건`(합계는 쓰지 않는다 — 클라이언트 더하기 금지).
  상한 20(서버 상수 — E34 `LIMIT 20`과 같음): 21번째는 체크되지 않고 막힘 자리에 `20건 상한 · 나눠 붙이기`. **전부-아니면-전무** — 한 건이라도 서버가 거부하면 아무것도 붙지 않는다.
- **검색 · 불러오기(DB-14):** 검색은 서버 액션을 다시 부른다(E34 — 점수 SQL `CASE` 합 `ORDER BY … LIMIT 20`). 검색 중에는 목록 자리를 바꾸지 않고 300ms 뒤 2px 진행 바만(§7-7).
  불러오기 실패 = 목록 자리 `--status-danger` 한 줄 `후보를 불러오지 못했습니다 · 다시 시도` + 2차 `다시 시도`, 1차 `aria-disabled`가 이 줄을 `aria-describedby`로 가리킨다.
  검색 0 = `{검색어}에 맞는 후보가 없습니다` · 3차 `검색 지우기`.
- **제출 · 거부:** 제출 중 1차 `…`, 행 · 검색 `aria-disabled`, `Esc` 무시(§7-17 그대로). 서버 거부 문자열은 막힘 자리에 붙고 다이얼로그는 닫히지 않는다(§7-17 ERROR) — 경합이면 후보를 다시
  불러오고, 아직 붙일 수 있는 선택은 체크된 채 남긴다.
- **성공:** 바로 닫힌다(토스트 없음). 결과는 호출 화면이 제자리에 보인다. 포커스는 트리거, 트리거가 사라졌으면 호출 화면이 정한 새 자리(S4 = 바뀐 행 · S5 = 첫 새 읽기 행).
- **폰(<700, DB-6):** 하단 시트, 행 ≥44, 검색 칸 40. 행동 줄 = 2차 `취소` 왼쪽 + 1차 오른쪽(**1차가 두 배 폭**, 44 — SYSTEM.md:1004 · :1215). 막힘 이유 · 결과 줄은 버튼 윗줄. DOM · Tab 순서 = 시각 순서.
- **다섯 상태:** LOADING = 검색 중 2px 진행 바 · 제출 중 `…` / EMPTY = 붙일 수 있는 후보 0이면 호출 화면이 트리거를 그리지 않는다(막힌 행만 있어도) · 검색 0은 위 한 줄 /
  ERROR = 불러오기 실패 줄 · 서버 거부 막힘 자리 / SUCCESS = 닫힘 + 호출 화면 제자리 결과 / PARTIAL = 해당 없음(전부-아니면-전무).
- **만드는 순서(C4 — 06.1-03):** `DECISIONS.md` 기록 → SYSTEM.md §7-17 한 단락(「고르기 목록」, SP-6106) → `/dev/components` 쇼케이스(하나 · 여럿 · 막힌 행 · 불러오기 오류) → 단위 테스트
  → 화면(06.1-06 S4 · 06.1-08 S5). 06 S10 `link-picker`가 먼저 main에 들어오면 E36 재검사 때 06.1-06이 그것을 G-4로 옮긴다(같은 모양 세 벌 금지).

- **행:** 1행 `{문서 번호}  {종류} · {작성자} · {날짜 또는 결재 상태}` + 우측 합계. 값이 바뀌는 후보만 2행(`합계 a → b` · `카드 a → b`, D-6111). 값이 바뀌는 행을 고르면 결과 줄
  `고르면 카드 사용 합계 · 카드가 파일 값으로`, 결재 중 문서를 고르면 결과 줄 `결재 중 문서 · 결재 끝까지 떼기 없음`.

- **경합:** 다른 사람이 먼저 붙였으면 막힘 자리 `다른 사람이 먼저 붙임 · {문서 번호}` + 후보를 다시 불러온다.
- **후보 0:** 붙일 수 있는 후보(막힌 행 제외)가 0이면 트리거(`붙이기`)를 렌더하지 않는다 — 빈 모달을 열지 않는다. 짝 없는 카드 줄이면 완화 후보 0일 때만 그 자리에 `대리 등록`, 완화 후보가 전부 막혔으면 막힌 이유 한 줄(S2 행 행동 · DB-9 · PA-ALLBLOCKED). 검색 결과 0은 G-4 EMPTY.
- **폰:** G-4 폰 시트(행 높이 ≥44, 행동 줄 2차 `취소` + 1차 두 배 폭 44). S4는 S2 행 행동에서만 열리므로 실사용은 PC지만 시트 모양을 같이 쓴다.
