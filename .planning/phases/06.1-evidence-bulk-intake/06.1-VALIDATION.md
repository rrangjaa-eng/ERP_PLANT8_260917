## Sampling Rate

- **After every task commit:** 바뀐 파일의 단위 테스트 + `pnpm lint && pnpm typecheck` (마이그레이션 태스크는 `pnpm lint:sql`, 두 번째 `pnpm db:generate`가 `No schema changes`)
- **After every plan wave:** 그 웨이브의 통합 파일 + `test/integration/leak-scan.test.ts` + 건드린 화면 E2E(`CI=true`) + 고친 05 · 06 모듈을 import하는 기존 테스트(플랜 ⓪ P-TESTS — E31) — DB · 포트를 쓰는 것은 전부 같은 flock 안(E4)
- **Before `/gsd-verify-work`:** ready PR의 CI 전체(build · 단위 · 통합 · E2E) 초록
- **Max feedback latency:** 단위 루프 기준 수 초 — Wave 0 뒤 실측
