## Deviations from Plan

### Auto-fixed / 추가 (오케스트레이터 지시 A · B · R-3)

**1. [지시 A] `permission_change`를 끌 수 없는 종류로** — `domain/action-log/record.ts`. 단위 1. 결과로 `action_log.optional_types` 선택지에서 `permission_change`가 빠진다(아래 열린 결정 2).

**2. [지시 B] 상태 전환 · 원장의 업무 범위 갈래 = 참여 뺀 보임** — `teamScopeForProject`가 행 범위 `limited`일 때만 `findProjectInScope(… { excludeMembership: true })`로 다시 보고, 참여로만 보이면 「덮는 팀 없음」으로 좁힌다(`all`은 조회 없음). 사람의 전환(`changeProjectStatus` manual) · `statusDestinations`(주입 사실이 없을 때) · `actorCoversProjectTeam`(상세 화면 기간 권리) · `saveProjectLedger` 기간 사실이 같은 판정을 쓴다 — 화면이 서버가 거부할 갈 곳 · 기간 칸을 그리지 않는다. 결재 경로(`trigger: "approval"`)는 결속 권한이 경계라 그대로. `statusDestinations` 인자 타입에 `id`가 필수가 되어 단위 테스트 `projectOf`에 고정 id 한 줄을 더했다.

**3. [지시 R-3 · CSO-4] `previewExpenseRoute` 판정** — 기안자 → `can(expenses, write)`(ForbiddenError) → 프로젝트 행 없음이면 팀 비용 문서가 아닌 한 `ExpenseNotFoundError`. `isTeamCostRow`는 `index.ts` 전용 함수라(그 파일이 `route-doc.ts`를 import — 순환) 같은 조건을 인라인했다. 통합 1(쓰기 키를 잃은 기안자 → 미리보기 · 제출 둘 다 ForbiddenError). 프로젝트 행 없음 갈래는 FK로 만들 수 없어 테스트하지 않았다.

**4. [Rule 2] 페이지가 `ForbiddenError`도 문서 정보 없는 미리보기로 떨어진다** — 계획은 `ExpenseNotFoundError`만 적었지만 3의 판정이 생겨 폼 갈래에서 던지면 화면 전체가 오류가 된다(정상 길에서는 폼 갈래 = 쓰기 권한 있음이라 닿지 않는다).

**5. [계획과 다름] behavior 「남의 작성 중 문서를 볼 수 있는 사람 → 이름 없는 미리보기」는 화면으로 닿지 않는다** — `canSeeExpense`는 번호 없는 작성 중 문서를 기안자에게만 보인다(`domain/expenses/access.ts` `canSeeExpense`), 다시 제출 폼도 기안자 몫이다. 그래서 E2E는 「다른 사람이 그 주소를 열면 404 · 결재선 · 팀장 이름 없음」으로 썼고, 「기안자가 아니면 문서 팀을 풀지 않는다」는 06.2-02 통합(`approvals-route-project-team` 「남의 문서 · 없는 id는 없는 문서」)이 잰다. 페이지의 `ExpenseNotFoundError` 대체 갈래는 계획대로 남겼다(방어).

**6. [사용자 결정 반영] A-9 「목록만 줄임」(2026-10-09, 06.2-02 SUMMARY)** — 계획 behavior의 「목록 상태 열 `행사 담당 팀장 결재 중`」 대신 E2E는 목록 `팀장 결재 중`(그리고 `행사 담당 팀장 결재 중` 아님)을 단언한다. 결재함 처리함 상태 열은 단계 이름을 싣지 않는다(`결재 중`) — 행 두 줄만 잰다. 결재선 `list` · 결재 시트 · 작성 중 한 줄은 `{이름} 행사 담당 팀장` 그대로.

**7. [감사자용] P2 셀의 숨은 사본** — `StaticTable` 접힌 줄이 같은 셀 노드를 그려 PC DOM에 같은 접근 이름 `{계급} 보는 범위` select가 둘(하나는 `display: none` 행 안 — 접근성 트리 밖)이다. E2E는 `.filter({ visible: true })`. `ui/table` 변경은 범위 밖.

**8. 보관된 계급 select `disabled`** — 코드는 넣었지만 계급 목록이 보관 계급을 싣지 않아(`listRoles` 기본) 화면으로 닿지 않는다. E2E 없음(업무 범위 칸과 같은 상태).
