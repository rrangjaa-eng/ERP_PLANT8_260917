## Pattern Assignments

### Migration (`db/migrations/00NN_*.sql`)
Analogs: `0013_role_work_scope.sql`, `0021_holidays_archive.sql`, `0029_evidence_tax_rule_seed_sync.sql`.
Header = Korean rationale comment + lock timeout pair + `--> statement-breakpoint` between statements. Inline CHECK in ADD COLUMN (squawk rejects separate ADD CONSTRAINT CHECK; NOT VALID+VALIDATE is a two-migration pair, see 0025/0026, 0027/0028).
```sql
SET LOCAL lock_timeout = '1s';
SET LOCAL statement_timeout = '5s';
--> statement-breakpoint
ALTER TABLE "roles" ADD COLUMN "work_scope" text DEFAULT 'team' NOT NULL CONSTRAINT "roles_work_scope_check" CHECK ("work_scope" IN ('team','company'));
--> statement-breakpoint
UPDATE "roles" SET "work_scope" = 'company' WHERE "id" IN ('role-division-head','role-ceo','role-sysadmin');
```
06.2 backfill (D-6203): add `view_scope` default 'team' + CHECK IN ('company','org_unit','team','own'); then `UPDATE roles SET view_scope='company' WHERE work_scope='company'` (covers screen-made roles), then seed `role-division-head`->`org_unit` (narrows from company), `role-ceo`/`role-sysadmin` stay company. Keep SEED_ROLES in sync ("값은 마이그레이션의 UPDATE와 같다", roles.ts:29).
Partial unique for soft-archive (0021):
```sql
CREATE UNIQUE INDEX "holidays_date_active_key" ON "holidays" USING btree ("date") WHERE "holidays"."archived_at" is null;
```
Use same shape for `project_members_active_key` on (project_id, user_id). Idempotent UPDATEs (0029) are the model for any value rewrite; migration files carry a `-- rollback-floor:` first line when a rollback is unsafe (0021:1). New numbering: next free is 0031; per CONTEXT regenerate with `pnpm db:generate` after merging origin/main (06.1 collision).

## Shared Patterns

- **Layers:** app -> domain -> repositories -> db; domain never imports `@/db` (scope-for.ts L5-7, eslint boundaries). Descriptor in domain, SQL in repositories.
- **Viewer-first signatures:** every repo/domain fn is `(viewer: Viewer, ...)`, optional trailing `tx: DbOrTx = db`.
- **Errors:** user-facing rejections `extends UserFacingError` (`@/lib/actions/user-facing-error`), shown as serverError; 404 for out-of-scope detail (D-6206).
- **Action log:** write via `recordAction` in the same tx for always-on types (`domain/action-log/record.ts`).
- **Migrations:** hand-edited SQL after `pnpm db:generate`; lock timeout pair; squawk-safe inline CHECK; backfill UPDATE in same file (0013 precedent). Risky path: db/schema, db/migrations, domain/permissions go in a separate user-merged PR.
- **Comments:** Korean, cite decision id (D-62xx) and phase task, as in existing files.
