
### `domain/leave/index.ts` 제출 / `resubmit.ts` (service, tx CRUD)

**LeaveValidationError** (`index.ts:61-65`): `throw new LeaveValidationError([{ field: "startDate", message }])` — `LeaveFieldError` 타입은 `days.ts`에서 import 중(`index.ts:49`).

**제출 호출 자리** (`index.ts:316-329`): 권한 → `countLeaveQuarters` → (여기 앞에 `loadLeaveHolidays`, tx 밖) → `prepareSubmission` → `withTransaction(async (tx) => {` 첫 줄에 `lockLeaveDrafter` → 조회 → `findLeaveOverlap` → throw → `insertLeaveRequest(...)`.
```ts
await assertLeaveWrite(viewer);
const days = countLeaveQuarters(input, leaveYearRange(today));   // 3번째 인자 holidays 추가
if (!days.ok) throw new LeaveValidationError(days.errors);
```
**다시 신청** (`resubmit.ts:24-41`): 같은 첫 3줄 + `withTransaction` 안 순서 = `lockLeaveDrafter(leave.drafterId)` → `resubmitDocument(...)` → 겹침(`excludeId: input.leaveId`) → `updateLeaveRequestFields`. 주석 `전이 판정이 먼저`(:37) 유지.
**함정:** 겹침 조회는 반드시 콜백의 `tx`로(전역 `db` 금지 — 풀 5 교착). `withTransaction`은 `SET LOCAL lock_timeout='5s'` 후 같은 tx를 넘김(`lib/db-transaction.ts:44-49`).

## Shared Patterns

- **tx 인자 규약:** repository 쓰기·잠금·겹침 조회는 `tx: DbOrTx`(`@/db/client`), 읽기 전용 단독 호출은 `(tx ?? db)`. `viewer` 첫 인자 + `void viewer;`.
- **오류 전달:** `LeaveValidationError(fieldErrors)` → 액션 `leaveRejected`(`actions.ts:27-29`) → 폼 `fieldErrors`(`leave-form.tsx:181`). 새 오류 타입 금지.
- **문구:** 명사형 `원인 · 다음 행동`(`splitReason`이 마지막 ` · `에서 분리).
- **순서:** 권한 → 칸 검증 → (휴일 로드는 tx 밖) → 결재선 준비 → tx[잠금 → 겹침 → 저장].
- **누수·등록:** 새 `*Action` 없음 → `action-registry-completeness`·`leak-scan` 영향 없음.
