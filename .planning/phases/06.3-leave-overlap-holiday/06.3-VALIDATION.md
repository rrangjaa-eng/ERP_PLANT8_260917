## Sampling Rate

- **After every task commit:** 해당 단위 파일 + `pnpm lint && pnpm typecheck`

- **Before `/gsd-verify-work`:** ready PR CI 전체 초록(`CI=true`)
- **Max feedback latency:** 120 seconds
