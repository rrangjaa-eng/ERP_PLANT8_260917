## Sampling Rate

- **After every task commit:** Quick run command + 그 태스크가 만든 통합 파일 하나
- **After every plan wave:** 위 통합 회귀 묶음 + 건드린 E2E(`CI=true pnpm playwright test test/e2e/people.spec.ts test/e2e/archive.spec.ts`)
- **Before `/gsd-verify-work`:** CI 전체 초록
- **Max feedback latency:** 240 seconds
