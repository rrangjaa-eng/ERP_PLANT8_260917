## 플래그된 가정

- **AQ-17(아침 확인 필요):** 시험 DB 사용자 `erp`는 컨테이너 superuser라 `SET LOCAL session_replication_role = replica`가 된다(CI 서비스 컨테이너도 같은 이미지 · 같은 사용자 — 실행 첫 단계에서 CI 워크플로의 postgres 서비스 정의를 읽어 확인하고, 아니면 멈추고 PR 본문에 적는다 — `.github/workflows/` 수정 금지). Phase 8 데모 정리는 action_log 행을 지우지 않는다.
- 거부 SQLSTATE는 `P0001`(plpgsql `RAISE EXCEPTION` 기본) + 메시지 고정 문자열 — 시험은 코드와 메시지 둘 다 본다.
- 트리거 생성은 `action_log`에 SHARE ROW EXCLUSIVE 잠금을 짧게 잡는다(쓰기가 잠깐 기다림). 배포 때 마이그레이션 단계에서 한 번 — 잠금 대기 상한은 기존 migrate-runner의 `lock_timeout` 설정을 그대로 쓴다(Grep으로 확인, 없으면 마이그레이션 머리에 `SET lock_timeout = '5s'` 한 줄).
