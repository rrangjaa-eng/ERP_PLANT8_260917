## Sampling Rate

- **After every task commit:** `pnpm lint && pnpm typecheck` + 바뀐 파일 관련 단위/통합 1~2개
- **After every plan wave:** 그 웨이브가 건드린 화면 E2E 스펙 (`CI=true pnpm test:e2e <스펙>`)
- **Before `/gsd-verify-work`:** PR ready 뒤 CI의 build · 전체 단위 · 통합 · E2E 초록 (로컬 반복 금지)
- **Screen gate:** 싼 게이트(lint · typecheck · build) → 독립 DOM 감사(`CI=true`, 실행자 아닌 별도 에이전트) → 수정 → 전체 게이트 한 번(CI) → 묶음마다 `/design-review` → `/qa`. 스크린샷 육안 판정 금지
- **Max feedback latency:** 미정 (리서치에 수치 없음)

### 화면 표면 DOM 실측 계약 (UI-SPEC W1~W20)

폭 **1280 · 1024 · 375 (+ 열 접기 경계 700)**, Codex 디자인 검토 폭 375 · 320 · 768 · 1280. 1280은 레일(#298) 있는 상태로 잰다. `CI=true` 프로덕션 빌드의 DOM 실측만(스크린샷 육안 금지). 권한 실측은 그 권한을 가진 계급으로 낮춰서(경영관리 · 기획 PM · intake-only 직원 각각). 감사 에이전트의 판정 기준이며, 자동 명령은 위 E2E 스펙 또는 감사 에이전트 실행이다(표면별 전용 명령은 리서치에 없다).
