# Phase 07.2 Plan 18: 희망 지급일 변경 요청(X4 · S16) Summary

승인된 지출결의의 희망 지급일 변경을 「기안자 요청 → 경영관리 승인(지급 예정일을 같은 트랜잭션에서 씀) · 거절(메모) · 60초 되돌리기」로 만들고, 이력 표 · 지급 대상 줄 · tick 알림 2종(요청 도착 · 결과)을 붙였다. 마이그레이션 0(07.2-01 표 그대로).

## 상태 전이

| 지금 | 행동(누가) | 다음 | 지급 예정일 | 로그 |
|---|---|---|---|---|
| — | 요청(기안자 본인 · 최종 승인 · 미종결 · 미지급 · 이체 파일 밖 · 대기 없음) | pending | 불변 | document_submit |
| pending | 철회(요청자) | withdrawn(이력 `회수`) | 불변 | document_withdraw |
| pending | 승인(expenses.payments 쓰기 · 지출결의 version) | approved | = 새 희망일(set_by = 처리자) | document_approve + payment_schedule_change |
| pending | 거절(같은 권한 · 메모 1~500) | rejected | 불변 | document_reject |
| approved | 되돌리기(같은 처리자 · 60초 · 승인 결과 version · 대기 요청 없음) | pending(decided_* 비움) | = 승인 전 값(null 포함) | document_update(상태 승인→대기) + payment_schedule_change |

모든 쓰기: 지출결의 행 잠금 → 잠금 뒤 재판정(지급 기록 · 이체 파일 → `지급 진행 중 · 변경 요청 불가`, 종결 · 처리됨 → `이미 처리됨 · 새로 고침`, version → `다른 사람이 HH:mm에 바꿈 · 새로 고침`) → 요청 행 조건부 갱신.

## 플래너 가정 다섯(사용자 확인 요청)
1. **이체 파일 확정** = `scheduled_payment_set_at ?? 최종 승인 시각` 뒤 `excel_export`/`bank_transfer` 로그에 문서 id가 담긴 적 있음. 한계 둘: ⑴ 그 로그는 정리(prune) 대상이라 관리자가 정리하면 막힘이 풀린다 ⑵ 이체 파일 만들기는 지출결의 행을 잠그지 않아 같은 순간의 승인과 둘 다 지날 수 있다(T-07.2-18-08 accept).
2. 알림 두 종류 **기본 켬 · 이메일 켬**(관리자 규칙 화면에서 끔 가능).
3. 새 희망일은 내일(KST) 이후 영업일만 — 지난 날짜 `새 희망일 없음 · 날짜 고르기`, 휴일 `영업일만 선택 · 다시 선택`.
4. 지급 대상 행 아래 줄은 이체 파일 줄 우선(그 상태에선 요청이 막혀 함께 안 선다).
5. 되돌리기 창 60초(토스트 4초 + 지연 여유).
