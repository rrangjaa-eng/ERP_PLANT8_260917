## Pattern Assignments

### PU1/PU2/PU5 액션 (`app/(app)/projects/actions.ts` + registry)
**Analog:** `actions.ts:271-286`, `actions.registry.ts` 상단.
```ts
export const changeProjectStatusAction = authedActionClient
  .schema(z.object({ projectId: z.string().uuid(), from: z.enum(PROJECT_STATUSES), to: z.enum(PROJECT_STATUSES) }))
  .action(async ({ parsedInput, ctx }) => {
    await changeProjectStatus(ctx.viewer, parsedInput.projectId, { from: parsedInput.from, to: parsedInput.to });
    revalidatePath("/projects");
    return { status: parsedInput.to };
  });
```
```ts
registerAction({ name: "changeProjectStatusAction", menu: "projects.status", action: "write", dtoName: null });
```
규칙: 판정은 전부 domain, 거부 문구는 `UserFacingError`로 serverError 전달. `.strict()`는 `submitSettlementAction` :288 선례(입력 최소). 새 액션마다 registry 등록 필수(`test/unit/action-registry-completeness.test.ts`). 새 메뉴키는 `projects.delete`/`reopen`/`info`.

### PU1/PU5 repository 확장 (`repositories/projects.ts:488-511`)
```ts
export async function updateProjectPeriod(viewer, id, input: {... expected}, tx: DbOrTx): Promise<ProjectRow | null> {
  void viewer;
  const [row] = await tx.update(projects).set({ ..., updatedAt: new Date() })
    .where(and(eq(projects.id, id), sql`${projects.startDate} IS NOT DISTINCT FROM ${input.expected.startDate}::date`))
    .returning();
  return row ?? null;   // null = 동시 수정 거부
}
```

## Shared Patterns
- **Server Action:** `authedActionClient.schema(zod).action(...)` + `revalidatePath` + 같은 폴더 `actions.registry.ts`에 `registerAction({name, menu, action, dtoName})` (`projects/actions.ts:271`, `registry:5-26`).
- **오류:** domain은 `UserFacingError`(`@/lib/actions/user-facing-error`) 하위 클래스로 던지고 문구가 serverError로 나감. 로그는 `log.warn(event,{...})`, 금액·개인정보 금지.
- **권한:** 메뉴키로만(`can`, `ForbiddenError`), 계급 이름 판정 금지.
- **일괄:** 단건 루프 + 부분 성공 + version 동봉(payments/batch.ts).
- **DTO 노출:** `registerDto` + `test/integration/leak-scan.test.ts`.
- **주석 규약:** 파일 머리에 단계 번호·결정 번호(D-xxxx) 한국어 주석.
