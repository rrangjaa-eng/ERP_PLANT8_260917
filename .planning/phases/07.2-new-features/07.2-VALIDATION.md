## Sampling Rate

- **After every task commit:** `pnpm lint && pnpm typecheck` + 바뀐 파일 관련 단위·통합(마이그레이션 PR은 `pnpm lint:sql` 추가)
- **After every plan wave:** 플랜(PR) 끝에 CI 전체(`CI=true`), 화면 플랜은 독립 DOM 감사 → `/design-review` → `/qa`
- **Before `/gsd-verify-work`:** Full suite must be green
- **Max feedback latency:** 120초(로컬 관련 시험)
