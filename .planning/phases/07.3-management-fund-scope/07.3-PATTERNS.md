## Pattern Assignments

### `domain/permissions/can.ts` (service/guard, request-response)

**Analog:** 자기 자신. 단일 접점 — 비자금 키는 지금과 100% 동일하게 둔다.

**현재 본문** (`can.ts:12-30`):
```typescript
export type CanDeps = {
  findPermission: typeof defaultFindPermission;
};
export async function can(viewer: Viewer, menu: string, action: PermissionAction, deps?: Partial<CanDeps>): Promise<boolean> {
  if (!viewer.roleId) return false;
  const findPermission = deps?.findPermission ?? defaultFindPermission;
  const row = await findPermission(viewer, viewer.roleId, menu, action);
  return row?.allowed === true;
}
```
**적용:** `CanDeps`에 `fundGate`를 더하고(RESEARCH Code Examples), `row?.allowed !== true`면 false → `!isFundScopedMenu(menu)`면 true → `fundGate(viewer)`. `can.ts`는 `domain/settings/registry.ts`를 import하지 않는다(`registry.ts:5`가 `can` import — 순환). 설정은 `repositories/settings.findSimpleValue` + 잎의 키 문자열로 읽는다. 계급 id/이름 비교 금지(`menus.ts:20-24`), 면제는 `role.viewScope === "company"`.
