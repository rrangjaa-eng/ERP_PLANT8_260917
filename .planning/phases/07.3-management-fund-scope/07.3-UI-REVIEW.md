## Top 3 Priority Fixes (all WARNING, none blocking)

1. **The lock-line 「설정」 link is a different size from the hint it sits in.** Measured 14px on PC and 15px on phone, against 13px hint text. Impact: one line shows two type sizes. Fix: either add a `Form.Hint`-context size rule for `.tertiary` to SYSTEM (record it in DECISIONS first), or accept and document the mismatch, since 3차 is a shared component. This needs user approval because it is a system change.
2. **The settings hint 「증빙 등록 · 지급 · 구매 · 조정 · 예산 · 매출 정산」 does not name 「증빙 무효 처리」 or 「결재 중 증빙 붙이기」.** Impact: an admin cannot tell that all 8 menus follow this setting. Fix: name the 8 groups to match the grid, or use a shorter collective noun. This belongs to 07.3-01 (domain/settings/keys.ts hint).
3. **The lock line for the account without settings access (`자금 기능 본부 미지정`) gives no next step.** Impact: the user cannot tell who to ask. This is acceptable under the §7 "잠김 한 줄, 명사형" rule. Optional: a name-form suffix such as `· 시스템 관리자`, mirroring the 개정 10 precedent `계급 지정 권한 없음 · 시스템 관리자`.

## Detailed Findings

### Pillar 1: Copywriting (3/4)
- The note `{본부}만` and the unset text `자금 본부 미지정` / `자금 기능 본부 미지정 · 설정` match SYSTEM.md:1144 exactly.
- WARNING: the settings hint (07.3-01, domain/settings/keys.ts) lists 6 terms; the 2 evidence menus are only implied.

### Pillar 2: Visuals (3/4)
- The note sits after the group name and is not right-aligned, as §7-13 specifies. The phone note is beside the checkbox and the labels are unchanged (D1 holds).
- WARNING: on the lock line, the 3차 link at 600 weight and 14–15px dominates the 13px hint.

### Pillar 3: Color (4/4)
- `.groupNote` uses `--text-muted`. PermissionGrid.module.css:102-108 has no hex, rgb or px values.

### Pillar 4: Typography (3/4)
- The note is 13px, weight 400, lighter than the group name (`--fw-medium`).
- WARNING: the link font size differs from the hint (app/(app)/admin/permissions/page.tsx:55-60, Button.module.css:92-127).

### Pillar 5: Spacing (4/4)
- `margin-inline-start: var(--s-2)`. Group rows are 37.30 with or without a note. Phone dt and dd heights are 71, the same as main.

### Pillar 6: Experience Design (3/4)
- State coverage: default, unset, and no-settings-permission states were all measured. The error path reuses the existing `errorMessage`.
- The no-settings account gets a lock line with no next step (minor, see fix 3). There are no leftover decisions on the screen.
