## Pattern Assignments

### `app/print/*/[id]/layout.tsx` (layout, request-response) — 3개 서류 공통

**Analog:** `app/print/certs/[id]/layout.tsx:1-31`

한 요청에서 판정을 `cache`로 한 번만 하고, 레이아웃에서 `notFound()`를 스트리밍 전에 낸다. 제목은 `generateMetadata`가 서버에서 내고, 404 변종에는 제목이 없다(L3).

```typescript
const judgePrintable = cache(async (id: string): Promise<boolean | null> => {
  if (!(await getSessionId())) return null;
  const { viewer } = await requireSession();
  return isCertificatePrintable(viewer, id);
});
export async function generateMetadata({ params }) {
  const { id } = await params;
  return (await judgePrintable(id)) === true ? { title: "확인증 인쇄" } : {};
}
export default async function CertPrintLayout({ children, params }) {
  const { id } = await params;
  if ((await judgePrintable(id)) === false) notFound();
  return children;
}
```

적용: 판정 함수를 `getExpense`/`getLeave`/`getSettlement`(`!== null`)로 바꾼다. 제목은 `지출결의서 {번호}` 식으로 낸다. 세션이 없으면 `null`을 돌려 페이지가 로그인으로 보낸다(`layout.tsx:12-16`). 확인증의 `assertCertFeatureEnabled`는 복사하지 않는다.

### `app/print/_frame/print-frame.module.css` (공용 CSS)

**Analog:** `app/print/certs/[id]/print-cert.module.css:1-37`

```css
@page { size: A4 portrait; margin: 0; }
.root { min-height: 100vh; padding: var(--s-4) 0; background: var(--surface-canvas);
  color: var(--print-ink); font-size: 14px; line-height: var(--lh-body); word-break: keep-all; }
```

적용 시 바꿀 곳(UI-SPEC):
- `@page margin`을 `22mm 22mm 20mm`으로 두고 `.sheet`는 `min-height: 297mm`으로 한다. 고정 `height`와 `break-inside: avoid`는 뺀다.
- `@media print`에서 `.sheet`의 padding·width·outline을 접는다.
- 확인증 CSS는 건드리지 않는다.
- `.progress`·`.notReady` 클래스는 `loading.tsx`가 쓰므로 새 module에도 함께 옮긴다. 원본 CSS의 해당 규칙은 다음 이유로 읽지 않았다(286줄 중 앞 40줄만 읽음). 복사 전 원본 `print-cert.module.css` 나머지 구간을 확인할 것.

### `app/print/_frame/PrintBar.tsx` (client, event-driven)

**Analog:** `app/print/certs/[id]/print-sheet.tsx:34-58` (`useRef` 가드 + `window.print()`, 자동 인쇄는 `data-ready` 뒤 한 번)

```typescript
const printed = useRef(false);
...
if (state !== "ready" || printed.current) return;
printed.current = true;
window.print();
```

적용:
- 갈래 M(수동)이면 자동 호출은 버리고 버튼 `onClick`에서 서버 액션을 호출한 뒤 응답을 기다리지 않고 `window.print()`를 부른다. 실패해도 화면에 띄우지 않는다.
- `beforeprint` 리스너는 5초 안 중복을 한 건으로 합친다.
- 갈래 A(자동)이면 위 `useRef` 가드를 그대로 쓴다.
- 갈래는 실행 시점 `docs/design/SYSTEM.md` §6-6 문구로 정한다.
- 이미지 `decode()` 대기는 뺀다(UI-SPEC: 로고가 없으므로 `data-ready`를 루트에 처음부터 붙인다).

```typescript
export const CERT_LINK_EXPIRE_HOURS: SettingDef<number> = {

  kind: "simple",
```

- 읽기는 `getSettingValue(KEY)`(`domain/certs/events.ts:81`, `:493`와 같은 호출)로 한다.
- 07.3-02~04가 같은 파일을 건드리므로 병합 충돌과 순서를 확인한다. 위험 경로이므로 별도 PR로 뗀다.
