## Top 3 Priority Fixes

1. **D1 제목 괘선 `<hr>`의 UA 기본 테두리** — print에서 허용 밖 회색(#808080)과 세로 테두리(L/R 1px inset)가 종이에 생긴다(단언 3 · 5 위반) — `app/print/_frame/print-frame.module.css` `.rule`에 `border: 0;`을 먼저 두고 `border-top`을 그 뒤에(또는 `height:0; border:0; border-top:…`) 둔다. 색 `color`도 상속되게.
2. **A 폰 상세 머리 줄 빈 actions 틈(375 · 320, 102.6 vs 86.6px)** — 폰에서 제목 아래 16px 공백 — 사용자 결정 카드 대기. 수정은 `ui/detail-screen`(머리 줄이 보이는 자식 없는 actions를 접기) 쪽이며 이 감사는 결정을 대신하지 않는다.
3. **(권고) 감사 재현성** — `/expenses/{id}`는 스트리밍 중 `h1[data-ui="screen-title"]`이 두 개 잡히는 순간이 있다(첫 실행 strict mode 위반). `mobile-print-entry.spec.ts`의 `headHeights`가 같은 셀렉터를 쓰므로 `networkidle` 뒤 측정 또는 `:visible`로 고정 권장.

## Detailed Findings

### Pillar 1: Copywriting (4/4)
- 단언 5: dt = `프로젝트 · 지급처 · 증빙 · 지급 방식 · 지급 예정일 · 상세`(순서 일치, 4상태 × 5폭). 표 머리 `번호(sr) · 구분 · 내용 · 금액`, tfoot `지급 총액 / 금 일천삼백육십사만 원정 / 13,640,000`, 「합계」 0.
- 단언 6: 번호 줄 상태 글자 F-E1 `팀장 결재 중`(첫 단계) · 한 단계 승인 뒤 `본부 책임자 결재 중` · F-E3 `반려` · F-E4 `결재 중`(단계 이름 없음) · F-E2 0개. 각 정확히 1.
- 404 `<title>` = `PLANT8 ERP`(기본), 열람 가능 = `지출결의서 26001-0001`(단언 12).
- 관찰(결함 아님): 결재 칸 단계 이름이 `본부 책임자`로 두 칸 반복(F-E2: 본부장 · 경영 두 사람 모두 `본부 책임자`). 단계 이름은 `statusStepLabel`/결재선 설정 출처라 07.4 범위 밖이나, 종이 읽기에서 두 칸이 같은 이름이다 — 픽스처(setupExpenseE2E) 결재선 이름 탓일 가능성이 크다. 확인만 권고.

### Pillar 2: Visuals (3/4)
- 결재란: F-E1 5칸(1+4) `submitted, pending×4`, F-E3 2칸 `submitted, rejected` + `반려 사유` 1, F-E4 `기안` 1칸만(단언 7 통과).
- `<caption>` 표당 정확히 1(`명세`), 상자 1×1px(단언 19 통과).
- D1(WARNING): `.rule`(hr)이 화면 · 인쇄 모두 좌 · 우 · 아래 1px inset `rgb(128,128,128)`. 높이 0 요소라 육안으로는 거의 안 보이지만 계약 위반.

### Pillar 3: Color (2/4)
- print 미디어 계산 색 집합: `rgb(0,0,0)` · `rgb(0,84,70)`(=--print-rule) · `rgb(207,219,215)`(=--print-line) · **`rgb(128,128,128)` — HR.rule color / borderRight / borderBottom / borderLeft**. 단언 3 결함(D1). 상태색 0, 배경 이미지 · 배경색 0(단언 4 통과).
- 화면: 바탕 `--surface-canvas`, 종이 `--surface-base`, 진행 바 `--accent`(인쇄 숨김) — 토큰만. stylelint `app/print/**` 0건, 색 리터럴 grep 0(단언 14 통과).

### Pillar 4: Typography (4/4)

### Pillar 5: Spacing (3/4)
- 모든 간격 `--s-*`. `.sheet` 793.7px 모든 폭(단언 2), 화면 바 = min(793.7, 창 폭).
- A(WARNING, 결정 대기): 375 · 320 `/expenses/{결재 중}` `.head` 102.6px vs 첫 자식 86.6px — 차 16px = 빈 actions 행 + `--s-4` 간격. actions 안 `인쇄` 링크 display none(PcOnly), 남은 보이는 자식 없음. 위반 근거 UI-SPEC:597 단언 11 「머리 줄 높이 = 첫 자식 높이」 · UI-SPEC:371(입구 표 폰 줄). 원인 `ui/detail-screen`(actions 상자가 비어도 렌더) — 이 플랜은 `ui/` 변경 금지라 사용자 카드로 올라가 있다.
