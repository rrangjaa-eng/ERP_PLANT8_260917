## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | vitest (unit · integration) + Playwright (E2E) |
| **Config file** | vitest.config.ts · playwright.config.ts |
| **Quick run command** | `pnpm lint && pnpm typecheck && pnpm exec vitest run --project unit <바뀐 파일 관련>` |
| **Full suite command** | CI (ready 때 build · 전체 단위 · 통합 · E2E — 로컬에서 되풀이하지 않음, CLAUDE.md §5) |
| **Estimated runtime** | 단위 ~30초 · 통합(플랜당 파일 3~6개) ~2~4분 · E2E(플랜당 스펙 2~5개) ~3~6분 |

통합 · E2E 명령은 공용 DB 잠금 꼴 그대로: `flock /tmp/plant8-erp-test.lock sh -c 'pnpm db:dev && pnpm db:reset:test && …'` — 아래 표는 그 안쪽 명령만 적는다. 표는 각 PLAN `<verify>`와 같은 집합이다(eng 1회차 반영 2026-11-04). 캡처 스펙(design-capture-*)은 `DESIGN_CAPTURE_DIR` 없이 돌면 건너뛰므로 늘 지정한다. desktop-settings 스펙은 `--project=desktop-settings --no-deps`로 돌린다.

## Sampling Rate

- **After every task commit:** Run lint · typecheck · 관련 단위 · 통합
- **After every plan wave:** Run 건드린 화면 E2E(CI=true)
- **Before `/gsd-verify-work`:** Full suite must be green
- **Max feedback latency:** 태스크당 6분 이하(통합 + E2E 묶음 한 번)
