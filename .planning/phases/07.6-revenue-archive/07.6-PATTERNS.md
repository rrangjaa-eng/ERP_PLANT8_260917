## Pattern Assignments

### `domain/revenue/archive.ts` (service, CRUD + 로그) - 신규

**Analog:** `domain/projects/members.ts` (프로젝트 행 잠금 -> 조건부 보관/해제 -> recordAction) + `domain/reserves/index.ts` `restoreReserve`.

**잠긴 프로젝트 래퍼** (`members.ts:258-266`) - 매출용은 팀/PM 비교 대신 `fundOp` 쓰기 범위 판정을 tx 앞에서 하고, tx 안에서는 잠금 + 보관 프로젝트 거부만 복사:
```typescript
async function inLockedProject<T>(viewer: Viewer, basis: ProjectRow, write: (tx: DbOrTx, row: ProjectRow) => Promise<T>): Promise<T> {
  return withTransaction(async (tx) => {
    const row = await lockProjectForWrite(viewer, basis.id, tx);
    if (!row || row.archivedAt !== null) throw new UserFacingError(NOT_PROCESSED);
    ...
    return write(tx, row);
  });
}
```

**지우기 -> 로그** (`members.ts:304-312`):
```typescript
await inLockedProject(viewer, project, async (tx) => {
  if (!(await archiveLiveMember(viewer, { projectId, userId }, tx))) throw new UserFacingError(NOT_PROCESSED);
  await recordAction(viewer, { actionType: MEMBER_ACTION, entity: PROJECT_ENTITY, entityId: projectId, detail: {...} }, { tx });
});
```
매출 줄은 `archiveLiveMember` 자리에 `archiveRevenueEntryIfVersionMatches(viewer, id, expectedVersion, owner, tx)`(WHERE id + version + projectId + kind + `archived_at is null`, `archived_by = viewer.id`, `version + 1`) 0행이면 R6와 같은 충돌 문구(`domain/revenue/index.ts:507`)로 거부. `actionType: "archive"`, `entity: "revenue_entry"`, `entityId: projectId`(index.ts:578 관례), `detail: { entryId, lineChanges }`.

**되돌리기 10분 창 + 본인 판정** (`members.ts:48, 319-330`): `RESTORE_WINDOW_MS = 10 * 60_000`, `Math.abs(now().getTime() - occurredAt.getTime()) <= RESTORE_WINDOW_MS`(양쪽 재기 주석 R-1 유지). 매출은 로그 조회 대신 줄의 `archived_by === viewer.id` + `archived_at` 10분 이내로 판정(D-7602 가정 A1) - 줄 자체에 시각이 있어 `findLatestMemberChangeFor` 불필요.

**복원기 (보관함용)** (`restoreReserve` `reserves/index.ts:541-560`): 입구 권한 -> `UUID_SHAPE` 검사 -> tx -> 읽기 -> `afterLock?.()` 테스트 훅 -> 재읽기 -> 이미 활성이면 로그 없이 `{ restored: false }` -> 해제 -> `recordAction({actionType:"restore"...}, {tx})`:
```typescript
if (!UUID_SHAPE.test(id)) denyWrite(viewer, "reserve.restore", { entryIds: [id] }, new UserFacingError(ENTRY_NOT_FOUND));
...
if (!current || current.archivedAt === null) return { restored: false };
```
시그니처는 `restoreRevenueEntry(viewer, id, deps?: Partial<{ recordAction; afterLock; now }>): Promise<{ restored: boolean }>` (DOMAIN_RESTORERS 타입에 맞춤). 보관 프로젝트의 줄은 복원 거부(` · 복원 불가` 끝맺음, `domain/archive/index.ts:243-246`).

**권한/범위 호출 모양** (`domain/revenue/index.ts:592`, tx 앞에서):
```typescript
if (!(await findProjectInScope(viewer, await projectRowScope(viewer, undefined, { fundOp: [REVENUE_SETTLEMENT_MENU, "write"] }), projectId))) throw new ProjectNotFoundError("존재하지 않는 프로젝트");
```
권한 `revenueWriteRights` (index.ts:540-542)는 tx 앞에서 계산. 잠근 tx 안에서 `can` 호출 금지.

**로그 상세**: `buildChanges(entryChangeView(row), {})`(지우기, 이후 null) / `buildChanges({}, entryChangeView(row))`(복원) -> `lineChanges: [{ id, kind, no, name: null, changes }]`. `no`는 `numberEntryChanges`(index.ts:529, R1 필터 후)로 부여. `detail-lines.ts:64-66` 렌더러는 수정 없음.
