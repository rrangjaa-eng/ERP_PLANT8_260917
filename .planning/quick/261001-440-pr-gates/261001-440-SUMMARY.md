# 261001-440 — 머지 훅 게이트 판정: PR이 추가한 게이트 로그 줄로

## 무엇을
`.claude/hooks/plant8-skill-gate.sh` `merge)` 분기가 review·qa·design-review를 STATE 페이즈 로그(`phase-${current_phase}.log`) 하나에서만 찾던 것을, 사용자 결정 (가)(2026-10-01)대로 바꿨다.
- PR diff가 `.claude/gates/*.log`를 건드렸으면, 그 로그에 이 PR이 더한 줄(대상 대비 `+`)에서만 찾는다. gh 경로는 files API `.patch`, gh 실패 대체 경로는 병합 커밋 첫 부모 대비 `git diff -U0`. 추가 줄을 못 받으면 비어서 거부(fail closed).
- 건드리지 않았으면 기존대로 STATE 페이즈 로그.
- 문서 PR 면제·위험 경로 판정·대체 경로·다른 분기는 그대로.

- RED: 새 테스트 10개 중 8건 실패(PASS=149 FAIL=8) — 모두 STATE 페이즈 로그만 보는 기존 판정 때문.
