### 절차
1. `/browse`로 출처 확인: GitHub `orioncactus/pretendard` 최신 릴리스(2024-05 기준 v1.3.9 — **버전·경로는 확인 필요**). 릴리스 zip 안의 `web/variable/woff2-dynamic-subset/`(서브셋 woff2 100여 개) + `web/variable/pretendardvariable-dynamic-subset.css`. npm 패키지 `pretendard`의 `dist/web/variable/` 에 같은 파일이 있다(패키지 의존은 만들지 않는다 — 파일만 복사)
2. 라이선스 파일(`LICENSE`, OFL 1.1) 원문을 함께 둘 것. OFL은 재배포 시 라이선스 동봉을 요구한다
3. `@font-face` 계획을 `SYSTEM.md` §2-1 아래에 코드 블록으로 적는다: css의 `url(…)`을 `/fonts/pretendard/…`로 바꾸고 `font-display: swap`, `font-weight: 45 920`(Variable). 전역 CSS는 `--font-sans`만 쓴다(`tokens.css` 그대로)
4. (Phase 1 머지 후) `public/fonts/pretendard/` 에 복사, `app/layout.tsx`(또는 전역 CSS)에 css 링크. 캐시 헤더는 Cloud Run 정적 자산 기본
5. **검수**: Windows Chrome/Edge에서 표의 자릿수 정렬 스크린샷 — 맑은 고딕 폴백과 Pretendard `tnum`을 나란히. 첫 로드 전송량 200–300KB 확인(사내 10~30명, 캐시 후 0)

### 물을 것 (한 건)
- 서브셋 파일 100여 개를 리포에 커밋하는 것(약 2MB)에 동의하는지 — 대안은 빌드 시 다운로드 스크립트(`scripts/fetch-fonts.sh`), 그러면 배포가 외부 릴리스 URL에 의존한다. **권고: 커밋**(사내망 정책·재현성)

### 초안이 임시로 정한 것 (SYSTEM.md에 없는 것 — 보드에서 「내가 정한 것」 표로 보이고 물어야 한다)
- **C-1 폼**: (a) 세금 자동 계산(EXP-15)은 **공급가액 입력 아래 한 줄** `부가세 10% 1,240,000 · 지급 총액 13,640,000 · 세금계산서 규칙 · 서버 계산`(`--fs-sm --muted`, 숫자 700). 지급 예정일 아래에도 같은 모양으로 `결재 마감 · 지급일 규칙` (b) 폰에서 제출 줄은 **하단 탭 위에 고정**(탭 유지), 1차 버튼 44 전폭, 이유는 그 아래 한 줄 (c) 「바꾸기」가 무엇을 여는지는 **정하지 않았다**(버튼만 있음) (d) 결재선 끝에 `· 자기 승인 없음 · 결재 규칙` 한 마디로 건너뜀을 표시. 그 밖에: 거래처 자동 채움 옆에 `기본 증빙 세금계산서` 부제, 제출 실패(ERROR)는 버튼을 살려 두고 옆에 `제출하지 못했습니다 · 지급 예정일 1칸 · 값은 남아 있습니다`, 제출됨(SUCCESS)은 버튼 자리에 `결재 요청됨 → 김도윤 · 14:02` + 토스트 + 3차 「지출결의 목록」
- **C-2 손익 원장**: (a) **폰 P1 = 프로젝트 · 수익 · 목표 대비 막대**(수익률은 접힌 줄로). 막대는 폰에서 56px (b) 완료 프로젝트는 **같은 표의 「완료 · 정산」 그룹**, 수익 셀 아래 `정산 09-08 · 스냅샷` 부제. 그 밖에: 계산 불가 행은 비용·수익·수익률·막대 전부 `계산 불가`/`—`, 머리에 `계산 불가 1건` 배지, 합계 부제 `계산된 것만 · 6건 · 계산 불가 1건 제외`; 팀장 장면은 「팀」 열과 팀 필터가 **아예 없다**(서버가 안 보냄); 「Excel 내보내기」 2차 버튼; 내 차례에 정산 결재 한 줄
- **C-3 외부 수령자**: (a) **개인정보 수집·이용 동의 = 체크박스 + 고지 문장**(수집 항목 · 목적 · 보존 5년 · 미동의 시 지급 불가 · 「전문 보기」 3차). 서명 위, 1px 선으로 묶음. **문장은 법무 확인 전 초안** (b) 서명 「다시 쓰기」 3차 버튼은 **서명이 있을 때만** 오른쪽 아래 (c) 링크 만료 문구 `이미 제출된 링크입니다 · 김하늘 · 2026-09-20 18:42 제출됨. 내용을 고치려면 담당자 박서연 · PLANT8 경영관리에 연락해 주세요`. 그 밖에: 지급 블록 아래 `PLANT8이 미리 채운 금액입니다 · 다르면 담당자 박서연에게 연락해 주세요`(이 화면만 ~해 주세요체 허용), 1차 버튼 라벨 「확인증 제출」, 막힘 이유가 빈 칸 전체를 나열, 제출됨 화면에 지급일·은행 한 줄과 담당자 연락 안내, 주민등록번호 뒷자리는 `type=password`
