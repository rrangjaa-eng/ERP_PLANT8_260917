## 0. 방향

**이름: 원장(元帳)** — 안 A. 색 구성은 안 C(작업대)의 그린 톤온톤을 흡수했다.

**한 줄 원칙**
> 화면 전체가 하나의 원장이다. 카드도 패널도 그림자도 없다. 깊이는 선 두께 2단계와 그린 명도 단계로만 만든다.

이 한 줄이 이 제품이 남과 다른 지점이다. 「흔한 AI 대시보드」(카드 타일·큰 숫자·그라디언트)로 가는 길을 구조적으로 막고, 「관공서 사내망」(회색 격자·작은 글씨)과는 선 두께의 위계와 여유 있는 행 높이로 갈라진다.

**채택 이유 3줄**
1. 가장 잦은 작업(견적 줄 표, 연 1,379행)을 표 자체가 화면인 틀이 정면으로 푼다. 표를 「나중에 따로」 만드는 안은 시스템 두 벌이다.
2. 계급마다 칸 수가 달라지는 정보 노출표에 가장 잘 견딘다. 원장은 칸이 빠지면 폭이 재분배될 뿐, 빈 타일이 남지 않는다.
3. 컴포넌트 수가 가장 적고 규칙이 한 줄로 말해진다. 비개발자 1인이 6개월 뒤에도 고칠 수 있다.

### 1-3. 색 사용 규칙

1. **포인트 색(`--accent`)을 쓰는 곳은 다섯 곳뿐**: ① 내 차례 태그·행동 링크 ② 편집 중 셀·행 ③ 1차 버튼 ④ 포커스 링 ⑤ 현재 위치(내비게이션 밑줄). 그 밖의 장식(아이콘 색, 제목 색, 구분선 색)에는 쓰지 않는다.
2. **배경 틴트 단계는 세 개(`--bg` → `--surface` → `--g-50` → `--g-100`)만 쓰고 중첩하지 않는다.** 틴트 위에 틴트를 올리지 않는다. 틴트 위에 두 번째 깊이가 필요하면 선(2px)으로 만든다.
3. 상태색은 **글자·태그 테두리·약한 배경** 세 형태로만 쓴다. 상태색으로 넓은 면을 채우거나(행 전체 붉게), 상태색 버튼을 만들지 않는다. 막힘 행의 배경은 `--danger-weak`이 아니라 태그만 붉다. 오류 **셀**만 `--danger-weak`으로 채운다.
4. 상단 바(`--bar`)는 앱 전체에서 **딥그린 면이 나오는 유일한 곳**이다. 1차 버튼은 면이 아니라 컨트롤이다. 하단 힌트 줄·푸터는 흰 바탕에 `--faint` 글자다.
5. 검정 `#000000`은 인쇄 템플릿의 글자에만 쓴다(§6-6). 화면 글자는 `--fg`다.
6. 새 색을 만들지 않는다. 필요하면 `--g-*` 단계에서 고르고, 없으면 `DECISIONS.md`에 이유를 남기고 단계를 추가한다.

| 항목 | 결정 |

시스템 스택을 버린 이유: 회사 PC는 Windows가 많아 시스템 스택이면 맑은 고딕이 되고, 맑은 고딕은 tabular-nums를 지원하지 않아 표의 자릿수 정렬이 깨진다. 표가 화면인 시스템에서 이건 비용이 아니라 성립 조건이다. 서브셋 첫 로드는 약 200–300KB, 사내 고정 사용자라 캐시 후 0이다.

| 토큰 | 크기 | 행간 | 굵기 | 쓰는 곳 |
|---|---|---|---|---|
| `--fs-xs` | 11 | 1.4 | 600 | 상태 태그 · 행 번호 · 단축키 kbd |
| `--fs-sm` | 12 | 1.5 | 400/600 | 표 머리글 · 라벨 · 힌트 줄 · 각주 · 외화 병기 2행 |

- 화면당 크기 4단계 이상 섞지 않는다. 큰 숫자 히어로(`--fs-xl` 이상 금액)는 만들지 않는다(안티슬롭).
- 폰(<700px)에서는 `--fs-base`가 15px가 된다. 그 밖의 단계는 그대로.

### 2-3. 행간 · 자간 · 줄 길이

- 한글 본문: `line-height: 1.6`, `letter-spacing: -0.015em`, `word-break: keep-all`, `overflow-wrap: anywhere`(긴 영문 거래처명 대비)
- 표 셀: `line-height: 1.5` (밀도). 단, 셀 내용이 2줄이 되면(항목명 줄바꿈·외화 병기) 행 높이는 내용을 따른다. 행 높이를 고정하지 않는다
- 제목(`--fs-lg` 이상): `letter-spacing: -0.02em`
- 숫자: `letter-spacing: 0` (자간 음수를 풀어 자릿수 폭을 지킨다)
- 줄 길이: 산문(안내·설정 설명)은 `max-width: 64ch`. 표·폼은 컨테이너 폭을 따른다

## 3. 간격

- 기본 단위 **4px**. 토큰 `--s-1`(4) `--s-2`(8) `--s-3`(12) `--s-4`(16) `--s-6`(24) `--s-8`(32) `--s-12`(48)
- 컨테이너: `max-width: 1280px`, 좌우 패딩 PC 20px(`--s-5`=20, 예외 허용) · 폰 14px. 가운데 정렬하지 않고 **왼쪽 정렬**(원장은 왼쪽에서 시작한다). 1440에서 오른쪽이 비는 것을 받아들인다
- 그리드: 열 그리드를 두지 않는다. 정렬 기준은 **표의 열 정렬**(문자 좌·숫자 우)이다. 「내 차례」의 금액은 행동 버튼 왼쪽의 고정 최소폭(11ch) 칸에 우측 정렬한다 — 아래 표의 열과 억지로 맞추지 않는다
- 표 셀 패딩: `6px 8px`(PC) · `10px 8px`(폰, 터치 목표 44px 확보). 그룹 머리글 행은 위로 `--s-3` 추가
- 섹션 사이: 2px 강한 선 위 `--s-6`, 아래 `--s-3`
- 폼: 라벨-입력 세로 4px, 항목 사이 16px, 묶음 사이 24px + 1px 선
- 터치 목표: 폰에서 모든 행동 요소 최소 44×44. PC 버튼 높이 32, 폰 40

| 카드 | 해당 없음 — **카드를 만들지 않는다** |
| 아바타·QR 등 외부 이미지 | 0 |

직각은 이 시스템의 형태 원칙이다. 「둥글둥글 = 장난감」을 배제한 브리프의 직접 결과다.

### 4-2. 테두리 (선 3단계 + UI 경계 1)

| 종류 | 두께 · 색 | 쓰는 곳 |
|---|---|---|
| 강한 선 | `2px solid --line-strong` | 섹션 시작(내 차례 위, 표 머리글 아래), 합계 행 위, 상단 바 아래, 모달 테두리 |
| 약한 선 | `1px solid --line` | 표 행 사이, 목록 항목 사이, 폼 묶음 사이 |
| 점선 | `1px dotted --line` | 「내 차례」 항목 사이 (표가 아님을 표시) |
| UI 경계 | `1px solid --line-ui` | 입력 테두리(대기 상태), 체크박스, 2차 버튼이 아닌 3차 컨트롤 |

세로선은 표 안에서 쓰지 않는다(격자 = 관공서 인상). 열 정렬은 정렬 방향(문자 좌 · 숫자 우)과 패딩으로 만든다. 예외: 인쇄 템플릿의 괘선(§6-6).

### 4-3. 그림자 · 깊이

- **그림자 없음.** `box-shadow`는 인셋 선(`inset 0 -2px 0 --accent` 현재 탭 밑줄, `inset 2px 0 0 --danger` 오류 셀 좌측)에만 쓴다
- 깊이는 세 수단만: 선 두께(2px/1px) · 배경 한 단계(`--surface`/`--g-50`/`--g-100`) · 가림막(`--scrim`)
- 모달·시트: `--bg` 면 + `2px solid --line-strong` 테두리 + 뒤에 `--scrim`. 그림자 없음
- 고정(sticky) 요소: 표 머리글은 스크롤 시 상단에 붙고 아래 1px `--line-strong`으로 구분. 그림자로 띄우지 않는다

## 5. 모션

**원칙: 응답형만.** 사용자의 입력에 즉시 반응하는 상태 변화 외에는 움직이지 않는다.

### 허용 목록

| 대상 | 속성 | 시간 | 이징 |
|---|---|---|---|
| 버튼·행·탭 hover/focus | `background-color`, `color`, `border-color` | 120ms | `ease-out` |
| 저장 완료 행 | 배경 `--g-50` → `--bg` 한 번 | 600ms | `ease-out` |
| 토스트 나타남/사라짐 | `opacity`, `translateY(4px→0)` | 160ms | `ease-out` |
| 시트(폰 하단) 열림/닫힘 | `transform: translateY` | 200ms | `cubic-bezier(.2,.8,.2,1)` |
| 모달 열림 | `opacity` | 120ms | `ease-out` |
| 진행 표시(로딩) | 상단 2px 바 `width` | 무한, 1.2s | `linear` |

### 금지 목록
섹션 fade-up · 카드/행 hover 확대(`scale`) · 페이지 전환 애니메이션 · 숫자 카운트업 · 스켈레톤 반짝임(shimmer) · 패럴랙스 · 그라디언트 이동 · 아이콘 회전(로딩 스피너 포함 — 상단 진행 바로 대체) · 자동 슬라이드

### `prefers-reduced-motion: reduce`
모든 `transition-duration`·`animation-duration`을 `0.01ms`로. 진행 바는 정지된 `--accent` 2px 선으로 대체. 시트·모달은 즉시 나타남.

- 기타소득 확인증: 같은 골격. 제목 「기타소득 지급 확인증」, 수령자 정보 표(이름·주민등록번호 뒷자리 마스킹·주소·연락처·계좌), 지급액·소득 종류·원천징수액, 하단에 터치 서명 이미지와 제출 일시

- 첨부 이미지는 2장부터 한 장에 하나, 긴 변 맞춤
- 화면에서 「인쇄」는 2차 버튼. 새 탭으로 인쇄 라우트를 열고 자동 `window.print()`

## 7. 컴포넌트 규칙

모든 컴포넌트는 LOADING · EMPTY · ERROR · SUCCESS · PARTIAL 다섯 상태를 정의한다(UX-01). 상태별 규칙은 §7-7.

### 7-1. 버튼 위계

| 위계 | 모양 | 한 화면에 | 예 |
|---|---|---|---|
| 1차 | `--accent` 면 + 흰 글자 600 · hover `--accent-hover` | **1개** | 일괄 저장 · 제출 · 승인 |
| 2차 | 흰 면 + `1px --line-strong` 테두리 + `--fg` 600 · hover `--surface` | 필요한 만큼 | 복사해 새 차수 · 인쇄 · 반려 |
| 3차 | 테두리 없음, `--accent` 글자 600 + 아래 1px 밑줄 · hover 밑줄 2px | 표·목록 행 안 | 증빙 올리기 · 견적 열기 · 바꾸기 |

- 높이 PC 32 · 폰 40. 패딩 좌우 12. `--fs-sm` 600. radius 0
- 단축키가 있는 버튼은 라벨 오른쪽에 `kbd`(`--fs-xs`, `1px --line`, `--faint`)로 병기: `일괄 저장 ⌘S`
- 건수가 있으면 라벨 뒤에 숫자: `일괄 저장 3`
- **비활성 버튼은 이유를 옆에 글자로 쓴다.** `--surface` 면 + `--faint` 글자 + `cursor: not-allowed`. 이유 텍스트 `--fs-sm --danger` + 다음 한 수 3차 버튼. 이유 없는 비활성 버튼은 금지(UX-06)
- 위험 행동(삭제·반려)은 색이 아니라 **확인 모달**로 구분한다. 붉은 버튼 없음
- 버튼 라벨 = 실제 동작(§8). `확인` `제출` 같은 빈 라벨 금지

### 7-2. 입력 · 오류 표시

- 텍스트 입력: 높이 32(PC)/40(폰)/48(외부 수령자). `1px solid --line-ui`, 배경 `--bg`, 패딩 `0 8px`, `--fs-base`. focus: `outline 2px --focus offset 2px`, 테두리는 그대로. radius 0
- 표 안 입력: 테두리 없이 아래 `1px --accent` 밑줄 + focus 링. 셀 배경 `--g-50`
- 라벨: 입력 위(폰) 또는 왼쪽 96px(PC 폼). `--fs-sm --muted` 600. 필수 표시 `*` 없음 — 필수인데 비면 제출 버튼이 이유를 말한다
- 자리표시자(placeholder)는 형식 예만: `2026-09-18`, `12,400,000`. 안내문 금지
- 금액 입력: 타이핑 중 쉼표 자동 삽입, 우측 정렬, `tabular-nums`
- 선택(select): 네이티브 `<select>` 그대로 + 시스템 테두리. 커스텀 드롭다운 만들지 않는다
- 오류(서버 검증, UX-04): 입력 테두리 `--danger` 1px + 입력 아래 `--fs-sm --danger` 한 줄 **「원인 · 다음 행동」**. 예: `날짜 형식이 아닙니다 · 2026-09-18처럼 적어 주세요`. 아이콘 없음. 입력값은 지우지 않는다
- 자동 채움된 칸: 입력 대신 텍스트 + 「바꾸기」 3차 버튼

### 7-3. 표 (이 시스템의 중심 컴포넌트)

**구조**
- 머리글: `--fs-sm --muted` 600, 아래 `1px --line-strong`. 스크롤 시 sticky. 읽기용 표(목록)는 흰 바탕, **편집용 표(견적·카드·목표)는 `--g-100` 바탕 + `--g-950` 글자** — 편집 가능한 표임을 머리글 색으로 안다
- 행: 아래 `1px --line`. hover `--surface`. 높이는 내용 따라(최소 36 PC / 44 폰)
- 그룹 머리글 행: `--fs-sm --muted` 600, 위 12px 여백, 아래 `1px --line-strong`
- 합계 행: 위 `2px --line-strong`, `--fs-base` 700. 편집용 표에서는 `--g-100` 바탕. **저장 결과 메시지가 이 행 오른쪽 끝에 붙는다**(아래)
- 세로선 없음. 첫 칸(행 번호) `--fs-xs --faint`, 폭 28
- 열 폭: 문자 열은 `auto`, 숫자 열은 내용 최대 자릿수에 고정(`ch` 단위). 항목명은 줄바꿈 허용(`keep-all`), 거래처는 한 줄 말줄임

**편집 (UX-05, 엑셀과 같은 키)**
- 셀 클릭 또는 Enter → 편집. Tab/Shift+Tab 좌우, Enter 아래, 방향키 이동, Esc 취소(값 되돌림), ⌘C/⌘V 범위 복사·붙여넣기(붙여넣기 범위가 표를 넘으면 새 줄 자동), ⌘↵ 새 줄, ⌘S 일괄 저장, ⌘E 현재 줄로 지출결의, ⌘D 줄 복제, Delete 줄 삭제(확인 모달)
- 편집 중 행: 배경 `--g-50`, 셀에 `--accent` 밑줄. 저장 대기(dirty) 셀: `inset 0 0 0 1px --g-600` 외곽선. 선택 범위: `--g-50`, 활성 셀 `2px --accent` 외곽선
- **일괄 저장은 전부 저장 또는 전부 거부.** 실패 시: 오류 셀은 `--danger-weak` 배경 + 좌측 `2px --danger` 인셋 선으로 **고정**(다른 셀을 편집해도 남는다), 셀 hover/포커스에 이유 한 줄(`--fs-sm --danger`, 셀 아래 인라인). 합계 행 오른쪽에 `오류 1칸 · 전부 거부` 붉게. 성공 시 같은 자리에 `저장됨 6줄 14:02` `--success`, 편집 행 배경이 600ms 동안 `--g-50` → `--bg`
- 충돌(다른 사람이 먼저 저장): 해당 셀을 오류 셀과 같은 모양으로 고정, 이유 `다른 사람이 14:01에 9,800,000으로 바꿈 · 덮어쓰기 / 그 값으로`
- 읽기 모드와 편집 모드를 나누지 않는다. 편집 권한이 있으면 표는 항상 편집 가능하다

**외화 병기 (행 높이 규칙)**
- 금액 셀은 `vertical-align: top`. 외화가 있는 행만 금액 셀이 두 줄(1행 원화, 2행 `--fs-sm --muted` `USD 4,400.00 @1,318.18`)이 되고, 같은 행의 다른 셀은 첫 줄 기준으로 정렬된다. 행 높이는 두 줄 셀을 따른다. 고정 높이 금지
- 편집은 원화가 아니라 **외화 금액·환율** 두 칸에서 하고 원화는 계산값(읽기 전용)이다
- 합계 행은 원화만. 외화 합계는 만들지 않는다
- 폰에서는 2행이 접힌 줄(P2)로 내려간다

**폰 전략 = 칸 접기 (가로 스크롤 금지 · 카드 전환 금지)**
- 모든 열은 우선순위 **P1 / P2 / P3**을 선언한다. `<700px`에서 P1만 열로 남고 P2는 각 행 아래 **접힌 줄** 하나(`--fs-sm --muted`, `라벨 없이 값 · 값 · 값`, 순서는 열 순서)로 들어가고 P3은 숨는다(상세에서 본다)
- P1은 **항목(문자 1개) + 금액(숫자 1개) + 상태 또는 행동(1개)**, 최대 3열. 그 이상 P1을 두면 시스템 위반
- 접힌 줄에 외화 2행·거래처·날짜·오류 이유가 들어간다. 그 대신 P1 셀 안의 2행(외화·오류 이유)은 폰에서 숨긴다 — 같은 정보를 두 번 보이지 않는다. 행은 두 줄이 되고 터치 목표 44px가 확보된다
- 합계 행의 부제(`공급가액 · 6줄`)는 폰에서 숨긴다. 네 숫자 줄(PNL)은 숨기지 않고 `--fs-sm`으로 줄바꿈한다
- 그룹 머리글·합계 행은 폰에서도 그대로. 합계는 P1 금액 열만
- 폰에서 셀 편집 없음. 행 탭 → 하단 시트(§7-8)에서 상세와 행동
- 표를 카드로 바꾸지 않는다. 카드가 없는 것이 이 시스템의 원칙이고, 접힌 행이 카드의 일을 한다

**칸 수 가변(정보 노출표) 대응**
- 열은 서버가 계급에 따라 **아예 보내지 않는다**. 클라이언트에서 숨기지 않는다(누수 방지)
- 빠진 열의 폭은 문자 열이 흡수한다. 숫자 열은 자릿수 고정폭이라 흔들리지 않는다
- 「차익」「손익」 열이 빠져도 합계 행은 남은 열만으로 성립한다. 빈 칸 자리를 `—`로 채우지 않는다(있는데 값이 없을 때만 `—`)

### 7-4. 「내 차례」 목록

- 역할별 첫 화면 최상단. 위 `2px --line-strong`, 항목 사이 `1px dotted --line`. 최대 **6줄**, 넘으면 `더 보기 4건` 3차 버튼
- 한 줄 = `[태그] 대상 — 상황(이유)  금액  다음 한 수(3차 버튼)`. 이유와 다음 한 수는 **반드시 같은 줄**에 있다(브리프 검증 질문 1)
- 태그(§7-5) 순서 고정: 막힘(`--danger`) → 오늘(`--warning`) → 결재(`--accent`) → 대기(`--accent`)
- 폰: 두 줄(1행 태그·대상·행동, 2행 금액·이유)
- 항목이 0이면 이 블록은 **사라진다**. 「할 일이 없습니다」를 쓰지 않는다. 대신 목록 화면이 위로 올라온다

### 7-5. 상태 태그

- `--fs-xs` 600, `1px solid currentColor`, 패딩 `1px 6px`, radius 0, 배경 없음. 색은 의미 토큰 하나: `--danger`(막힘·증빙 없음·반려) · `--warning`(오늘·마감 임박) · `--accent`(내 차례·결재 중·편집 중) · `--success`(승인·연결·저장됨) · `--muted`(대기·미착수·임시)
- 표 상태 열에서는 태그 대신 **색 글자만**(`--fs-xs` 600). 테두리 태그는 「내 차례」와 화면 제목 옆에서만
- 태그 글자는 두 글자~네 글자 명사: `막힘` `오늘` `결재` `대기` `승인` `반려` `편집 중`. 문장 금지

### 7-6. 토스트

- 화면 하단 왼쪽(폰은 하단 탭 위), `--bg` 면 + `2px --line-strong` 테두리, `--fs-sm`, 최대 1개. 4초 뒤 사라짐, 오류는 닫을 때까지
- 내용 = **버튼과 같은 단어 + 결과**: `일괄 저장 · 6줄 저장됨` `제출 · 결재 요청됨 → 김팀장`. 실행 취소가 가능하면 3차 버튼 `되돌리기`
- 표 저장 결과는 토스트를 띄우지 않는다(합계 행에 이미 있다). 화면 이동이 따르는 행동(제출·승인)만 토스트

### 7-7. 다섯 상태 (LOADING · EMPTY · ERROR · SUCCESS · PARTIAL)

| 상태 | 모양 | 규칙 |
|---|---|---|
| LOADING | 상단 바 아래 `2px --accent` 진행 바 + 표는 머리글·합계 행 뼈대만 그리고 본문 자리는 `--surface` 행 3개(반짝임 없음) | 스피너·스켈레톤 애니메이션 없음. 300ms 안에 끝나면 아무것도 보이지 않게(지연 표시) |
| EMPTY | 표 본문 자리에 한 줄: **「무엇이 없다 · 다음 한 수」** `--fs-base --muted` + 3차 버튼. 그림·일러스트 없음 | 예: `이 프로젝트에 견적 줄이 없습니다 · 첫 줄 만들기 ⌘↵` / `결재할 건이 없습니다 · 지출결의 목록 보기`. **「내 차례」가 비면 블록 자체가 없다**(§7-4). 필터 결과 0은 `조건에 맞는 건이 없습니다 · 필터 지우기` |
| ERROR | 표 본문 자리 또는 폼 상단에 한 줄 `--danger`: **「무엇이 안 됐다 · 다음 행동」** + 2차 버튼 `다시 시도` | 사과 문구 없음. 입력값은 보존. 예: `저장하지 못했습니다 · 네트워크 · 다시 시도` |
| SUCCESS | 행동한 자리에서 결과가 보인다: 합계 행 `저장됨 6줄`, 제출 버튼 자리에 `결재 요청됨 → 김팀장` | 성공 화면·체크 아이콘·확인 모달 없음 |
| PARTIAL | 일부만 보이거나 계산되지 않은 상태: `계산 불가 1건`처럼 건수 배지(`--fs-xs --muted` 테두리 태그) + 합계는 계산된 것만 | 빈 자리를 0으로 채우지 않는다 |

### 7-8. 모달 · 시트

- 모달(PC): 폭 480 고정, `--bg` + `2px --line-strong`, 제목 `--fs-lg`, 하단 오른쪽에 2차 「취소」 + 1차 행동. 위험 행동 확인에만 쓴다(삭제·반려·덮어쓰기). 폼을 모달에 넣지 않는다 — 폼은 화면이다
- 시트(폰): 하단에서 올라옴, 높이 내용 따라 최대 85vh, 위 `2px --line-strong`. 표 행의 상세·행동, 메뉴(≡)에 쓴다
- 둘 다 `--scrim` 뒤, Esc로 닫힘, 포커스 트랩, 열릴 때 첫 행동 요소에 포커스

### 7-9. 단축키 힌트 줄 (C에서 흡수)

- 편집용 표가 있는 화면 하단에 **항상** 보인다. `--fs-sm --faint`, 항목 사이 16px, `kbd`는 `--fs-xs` `1px --line`
- 내용은 그 화면에서 실제로 되는 것만, 최대 7개: `이동 Tab ↑↓←→ · 범위 복사 ⌘C / 붙여넣기 ⌘V · 취소 Esc · 새 줄 ⌘↵ · 저장 ⌘S · 지출결의 ⌘E`
- 폰에서는 숨는다(키보드가 없다)
- 명령 팔레트 `⌘K`: 상단 바에 글자로 상시 노출. 열면 검색 입력 하나 + 결과 목록(원장 행 모양). 명령 파서는 만들지 않는다 — 검색과 이동만

### 7-10. 첨부 영역

- `--surface` 면 + `1px dashed --line-ui`, 높이 96(PC)/72(폰). 안의 글자 한 줄 `--fs-sm --muted`: `파일을 끌어 놓거나 ⌘U · 이미지·PDF 10MB`
- 첨부된 파일은 목록 행(파일명 · 크기 · 날짜 · 3차 「삭제」). 썸네일은 이미지일 때 48px 정사각, radius 0
- 폰: 영역 탭 → 카메라/사진/파일 네이티브 선택
- 업로드 중: 행 아래 `2px --accent` 진행 바. 실패: 행이 오류 셀 모양(§7-3)

## 8. 카피 규칙

1. **버튼 = 실제 동작.** `제출` `확인` `저장` 단독 금지. `지출결의 제출` `일괄 저장 3` `증빙 올리기` `복사해 새 차수`
2. **토스트·결과 = 버튼과 같은 단어.** 버튼이 「일괄 저장」이면 결과는 「일괄 저장 · 6줄 저장됨」. 다른 동사로 바꿔 말하지 않는다
3. **오류 = 원인 · 다음 행동.** 가운뎃점으로 나눈 한 줄. `증빙 없음 · 증빙 올리기` `날짜 형식이 아닙니다 · 2026-09-18처럼`. 원인만 쓰고 끝내지 않는다
4. **사과·감탄·이모지·느낌표 없음.** 「죄송합니다」「성공했습니다!」 금지. `저장됨` `제출됨` `결재 요청됨`
5. **안내 문구 없음(UX-06).** 「이 화면에서는 …할 수 있습니다」류 설명을 두지 않는다. 다음 한 수를 버튼으로 보인다
6. 문장은 **명사형 종결** 우선(`저장됨` `증빙 14일 경과`). 외부 수령자 화면과 오류의 「다음 행동」만 `~해 주세요`체 허용
7. 용어는 앱 전체에서 하나: 지출결의(결의서 X) · 견적 줄(항목 X) · 실행가(원가 X) · 증빙(첨부 X) · 결재(승인 요청 X) · 지급 예정일 · 법인카드 사용 · 기타소득 확인증. 용어표는 `.planning/research/ERP260907-CONTEXT.md`의 업무 용어를 따른다
8. 숫자 앞에 「총」「약」을 붙이지 않는다. 합계 행이 합계다
9. 대소문자: 라틴 고유명사만 원문대로(`USD` `QR` `PDF`). 영문 버튼·라벨 없음

## 9. 아이콘

- 세트 **Lucide 하나**. 패키지 의존 없이 필요한 아이콘의 SVG를 `components/icons/`에 인라인으로 복사한다(ISC). 다른 세트와 섞지 않는다
- 크기 2단계: **16**(표·목록·버튼 안) · **20**(폰 하단 탭·시트 제목). `stroke-width: 1.75` 고정, `currentColor`
- 쓰는 곳은 **의미가 글자보다 빠른 곳만**: 첨부(paperclip) · 검색(search) · 닫기(x) · 메뉴(menu) · 정렬 방향(arrow-up/down) · 외부 링크(external-link) · 인쇄(printer). 상태·의미를 아이콘으로 전달하지 않는다 — 상태는 글자다
- 아이콘 단독 버튼은 `aria-label` 필수. 폰 하단 탭은 아이콘 없이 글자만
- 장식 아이콘(제목 옆, EMPTY 일러스트, 성공 체크) 금지
