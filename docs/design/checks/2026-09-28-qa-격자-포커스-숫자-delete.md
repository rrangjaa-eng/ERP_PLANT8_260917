# 묶음 ④ /qa — 격자 포커스 복귀 · 숫자 칸 Delete — 점검표
화면: ui/input/, ui/table/
기준: BRIEF.md · frontend.md 화면 사용성 원칙 · CHECKLIST.md §1 · SYSTEM.md §7-2(숫자 입력) · §7-3(표 키보드 · 붙여넣기)

변경 범위: /qa ISSUE-003(숫자 칸 쉼표 바로 앞 Delete가 캐럿 앞 숫자를 지움) · ISSUE-001(선택 칸 편집기가 change로 확정되면 포커스가 body로 빠짐) · ISSUE-002(붙여넣기가 기준 줄을 다른 그룹으로 옮기면 포커스가 body로 빠짐). 배치·모양·문구는 그대로다.

지금 화면 기준(고치기 전):
- `1|,500,000`에서 Delete → `500,000`(사용자가 지우려던 자리와 다른 숫자가 지워짐, 모르면 그대로 저장)
- 리저브 클라이언트·견적 거래처 칸에서 ↓(또는 마우스로 옵션)를 고르면 포커스가 `<body>` — 이어 누른 Ctrl+S가 격자에 닿지 않는다
- 새 줄에 붙여넣어 줄이 다른 클라이언트·대분류 그룹으로 옮겨 가면 같은 증상
