## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 개정문이 새로 정한 글자는 막힘 기안자 끝 줄(`결재할 사람 없음 · 회수 후 새로 신청`, 사용자 결정) 하나뿐, 설명문 없음
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 결재선 해석(지금 담당 · 담당 없음 · 막힘)은 서버가 하고 화면은 그리기만 한다고 §6-3에 적었다
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 행동 줄 = 서버 가능 행동 그대로, PC 행에 `회수` 없음(§6-1 개정문)
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 결재 시트 1차 `승인`(첫 포커스) 하나 + 2차(§7-8 개정문)
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 반려·회수는 확인(§7-17)을 거치고 PC 행 `승인`↔`반려` `--s-4` 간격(§6-1 개정문). 붉은 버튼은 두지 않는다(§7-1)
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: `내 결재` 행 상태 칸 비움(그룹 머리글이 말함) — §6-1 개정문
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 결재함 EMPTY는 기존 §7-7 그대로(`연차 목록 보기`), 이번 개정이 바꾸지 않음
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 시트·확인은 §7-17 네이티브 dialog(Esc · 포커스 트랩 · Ctrl+Enter), 결재함은 읽기 표라 편집 키 해당 없음
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 이동(처리함 행)은 링크, 시트 열기(내 결재 행)는 button — §6-1 개정문

## 사용자 결정(§1)
- [x] §1의 결정을 하나도 어기지 않았다(웜톤 · 견적 엑셀식 · 옆 패널 · 스킨 A …) — 근거: 옆 패널은 「한 건 등록 폼」 결정이고 결재 옆판은 옆 패널이 아니라고 명시(A3). 결재함 행 `승인` 즉시(사용자 결정) 유지
