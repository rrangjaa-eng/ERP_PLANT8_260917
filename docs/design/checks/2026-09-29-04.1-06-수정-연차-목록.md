지금 화면(고치기 전): 연말에 낸 다음 해 신청이 1월 1일 전까지 목록에서 보이지 않음(연도 위 끝 = 올해) · 지난해 행 날짜가 `09-29`처럼 연도 없이 올해 날짜와 구분 안 됨 · 폰 접힌 줄 `신청 MM-DD`를 눌러도 이동 안 함 · 권한 읽기 오류가 목록 전용 오류 화면이 아닌 상위 오류 화면으로 감.

## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 글자 추가 없음(날짜 표기 규칙과 연도 선택지만)
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 기본 연도는 여전히 올해, 다음 해는 신청이 있을 때만 선택지에 생긴다(사용자 결정 2026-09-29)
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 신청이 없는 미래 연도는 선택지에 없고 `?year`로 줘도 올해로 바뀐다(단위 resolveLeaveYear · E2E 연도 규칙 사례)
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 1차 `연차 신청` 규칙 불변(E2E 첫해 목록 · 신청 두 건 사례 통과)
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 위험 동작 없음(해당 없음)
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 연도는 여전히 한 자리(선택지가 둘 이상이면 select만 — 올해를 늘 선택지에 두어 다음 해를 볼 때도 select 한 자리)
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: EMPTY 변경 없음
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 접힌 줄 링크는 tabIndex -1(주 행 링크 하나만 초점), 주 행 Tab 순서 불변
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 주 행·접힌 줄 모두 같은 문서 링크
