## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 계정 그룹에 더한 것은 항목 이름 `연차` 하나뿐. 목록 글자 = 잔고 줄(값) · EMPTY 한 줄(`신청한 연차가 없습니다` + 다음 한 수) · 오류 한 줄(`연차 불러오기 실패` — 명사형, noun-style 테스트 통과). 설명문 없음. 신청 폼 글자 = 일수 힌트(`주말 N일 제외` / `재택 · 차감 없음`) · 잔고 행 · 결재선(값) · 막힘(`시작일 비어 있음 · 시작일 적기` — days.ts 상수) · 실패(`신청 실패 · 종료일 1칸` / `신청 실패 · 네트워크 · 다시 신청` — 명사형). 사람 상세 섹션 글자 = 라벨 · 값 · 힌트 `빼려면 -1처럼`(UI-SPEC S9 관리자 라벨) · 막힘 `사유 비어 있음 · 사유 적기` · 월차 거부 한 줄(04.1-03 문구 그대로) · EMPTY `연차 조정 기록이 없습니다`. 등록 폼 오류 `입사일 비어 있음 · 입사일 적기`
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 진입점 노출은 서버(layout allowedMenus)가 권한표로 정한다. 목록 연도 기본 = 올해(seoulToday), 연도 select 제어값 = 보는 연도(`—`로 열리지 않음), 잔고 줄은 서버 계산(formatBalanceLines). 폼: 종류 `종일` · 시간 DEFAULT_HALF_PERIOD 제어 기본값(E2E T1), 시작일을 고르면 종료일 자동(E2E T10), 일수 · 잔고 · 결재선은 서버 미리보기. 사람 상세: 섹션 연도는 서버가 한 번 정하고(퇴직자 = 퇴직 연도) 연차 조정은 그 연도에 자동 기록 — 연도를 묻지 않는다, 잔고 Select 처음 값 `연차`
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: `leave` view가 없으면 항목 자체가 없고 `/leave` 404(E2E). write가 없으면 머리 1차 · EMPTY 3차 `연차 신청`이 둘 다 없다(E2E CX-R5). 연도 옵션이 하나면 select 자체가 없다(T9 E2E). 폼: 필수 칸이 비면 1차 aria-disabled + 이유 + 그 칸으로 가는 3차, 제출 중 2차 `취소` aria-disabled(E2E). 잔여 초과는 막지 않는다(경고만, E2E toBeEnabled). 사람 상세: 월차 조정이 불가능하면 `월차` 옵션을 빼고(E2E 옵션 배열 `["연차"]`) 고른 월차는 연차로 돌아감, 보기만 권한이면 입력 · 조정 폼 없음(E2E)
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 1차 메뉴 다섯 · 하단 탭 넷 불변(단위 단언). 목록은 필터 줄 오른쪽 1차 `연차 신청` 하나 — 올해 0건이면 1차 대신 EMPTY 3차(E2E `연차 신청` 링크 1개). 폼은 1차 `연차 신청 Ctrl+Enter` 하나(2차 `취소 Esc` 오른쪽 끝). 사람 상세 연차 섹션은 1차 `연차 조정 추가` 하나(지난 연도 · 연차면 `{V} 연차 조정 추가` — 기록 연도를 버튼이 말한다, E2E)
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 위험 동작 없음 — 로그아웃은 여전히 계정 그룹 맨 끝, 목록 행에 행동 버튼 없음(행 = 문서 링크). 폼의 되돌릴 수 없는 일(입력 버리기)만 확인 모달(ui/confirm-dialog). 조정 기록은 추가만(수정 · 삭제 버튼 없음 — 틀리면 반대 부호로 한 줄 더)
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 진입점 한 자리. 연도는 부제 또는 select 한 자리(T9 E2E), EMPTY에 연도 없음. 합계 행 없음(A4 — 잔고 줄이 합계, E2E tfoot 0). 두 잔고 남음의 합 없음(E2E). 남은 중복: 상태 칸 글자가 그룹 머리글과 같은 낱말(단계 · 날짜 없음 — listMyLeave DTO에 단계 이름 · 처리일이 없다, SUMMARY 편차). 폼: 이번 신청 일수는 잔고 행 한 자리(E2E 폼 영역 `이번 신청` 1회), 힌트에 일수 없음. 사람 상세: 보는 연도는 `잔고` 옆 한 자리, 연도 select 없음
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 올해 EMPTY = `신청한 연차가 없습니다` + 3차 `연차 신청`, 지난해 EMPTY = + 3차 `올해 보기`(E2E). 로딩은 글자 없는 뼈대(300ms 지연 CSS 재사용). 폼은 빈 상태가 없다(§7-15). 조정 기록 0건은 한 줄 `연차 조정 기록이 없습니다`(행동 없음 — 바로 위 폼이 행동)
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: PC 사용자 메뉴의 방향키 이동에 항목 하나가 늘 뿐(keyboard-nav · user-menu · admin-nav E2E 녹색). 목록은 읽기 표 — 행마다 문서 링크(Tab · Enter), 연도는 네이티브 select. 폼: Ctrl+Enter 제출 · Esc 취소(입력 있으면 확인) · Enter 기본 제출 막음, 막힘 3차가 그 칸으로 포커스(E2E toBeFocused). 사람 상세: 날짜는 네이티브 날짜 칸(칸을 벗어나면 저장), 조정 폼은 Enter 제출
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: `연차`는 `내 정보`와 같은 link 항목. 목록의 이동(행 · `연차 신청` · `올해 보기`)은 전부 링크, 재시도만 button. 폼의 제자리 동작(막힘 다음 한 수 · 다시 신청 · 취소)은 button. 사람 상세의 연도 이동(`{V-1} 회계연도` · `올해 보기`)은 링크
