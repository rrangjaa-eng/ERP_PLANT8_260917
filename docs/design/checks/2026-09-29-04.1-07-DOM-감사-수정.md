## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 두 수정 모두 글자를 더하지 않는다(접힌 줄은 같은 `기안자 · MM-DD`, 잔고 줄은 같은 문자열을 숫자만 굵게)
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 입력·선택지 변경 없음. 접힌 줄을 눌러도 주 행과 같은 곳이라 어디를 눌러야 할지 고를 필요가 없어졌다
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 접힌 줄 대상은 주 행에 대상이 있을 때만(`내 결재` 시트 · `처리함` 문서 링크) — 그 밖의 행은 글자만
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 버튼 모양·수 변경 없음(접힌 줄 대상은 글자 모양 그대로, 관리자 섹션 1차 `연차 조정 추가` 하나 유지 — admin-person-leave 10/10)

- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 빈 화면 변경 없음(해당 없음)
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 접힌 줄 대상은 tabIndex -1 — Tab 순서는 주 행 대상 하나 그대로(`/leave` foldLink와 같음), 키보드 경로 변경 없음
