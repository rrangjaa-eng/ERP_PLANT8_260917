## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 새 문구 없음(잔여 초과 줄은 서버가 이미 만든 경고 한 줄을 결재함에도 보인 것), DOM 감사가 모든 막힘 · 오류 문구 명사형 확인
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 결재자가 문서를 열지 않고도 잔여 초과를 결재함 행에서 본다(PC 행 즉시 승인의 전제 — UI-SPEC S4)
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 행동 변경 없음, 잔여 초과는 막힘이 아니라 경고(1차 살아 있음 — UI-SPEC 309줄)
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 버튼 변경 없음(DOM 감사: 화면마다 1차 하나)
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 변경 없음, 잔여 초과는 `--warning`(막힘 `--danger`와 구분 — UI-SPEC 168줄)
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 폰에서 잔여 초과는 접힌 줄 하나만 보임(E2E `visible` 1개 단언)
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 변경 없음
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 새 상호작용 요소 없음(접힌 줄의 잔여 초과는 기존 탭 대상 안 글자)
