바꾼 것: 반려된 내 문서를 다시 신청하려고 열 때 결재선이 막혀 있으면(대표 없음) 화면 전체가 오류 경계로 떨어지던 것을, 신청 폼 미리보기(04.1-06 L3)와 같은 방식으로 결재선 자리에 막힌 이유 한 줄(`.blockedReason`)을 보여 주게 했다. 새 마크업·클래스·토큰 없음 — 신청 폼이 이미 쓰는 요소를 같은 자리에 쓴다.

## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 더한 문구는 막힘 한 줄 `대표 없음 · 관리자에게 대표 계급 확인 요청`(기존 도메인 상수, 신청 폼과 같은 글자) 하나, error-copy-noun-style 단위 테스트 통과
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 다시 신청 폼의 기본값(원래 신청 값) 그대로, 이번 수정은 입력을 더하지 않음
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 결재선이 막히면 제출 막힘 이유가 결재선 자리에 보인다(신청 폼과 같은 규칙) — 화면이 오류로 사라지지 않아 회수·다른 행동이 남는다
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: DocumentActions 행동 줄 변경 없음
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 행동 줄 변경 없음, 막힘 줄은 기존 `--danger` 문구 색(.blockedReason)
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 결재선 칸 안에 미리보기 대신 막힘 한 줄만(둘 중 하나)
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 해당 없음(빈 화면 아님), 변경 없음
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 새 상호작용 요소 없음(텍스트 한 줄)
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 새 행동 없음
