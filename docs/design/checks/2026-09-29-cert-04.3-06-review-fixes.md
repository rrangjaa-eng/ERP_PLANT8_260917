> 범위: 검토 L5(칸 없는 validationErrors → 확인 시간 지남 E3) · L7(재확인 뒤 동의 판이 바뀌면 동의 해제) · M2(주민등록번호 · 이름 자동 완성 끔) · 감사 N2(서버 칸 오류 → aria-invalid) · N3(`.consentFull` 64ch → `var(--measure)`) · F1(PC ≥700에서 `size="external"` 칸 라벨이 왼쪽으로 가던 것 → 위로).

- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 변화 없음 — 동의가 풀리면 막힘 이유가 `동의`를 다시 나열하고 1차가 비활성
