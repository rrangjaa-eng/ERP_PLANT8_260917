## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 새 문구는 잠김 한 줄 「정보 노출표 · 사람 정보 잠김」 하나(명사형, 마침표 없음, 링크·버튼 없음), 그 외 설명문 추가 없음
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 보이는 열은 서버가 보낸 DTO 키로 화면이 정한다, 사용자 선택 추가 없음
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: admin.people 쓰기 없으면 「사람 등록」 링크·?new=1 폼이 없다(test/unit/app/people-list-hidden-id.test.ts DR-6), 가려진 열은 그리지 않는다, 고를 사람이 0명이면 행동 로그 「사람」 칸이 없다(test/unit/app/action-log-filter-people.test.ts)
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 목록 머리글 「사람 등록」 하나(쓰기 권한이 있을 때만), 행 동작은 3차 「상세」「삭제」
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 「상세」↔「삭제」 간격 --s-4 이상(test/e2e/people.spec.ts DR-7 실측 · 폰 375에서 쌓여도 세로 간격 --s-4 이상)
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 이름이 가려지면 계급이 행 머리글이 되고 접힌 줄에서 같은 값을 다시 잇지 않는다(단위 테스트 접힌 줄 글자)
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 등록된 사람 없음 분기(「사람 등록」 action)는 그대로, 전부 가림은 보는 사람이 바꿀 수 없어 행동 없이 잠김 사실만(DR-4 사용자 결정, DECISIONS.md)
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 링크·버튼은 그대로 탭 이동, 요소 추가·제거 외 변경 없음
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 동작 칸 「상세」 링크·「삭제」 3차 버튼 구성은 그대로
