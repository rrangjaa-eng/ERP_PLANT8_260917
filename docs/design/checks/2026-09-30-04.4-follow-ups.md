## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 행동 로그 · 상태 화면은 새 문구가 없다(새 탭 안내 글자도 더하지 않았다). 사람 목록에서 새로 생기는 글자는 잠김 한 줄 「정보 노출표 · 사람 정보 잠김」 하나뿐이다(명사형·마침표 없음, 링크·버튼 없음 — 단위 테스트 「전부 가림」). 나머지 문구는 없다
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 행동 로그 필터는 고를 사람이 없으면 칸을 그리지 않는다. 열 보임은 투영된 DTO 키 유무로 시스템이 정한다. 사용자가 고를 것이 늘지 않는다
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 행동 로그 「사람」 필터는 id 없는 선택지가 없고 0명이면 칸째 숨긴다(action-log-filter-people 단위 테스트). admin.people 쓰기 권한이 없으면 「사람 등록」 링크와 ?new=1 폼이 없다(DR-6 단위 테스트). 가려진 열은 머리글·칸·접힌 줄 어디에도 그리지 않는다(DR-4 단위 테스트)
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 쓰기 권한이 있을 때 목록 머리글 「사람 등록」 하나가 그대로이고, 권한이 없으면 주 행동이 없다(보는 사람에게 다음 행동이 없으면 사실까지 — §8-3)
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 「상세」와 「삭제」 사이 gap --s-4를 .rowActions로 둔다(DR-7 E2E 1280 수치). 폰에서 줄바꿈되면 위아래도 --s-4(/review 지적 반영). 삭제 버튼 컴포넌트는 그대로다
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 접힌 줄은 보이는 P2 값만 잇고 값이 없으면 줄이 없다. 「—」 빈 열도 그리지 않는다(/review: 계급 이름이 가려진 계급의 「계급」 열도 — 단위 테스트 「계급만 가려진 계급」)
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 「등록된 사람이 없습니다 · 사람 등록」 분기는 admin.people 쓰기 권한이 있을 때 그대로이고, 없으면 행동 없이 한 줄이다(/review — 할 수 없는 선택지, DECISIONS.md 2026-09-30 사람 목록 항목). 잠김 줄은 보는 사람이 바꿀 수 없는 상태라 행동이 없다(DECISIONS.md 2026-09-21 보관함 예외에 이은 action 생략, 새 항목으로 기록)
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 링크·버튼 순서(상세 → 삭제)가 그대로다. 권한이 없는 계급에서는 탭 정지점이 줄어든다
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 밑줄 3차 링크 · 버튼 13개가 1px → hover 2px 한 규칙으로 맞춰졌다(tertiary-underline-css 스윕 단위 테스트). /review D1(사용자 결정 2026-09-30): §4-4 offset도 var(--underline-offset)로 같은 스윕이 검사한다(없던 4곳 + 토스트 2px 리터럴). 「실행 기록」 링크는 마크업 위치 · className이 그대로이고 target/rel만 더했다. 「상세」 링크 · 삭제 3차 버튼의 className·구조를 바꾸지 않고 span으로 감쌌다
