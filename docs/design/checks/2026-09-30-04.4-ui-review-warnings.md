## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: page.tsx에서 문구를 더하지 않았다. id가 없는 행의 동작 칸은 자리 문구 없이 빈 칸이다
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 이번 변경은 결정 요소를 더하지 않고, 갈 곳이 없는 링크를 없앨 뿐이다
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: person.value가 꺼져 id가 없는 행은 「상세」·삭제 버튼을 숨긴다(단위 테스트 test/unit/app/people-list-hidden-id.test.ts)
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 목록 머리글 「사람 등록」 하나가 그대로다
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: PersonDeleteButton의 props·className·위치를 바꾸지 않았다. id가 있는 행에서만 그린다
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 새 글자가 없다
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 빈 목록의 ListEmpty 분기를 건드리지 않았다
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 링크·버튼은 그대로이고 id가 없는 행에서만 탭 정지점이 줄어든다(깨진 링크가 없어진다)
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 「상세」 링크·삭제 버튼의 className·구조를 그대로 두었다
