## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 더한 글자는 버튼 라벨 `인쇄` 하나와 잠김 이유 `저장 안 한 칸 {N} · 먼저 저장`(명사형 · 부정 접두 없음 — SYSTEM §8 규칙 5, D-7)뿐이다. 이유는 고친 칸이 있을 때만 선다. 인쇄 차단 한 줄(04.3-07)은 그대로이고 이제 그 줄이 가리키는 버튼이 있다(L8 해소)
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 사용자는 「인쇄」만 누른다. 새 탭 주소 · 인쇄 창은 시스템이 연다. 저장 안 한 칸 수 N은 04.3-07의 `changedCount` 그대로(시스템이 센다)
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 고친 칸이 있으면 「인쇄」는 `ui/button`의 `disabled` + `disabledReason`(렌더는 `aria-disabled`, 클릭은 컴포넌트가 막는다) — E2E가 `aria-disabled="true"` · 이유 전체 일치 · 눌러도 탭 수 불변을 단언. 저장하면 다시 켜진다
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 1차는 「고친 내용 저장」 하나 그대로. 「인쇄」는 머리의 2차(테두리)라 주 버튼이 둘이 되지 않는다
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 해당 없음 — 인쇄는 읽기 동작(저장된 값을 가린 번호로 찍을 뿐, 전체 번호 복호화 없음). 잠김 이유는 `reasonTone` 기본 `block`(UI-SPEC Color 「I4 「인쇄」 = block」)
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 머리는 제목 · `제출됨` 태그 · 부제 · 「인쇄」 각 한 번. 아이콘은 `aria-hidden`이고 글자 `인쇄`가 이름이다(아이콘과 글자가 같은 뜻을 한 번만 전한다)
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 해당 없음 — I4에 빈 상태 없음
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 머리의 「인쇄」는 `ui/button`이라 Tab · Enter로 눌리고, 비활성 때도 `aria-disabled`라 탭 순서에 남아 이유(`aria-describedby`)를 읽는다. 문서 순서상 제목 다음 첫 조작
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 새 탭을 여는 행동이지만 「인쇄」는 이동이 아니라 종이를 만드는 행동이라 버튼이다(`ui/button` 2차 — 이 화면의 다른 행동과 같은 부품). 링크 아님
