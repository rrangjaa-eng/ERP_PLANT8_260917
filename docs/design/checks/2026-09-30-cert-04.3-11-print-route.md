## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 화면에 보이는 글자는 템플릿 칸 이름 · 값뿐이고 설명문이 없다. 남은 한 줄 둘은 ERROR `인쇄물 만들기 실패 · 다시 시도`(화면)와 인쇄 미디어 전용 `인쇄물이 아직 준비되지 않았습니다 · …`(서명 없는 종이가 나가지 않게 — 화면에서는 늘 숨음). 확인 문장 `위 금액을 기타소득으로 …`은 §6-6 확정 템플릿 문장
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 사용자가 고를 것이 없다 — 열리면 서버가 저장된 값을 채우고 서명 decode가 끝나면 스스로 인쇄 창을 부른다. 출력 시각 · 가린 번호 · 전화 표시형 · 날짜 형식은 서버가 만든다
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 서명이 없거나 decode가 거부되면 본문(`.sheet`)을 렌더하지 않고 ERROR만 세운다. 준비 전 · ERROR 때 브라우저 인쇄는 CSS(`.root:not([data-ready]) .sheet { display: none }`)로 본문을 숨긴다 — E2E가 인쇄 미디어 본문이 준비 전 한 줄뿐임을 단언
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 정상 상태는 버튼이 없다(자동 인쇄). ERROR 때만 2차 「다시 시도」 하나(1차 없음 — 재시도는 주 행동이 아니라 복구)
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 해당 없음 — 읽기 전용 종이, 삭제 · 되돌릴 수 없는 동작 없음. ERROR 줄은 `--danger`
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 템플릿이 칸마다 한 번만 그린다(제목 · 번호 · 수령자 이름은 서명 줄 `수령자` 블록에 한 번). 원천징수 내역 2행과 한글 금액 줄은 값에서 파생되는 줄이라 렌더하지 않는다
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 해당 없음 — EMPTY 없음(UI-SPEC 다섯 상태). 서명 누락은 빈 화면이 아니라 ERROR + 「다시 시도」
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 표 없음 · 입력 없음. 「다시 시도」는 `ui/button`(탭 순서 · Enter). 인쇄는 자동
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 행동은 「다시 시도」 하나(`ui/button` 2차) — error.tsx와 ERROR 상태가 같은 모양

## 시스템
- [x] 새 색·서체·radius·그림자를 만들지 않았다(tokens.css 변수만) — 근거: `print-cert.module.css`는 `var(--…)`만(`grep -nE "#[0-9A-Fa-f]{3,6}\b"` 0건). 실물의 미리보기 리터럴 두 값(`#E9ECEA` · `#CFD3D0`)은 옮기지 않았다(개정 ⑬ — 바탕 `--surface`, 외곽 `1px --line`, 인쇄 미디어에서는 외곽 없음). 서명은 `filter: brightness(0)`(새 색 없음). mm 치수(210×297 · 여백 22/22/20 · 서명 64mm)는 실물 값 그대로(색 · 서체 · radius 아님)
- [x] 폰 320에서 가로 넘침 없음 · 터치 44px — 근거: 이 라우트는 A4 인쇄물이라 폰 레이아웃 대상이 아니다(UI-SPEC P1에 폰 규칙 없음 — 새 탭으로 PC에서 열려 인쇄한다). ERROR 줄은 flex-wrap으로 줄바꿈, 「다시 시도」는 `ui/button` 44px(폰). 폰 실측은 독립 DOM 감사 몫
