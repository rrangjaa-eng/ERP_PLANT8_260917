# 결재선 단계 저장 후속(Codex P2 r4141687057 · r4141687065) — 점검표

기준: BRIEF.md · frontend.md 화면 사용성 원칙 · CHECKLIST.md §1 · SYSTEM.md §7-2 · DECISIONS 2026-09-30

지금 화면 기준으로 어긋나 있던 것:
- ① 저장 안 한 단계가 있을 때 브라우저 뒤로 · 앞으로(앱 안 이동)는 링크 누름도 문서 이탈도 아니라 `입력 버리기` 확인 없이 초안이 사라진다 → 같은 확인 창으로 막는다.
- ② 화면이 단계 네 칸의 저장값을 키마다 따로 읽는다 — 그 사이 다른 저장이 커밋되면 한 번도 저장된 적 없는 섞인 결재선이 기준값(base)이 되고, 다음 저장이 헛 거부된다 → 단계 칸 전부를 한 문장으로 읽는다.
