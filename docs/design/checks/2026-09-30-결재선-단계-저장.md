# 결재선 설정 단계 저장(사용자 결정 2026-09-30 A) — 점검표
화면: app/(app)/admin/settings/, docs/design/SYSTEM.md, docs/design/DECISIONS.md
기준: BRIEF.md · frontend.md 화면 사용성 원칙 · CHECKLIST.md §1 · SYSTEM.md §7-1 · §7-2 · DECISIONS 2026-09-30

지금 화면 기준으로 어긋나 있던 것(PR #90 Codex r4137164384 · 결정 요청 5896711045):
- ① `연차 결재선` 섹션의 단계 네 칸(사용 · 담당 계급 · 조직 범위 · 특정 부서)이 칸마다 즉시 저장된다 — 두 칸을 바꾸는 사이의 중간 결재선이 잠깐 유효하고 그 사이 제출된 문서에 굳는다 → 단계마다 네 칸을 화면에 모아 두고 `N단 저장`(2차) 하나로 한 트랜잭션.
- ② 칸의 비활성(사용 꺼짐 · 범위가 특정 부서 아님)은 서버가 저장값으로 계산한다 — 저장 전 값을 바꿔도 칸이 그대로라 저장해야만 뜻이 보인다 → 화면의 지금 값으로 바로 켜고 끈다(같은 조건 목록을 서버가 넘긴다).

## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 새 글자는 버튼 `N단 저장`, 비활성 이유 `바뀐 칸 없음`(§7-1 UX-06이 이유 없는 비활성 버튼을 금지 — info 색), 오류 `다른 저장이 먼저 됨 · 새로 고침` · `결재선 단계 칸 단독 저장 불가 · 단계 저장으로`(명사형, 단위 error-copy 스캔 통과). 섹션 글자 전수는 독립 DOM 감사 ⑥(87줄 중 새 글자는 두 가지뿐). `바뀐 칸 없음` 네 줄 반복은 사용자 결정 A의 결과라 기록만(design 리뷰 참고)
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 칸 초기값 = 저장값 그대로, 값이 없는 3단 부서는 결재선 로더처럼 빈 값으로 저장(통합 「3단 특정 부서 행이 없어도」). 손대지 않은 단계는 다른 저장 뒤 새 값을 따라가 사용자가 새로 고칠 필요 없음(E2E 「손대지 않은 단계는」)
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 사용 끔 → 계급·범위·부서, 범위 ≠ 특정 부서 → 부서가 저장 전 화면 값으로 바로 비활성(E2E 1단 · DOM 감사 ② ③ — --faint on --surface, opacity 1). 바뀐 칸이 없으면 `N단 저장` aria-disabled + 이유
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 설정 화면에 1차 없음(그대로). `N단 저장`은 2차 — 바뀐 단계의 것만 켜져 다음 행동이 그 하나로 보인다(DOM 감사 ② — 켜진 버튼만 이유 줄 없음)
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 삭제 · 되돌릴 수 없는 동작 없음(해당 없음). 오류 줄은 --danger(`.error` 기존 규칙)
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 오류가 뜨면 이유 줄은 없다(Button은 비활성일 때만 이유를 그림 — 거부 뒤 버튼은 켜진 채 오류 한 줄만, E2E 「다른 관리자가 2단을 먼저」). 경고는 초안과 맞지 않으면 숨겨 저장값 · 화면 값이 섞이지 않음
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 빈 상태 없음(설정 키는 늘 있다) — 해당 없음
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: DOM 감사 ④ — 2단 계급에서 방향키로 바꾸고 Tab 2번(범위 → 2단 저장, 비활성 부서 건너뜀) · Enter로 저장, 새로 고친 뒤 값 확인. 오류 줄은 role=alert + 버튼 aria-describedby
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 네 단계 모두 같은 2차 `N단 저장`(ui/button), 설정 내보내기와 같은 2차 모양. 칸 마크업 · 클래스는 기존 SimpleFieldEditor와 같다
