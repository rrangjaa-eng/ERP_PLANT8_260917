# 04.3-14 수집 안내 v3 · 개인정보 화면 세션 · 접속기록 — 점검표
화면: app/c/[token]/, app/(app)/certs/submissions/[id]/, app/(app)/certs/events/[id]/, app/print/certs/[id]/, app/(auth)/login/, app/(app)/admin/action-log/
기준: BRIEF.md · frontend.md 화면 사용성 원칙 · CHECKLIST.md §1 · SYSTEM.md §6-5(E′4 수집 안내) · §6-6(인쇄) · §6-7(로그인) · 04.3-14-PLAN 「수집 안내 v3 문구」(카피 계약) · UI-SPEC 「개정 (2026-10-01 결정 확정)」

지금 화면(실행 전): E4는 v2 「개인정보 수집·이용 동의」 체크 · 요약 · 전문(문장이 화면 파일 `consent-block.tsx`에 있고 전문은 `<p>` 나열 · 제목과 본문 사이 ` · `) · 막힘 이유 낱말 `동의` · I4 줄 `동의 · 동의함 · {일시}`. I4 · 인쇄는 조회 기록이 없고(I3 「제출 내용」 링크는 04.3-17이 이미 `prefetch={false}`), 비활동 한도 120분(10~120) · 평문 가림이 그 설정을 따르며, 끊기면 이유 없이 `/login`으로 가고 다시 로그인하면 `/account`다. I3(`app/(app)/certs/events/[id]/`)는 이 플랜이 고치지 않는다 — 미리 가져오기 회귀를 E2E로 고정만 한다.

반영 라운드(독립 검토 Y1~Y6 · 사용자 결정 5936870579, 2026-10-01): 행동 로그(`app/(app)/admin/action-log/`)의 「정리」 건수가 접속기록 셋(`cert_view` · `mask_reveal` · `cert_correct`)을 세지 않는다(서버도 표시하지 않음 — 그 종류만 거르면 0건이라 기존 비활성 「정리할 행이 없습니다」). I4 · 인쇄의 무입력 부품(그리는 것 없음)이 라우터 캐시 복원 · 뒤따르는 활동 기록을 다룬다. 인쇄가 서버 판정으로 끊겨도 `next=`는 I4. 새 문구 · 버튼 · 색 없음.

## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 새 문장은 카피 계약 줄뿐이다 — E4 체크 라벨 · 요약 · 전문 8절은 v2를 대신하는 법령상 고지(개인정보 보호법 제22조제3항 · 제24조의2 — 사용자 결정 ①, 문장 정본 `domain/certs/consent.ts`)로 늘어난 줄 수가 없고, 로그인 화면 이유 줄 `개인정보 화면 · 다시 로그인`(명사형 · 잠김 상태) 하나. 기록 실패는 새 문구 없이 기존 오류 경계(`app/(app)/error.tsx` · 인쇄 오류 경계 — G0 DR-13). 무입력 이동 부품은 그리는 것이 없다
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 접속지 IP · 조회 기록은 서버가 요청 헤더에서 정한다. 끊긴 뒤 다시 로그인하면 원래 보던 I4 · 인쇄로 시스템이 돌려보낸다(`next=` — U5 a). 평문 가림 3분은 고정값(결정 ③). 안내의 보존 연수 · 문의 전화는 행사 판에서 채운다
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 볼 수 없는 사람은 지금처럼 404(조회 기록 0줄 — 통합 `cert-access-log`). 한도를 넘긴 개인정보 화면은 열리지 않고 로그인 화면으로 간다(첫 접근 판정 — E2E). E4 1차는 안내 확인 체크 전까지 막힘(지금 규칙 그대로)
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 버튼을 더하거나 바꾸지 않는다 — E4 1차 「확인증 제출」 · 로그인 1차 「로그인」 그대로. 「전문 보기」는 3차
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 위험한 동작을 더하지 않는다
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 전문 1절은 `PLANT8 · 경영관리 {문의 전화}` — 「문의」 · 「PLANT8」 중복 제거(G9 a), 절 제목과 본문 사이 ` · ` 없음(G0 DR-7). 로그인 이유 줄은 비밀번호 변경 줄과 함께 뜨지 않는다(reason 값이 하나)
