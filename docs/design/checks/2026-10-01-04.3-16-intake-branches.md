- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 경품 빠짐 · 안내 바뀜 뒤에도 이름 · 주민등록번호 · 연락처 · 서명을 남기고 주소만 버린다(전달 방식이 바뀌었을 수 있다) — 다시 적을 것을 최소로. 새 멱등 키 · 결과 불명의 같은 키는 시스템이 정한다
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 경품이 빠지면 목록에서 그 행이 사라지고, 경품이 0이면 E6-d에 1차 · 입력 · 목록을 세우지 않는다. 열리기 전(E6-e)에도 1차 · 입력 · 목록 없음
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: E′2는 1차 없음(행 = 행동) · E′4는 1차 「확인증 제출」 하나(바뀐 것 없음) · E6-b · d · e는 1차 없고 문의 전화 3차 `tel:`만
