# 04.6-01 결정 기록 · SYSTEM 개정 · 역할 토큰 두 단 — 점검표
화면: docs/design/DECISIONS.md, docs/design/SYSTEM.md, docs/design/tokens.css, docs/design/SKIN-EXPLORE.md
기준: BRIEF.md · frontend.md 화면 사용성 원칙 · CHECKLIST.md §1 · SYSTEM.md §0 · §1-4 · §2-2 · §3 · §4 · §6-3 · §7-8 · §7-20

이 작업은 문서·토큰만 바꾼다(CSS 모듈·TSX 변경 없음). 옛 토큰 이름은 옛 값 그대로라 아직 옮기지 않은 화면의 모양은 이 작업에서 바뀌지 않는다.

## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 화면 문구를 바꾸지 않았다. SYSTEM §6-1 「목록 부제 없음」 · §7-20 `ListScreen` 「부제 prop 없음」으로 설명문을 줄이는 방향만 문서에 적었다
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: UQ-1·2·3·6·7·Q1은 사용자 답(04.6-ANSWERS.md)을 인용만 했고 다시 묻지 않았다. `--field-h`는 기본 `--control-h`를 따르고 옆 패널 틀이 덮는다(칸마다 높이를 적지 않는다)
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: SYSTEM §7-20 `ListScreen`에 「빈 목록이면 머리 1차를 숨기고 빈 화면 버튼 하나」(DR5 A)를 적었다
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: SYSTEM §7-20 틀마다 1·2·3순위 한 줄(1차는 틀마다 하나), §7-8 옆 패널은 뒤를 막아(`inert`) 한 화면 1차 하나를 지킨다
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: SYSTEM §7-19 `RowActions`의 `danger`는 맨 끝 `--s-8` 간격 + `--status-danger` 글자, DECISIONS 2026-10-02 「삭제 행동 링크」
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 상태 낱말→색 표를 `ui/status-tag/status-map.ts` 한 곳으로 적었다(§7-5). 같은 사실을 SYSTEM 두 절에 되풀이하지 않고 §7-18~20은 기존 절을 가리킨다
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: SYSTEM §7-7 「빈 화면」 = 한 줄 + 첫 행동 버튼 하나(2차 버튼 모양)
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: SYSTEM §6-3 옆 패널 배치에 DOM·Tab·시각 순서 「취소 Esc → 1차」 · `Ctrl+Enter`, §7-3에 편집 표 키 동작 불변을 적었다(견적 줄 입력은 옆 패널·모달에 쓰지 않는다)
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: SYSTEM §7-19 행 안 행동은 링크이든 버튼이든 같은 모양, §4-4 3차 버튼·행동 링크가 같은 밑줄 규칙(`--underline-w-hover`)

## 사용자 결정(§1)
- [x] §1의 결정을 하나도 어기지 않았다(웜톤 · 견적 엑셀식 · 옆 패널 · 스킨 A …) — 근거: 웜톤 금지는 `tokens.test.ts` ①이 모든 `--surface-*`·`--n-*`의 R ≤ G · R ≤ B를 단언(통과). 견적 줄은 옆 패널·모달 금지를 §6-3·§7-8에 유지. 옆 패널(PC 오른쪽 480·폰 아래 시트)·스킨 A 값은 UI-SPEC 표 그대로. 팝업·모달·옆 패널 구분은 SKIN-EXPLORE §6 표를 §7-8로 옮겼다

## 시스템
- [x] 새 색·서체·radius·그림자를 만들지 않았다(tokens.css 변수만) — 근거: 새 hex는 UI-SPEC 「1단 원시 값」 표(기준 CSS 출처)와 기존 값뿐이다. 역할 토큰 값은 전부 `var(--원시)`이고 `tokens.test.ts` ⑤가 미정의·순환·옛 이름 참조를 막는다
- [x] 폰 320에서 가로 넘침 없음 · 터치 44px — 근거: 해당 없음(화면 코드 변경 0). 폰 값 `--text-body` 15 · `--panel-pad-x` `--s-4`만 문서·토큰에 적었고 화면 적용은 04.6-04·07. 터치 44(`--touch-min`) 값은 그대로
- [x] 실제 앱 화면(PC 1280 · 폰 390)을 찍어 보고 확인했다 — 스크린샷 경로: 해당 없음(화면 픽셀 불변). 옛 이름 옛 값 보존을 `tokens.test.ts` ⑥ 27개 단언으로 확인했다. 화면 사진 비교는 04.6-13 · 25
