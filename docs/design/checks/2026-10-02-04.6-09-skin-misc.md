# 04.6-09 알림·목록 보조·권한 격자·인증 틀 스킨 A — 점검표
화면: ui/toast, ui/banner, ui/pagination, ui/kv-list, ui/history-list, ui/approval-route, ui/next-turn, ui/permission-grid, ui/auth-frame
기준: BRIEF.md · frontend.md 화면 사용성 원칙 · CHECKLIST.md §1 · SYSTEM.md §4 · §7-4 · §7-6 · §7-11 · §7-13 · §7-14 · §7-16 · 공통 §4

이 작업은 아홉 컴포넌트 CSS 모듈을 스킨 A 역할 토큰으로 옮긴다(이관 전 표시 뗌). 마크업·문구·동작은 바꾸지 않는다. 지금 화면 기준 어긋남: 토스트·배너 2px 진한 선 + radius 0, 이력 목록·내 차례 머리 2px 선, 권한 격자 원시 `--g-*` 직접 참조, 모두 옛 이름(`--bg` `--fg` `--muted` `--line*` `--fs-*` `--danger` `--warning` `--row-min`).

## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: CSS 파일만 바꿨다. TSX·문구 변경 0(`git diff --stat -- ui`에 `.module.css`만).
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 해당 없음(입력·동작 변경 0). 이력 목록 편집 행 컨트롤 높이 `--control-h`(PC 32 · 폰 40) 그대로.
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 해당 없음(마크업·동작 변경 0). 권한 격자 `.errorCell`·`.delayed` 상태 표시 선택자 그대로, 색만 역할 토큰(`.errorCell`은 1px 링 → 역할 토큰 `--inset-error` 왼쪽 2px 선, 05-07 표 오류 셀과 같은 모양).
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 해당 없음(버튼 구조 변경 0). 내 차례 「다음 한 수」 3차 링크 모양 그대로.
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 위험 색은 역할 토큰 `--status-danger`(오류 셀은 `--inset-error` · 이력 목록 오류 · 결재선 반려 끝줄 · 페이지 줄 오류 수)로만 옮겼다. 위치 변경 0.
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 해당 없음(문구 변경 0).
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 해당 없음(빈 화면 컴포넌트 `ListEmpty`는 04.6-05 · 07 소유).
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 해당 없음(동작 변경 0). 권한 격자 체크박스 `accent-color`·크기 그대로.
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 토스트 「되돌리기」·페이지 번호·내 차례 다음 한 수 모두 글자 `--text-link` + 밑줄 1px → hover `--underline-w-hover`(2px)로 같은 모양(공통 §4).
