## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: CSS 한 규칙만 더함, 문구 변경 없음
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 정렬 순서 기본값·타입 기본값 그대로(변경 없음)
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 변경 없음(선택지 0개면 1차 aria-disabled + 이유, 04.5 DOM 감사 E2)
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: DOM 실측 ?new=1·?editId= 320·375·768·1280 모두 primary 1개
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 변경 없음(행 「삭제」는 기록된 예외 DeleteToArchive)
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 변경 없음
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 변경 없음(ListEmpty 「화면 항목 추가」)
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: Tab 순서 이름→타입→필수→정렬 순서→1차→취소, 이름 칸 Enter로 등록 완료 실측
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 체크박스 크기를 거래처 폼 .clearRow input·설정 화면 체크박스 줄(44)과 맞춤
