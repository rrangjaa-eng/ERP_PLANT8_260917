## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 권한표·노출표의 목록 부제 「계급 × 메뉴 × 동작」·「계급 × 정보 항목」을 뗐다(`ListScreen`에 부제 자리가 없다). 관리 인덱스는 설명문이 원래 없고 배너(이메일 실패 · 공휴일 확정)는 판정 함수가 정한 상태 줄 그대로. 로그인의 「비밀번호가 바뀌었습니다. 다시 로그인하세요.」·「개인정보 화면 · 다시 로그인」은 상태 안내이고 문구·자리 그대로(Q18)
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 권한 격자는 셀 하나가 곧 저장(일괄 저장 없음)이고 로그인은 `next`를 `safeLoginNext`가 정한다. 이 플랜은 입력·기본값을 바꾸지 않았다
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 관리 인덱스는 `adminIndexGroups`가 권한 없는 항목을 아예 빼고 볼 항목이 0이면 404(`withCertMenusGated` 흐름 그대로). 권한표·노출표는 `readPermissionGrid`·`readVisibilityGrid`의 ForbiddenError → 404 그대로
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 관리 인덱스·권한표·노출표는 1차 버튼이 없는 이동·편집 화면(목록 머리 `primaryAction` 없음 — 원칙 막는 모드 테스트가 1차 ≤ 1 확인). 로그인은 「로그인」 1차 하나
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 해당 없음 — 이 네 화면에 삭제·되돌릴 수 없는 행동이 없다(격자 셀 토글은 다시 눌러 되돌린다)
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 제목 하나(`ListScreen` h1)와 표 caption(스크린 리더용)만 있고 부제를 뗐다. 그룹 머리글과 항목 링크 라벨은 서로 다른 말(마스터 / 사람 …)
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 해당 없음 — 세 화면은 항상 내용이 있다(그룹 0이면 404, 격자는 계급·열이 시드로 항상 있다)
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 인덱스는 네이티브 링크 Tab·Enter, 격자는 `ui/permission-grid`(04.6-09 스킨 · 체크박스 Space) 그대로, 로그인은 Enter 제출
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 인덱스 항목은 모두 같은 `.link` 행, 배너 안 링크는 공용 3차 링크 모양(밑줄 1px → hover `--underline-w-hover`)
