## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 문구 변경 없음. CSS 한 규칙만 바꿨다
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 줄바꿈 여부는 CSS flex-wrap이 폭으로 정한다(JS 폭 감지 없음, 서버 렌더부터 같다)
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 해당 없음(변경 없음)
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 행 안 행동 링크 모양만 다룬다, 해당 없음
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 한 줄일 때 「삭제」 앞 간격 --s-8(= 사이 --s-4 + 여백 --s-4) 그대로(1280 · 375 · 320 project_status 실측 32px). 위험 색 규칙 미변경
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 해당 없음(변경 없음)
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 해당 없음(변경 없음)
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: DOM 순서·포커스 대상 불변
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 링크·버튼 공통 .action 규칙 불변
