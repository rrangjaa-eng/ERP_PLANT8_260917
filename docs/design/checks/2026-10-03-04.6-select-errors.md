## 원칙
- [x] 안내 문구: 새 문구 없음. 서버 검증 문구(「계급 필요 · 계급 선택」 등 명사형 한 줄)를 칸 아래와 행동 줄 이유에 그대로 보인다 — 근거: 액션 스키마 원문
- [x] 결정 최소: 사용자가 할 일이 늘지 않는다 — 근거: 비운 칸에 빨간 테두리와 한 줄이 생길 뿐
- [x] 같은 말을 두 번 하지 않는다 — 근거: 칸 아래 한 줄 + 행동 줄 이유는 프로젝트 등록 패널과 같은 기존 패턴(`Select error` + `reason`)
- [x] 새 색·서체·radius 없음 — 근거: `.selectInvalid`는 거래처 폼과 같은 `--status-danger` 한 줄

## 시스템 (DOM 실측)
- [x] 세 패널 빈 select 제출 뒤 `aria-invalid="true"` · `aria-describedby` 오류 줄 · 제출 버튼 설명에 칸 이름 · 패널 열림 — 스펙: test/e2e/panel-select-errors.spec.ts (CI=true 빌드, 수정 전 3건 실패 → 수정 후 통과)
- [x] 테두리 색 = `--status-danger` 계산값 · 오류 줄 색 동일 — 근거: 실측 select 테두리 rgb(155, 28, 28) = 토큰 rgb(155, 28, 28), 오류 줄도 rgb(155, 28, 28) (세 칸 × 320 · 375 · 1280)
- [x] 오류 문구 — 근거: 「계급 필요 · 계급 선택」 · 「본부 필요 · 본부 선택」 · 「소지자·팀 중 하나 필요 · 하나만 선택」(서버 원문, 명사형 한 줄)
- [x] 폰 320 · 375 가로 넘침 0 — 근거: 문서 scrollWidth − clientWidth = 0, 패널(dialog) 0 (세 패널 × 320 · 375 · 1280)
