- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 행동 없는 표시 컴포넌트, 해당 없음(변경 없음)
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 해당 없음(변경 없음)
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 글자는 status 하나(옛 children 경로 삭제로 글자 출처가 하나)
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 해당 없음(변경 없음)
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 정적 span, 포커스 대상 아님(변경 없음)
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 해당 없음(변경 없음)
