## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 설명문 추가 0. 더한 것은 결재선 단계 결과 낱말 `본인 승인` 하나(SYSTEM §7-5 B2 의미 목록 낱말 그대로)
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 낱말은 서버 단계 값 selfApproved에서 매핑 함수가 정한다. 사용자 입력 없음
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 행동 추가 없음(표시 낱말만). 표 밖 낱말은 StatusWord 타입 오류로 넘길 수 없다
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 버튼 변경 없음(결재선 목록 결과 칸 글자만)
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 해당 없음(위험 동작 변경 없음)
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 결과 칸은 `본인 승인 MM-DD HH:mm` 한 번 — 글자(leaveStatusDisplay)와 배지 낱말(leaveStatusWord)이 같은 낱말 하나에서 나온다
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 해당 없음(빈 화면 변경 없음)
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 정적 글자, 포커스 대상 추가 없음
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 행동 추가 없음
