## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 설명문 추가 0. 더한 글자는 결재선 결과 낱말 `본인 승인`(SYSTEM §7-5 B2) · 종류가 주는 `승인` 막힘 이유 한 줄(잠김 — Button disabledReason 자리) · 최종 승인 토스트 꼬리(종류 요약 finalNote)뿐. 연차 결재함 · 확인 창 · 토스트 글자는 그대로(`연차 반려` · `연차 회수` · `승인 · 최종 승인 · 2일 차감`)
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 숫자 열 머리글(금액 · 일수 · 둘 다)은 서버 measureHeader가 정하고, 숫자 칸 서식은 Num이 맡는다. 사용자 입력 추가 없음
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 종류가 막힘 이유를 주면 시트 `승인`은 aria-disabled + 이유(reasonTone block), `반려`는 그대로 산다. 숫자 없는 목록(measureHeader null)은 숫자 열을 통째로 그리지 않는다(빈 머리글 th 없음)
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 시트 1차 `승인` 하나 그대로(콜백 prop으로 바꿨을 뿐 마크업 · 순서 불변)
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 반려 · 회수는 2차 · 확인 창 그대로(액션만 종류 중립 withdrawAction으로)
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 문서 칸 `{종류} · {대상}` · 숫자 칸 · 부제의 조각은 서버 요약 하나에서 나오고 서로 겹치지 않는다(04.1 순서 그대로)
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 빈 결재함(ListEmpty) 변경 없음
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 포커스 대상 추가 없음. 막힌 `승인`은 aria-disabled라 탭 순서에 남고 이유를 aria-describedby로 읽는다(Button 계약)
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 행동 모양 변경 없음(PC 행 3차 승인 · 반려, 시트 2차 · 1차 그대로)
