## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 복원 줄 글자(`저장 안 한 편집 N단`) · 버튼(`복원` · `버림`) · 알림(`편집을 버렸습니다` · `되돌리기`) 그대로. 글자 추가 0, 바뀐 것은 줄이 뜨는 섹션뿐
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 고치기 전에는 연차 보관본이 지출결의 섹션에도 떠 사용자가 「이 줄이 어느 결재선 것인가」를 판단해야 했다. 이제 줄이 그 단계가 있는 섹션에만 떠서 그 판단이 없다
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 보관본이 없는 섹션의 복원 줄(누르면 다른 섹션을 바꾸던 버튼)을 숨겼다
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 버튼 모양 · 개수 변경 없음
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: `버림`은 확인 없이 지우고 되돌리기(C-1) 그대로, 이제 그 섹션 보관본만 지운다
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 두 섹션에 같은 줄이 겹쳐 뜨던 중복이 사라졌다
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 해당 없음(빈 화면 없음)
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 복원 뒤 초점은 되살린 첫 단계의 첫 칸(기존 규칙), Tab 순서 변경 없음
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 행동 모양 변경 없음
