# 05-08 지출결의 목록 — 점검표
화면: app/(app)/expenses/
기준: BRIEF.md · frontend.md 화면 사용성 원칙 · CHECKLIST.md §1 · SYSTEM.md §6-1(목록 = 원장) · §7-3(폰 열 접기) · UI-SPEC S8

지금 화면(고치기 전): `/expenses`는 04.6-19 자리 화면 — `ListScreen title="지출결의"` + `ListEmpty` 한 줄(`등록된 지출결의가 없습니다 · 법인카드 보기`)뿐이다. 문서가 있어도 목록이 없고, 빈 화면의 다음 한 수가 엉뚱한 화면(법인카드)으로 간다. 새 지출결의로 가는 1차 · 상태 보기 · 합계 줄 · 페이지가 없다.

## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 화면 글자는 제목 · `상태` 라벨 · 합계 줄 `합계 (진행 중 · N건)` · 열 머리글 · 그룹 머리글 · 행 값뿐이고 설명문 `<p>`는 0(list-lead-1280.png · list-pm-390.png). 빈 화면 셋은 UI-SPEC Copywriting 그대로 `… 없습니다 · {다음 한 수}` 한 줄. design-principles 막는 모드(`/expenses` sysadmin 포함, desktop 25 passed) 통과.
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 보기 기본값 `진행 중`(내 손이 필요한 문서), 그룹 · 그룹 안 순서 · 합계(공급가액 원화 합, 보기 전체) · 상태 낱말 `{단계} 결재 중`은 서버가 계산한다. 필터는 상태 select 하나뿐(월 · 팀 · 미연결 필터 없음 — UI-SPEC S8).
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: `새 지출결의`는 `expenses` 쓰기 권한이 있을 때만 넘긴다. 기안 열은 범위가 자기 문서뿐인 사람(PM)에게 서버가 보내지 않는다(list-pm-1280에 기안 열 없음 · 통합 drafterColumn false), 금액 열 · 합계 줄은 `expense.amount`를 볼 수 없으면 서버가 보내지 않는다.
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 1차는 머리 `새 지출결의` 하나(`ListScreen` `primaryAction`). 보임 범위 0건이면 틀이 머리 1차를 숨기고 `empty`의 2차 버튼 하나가 같은 행동을 맡는다(DR5 A). 행 안 행동 버튼 0.
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 목록에 삭제 · 되돌릴 수 없는 동작이 없다(읽기 표). 위험 색 글자는 상태 낱말 `반려`(status-map이 정함)뿐.
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 보기 0건 빈 화면의 다음 한 수는 `전체 보기` · `진행 중 보기`(보기 넓히기)라 머리 1차 `새 지출결의`와 같은 라벨을 두 자리에 쓰지 않는다. 그룹 머리글(`결재 중`)과 상태 낱말(`팀장 결재 중`)은 단계 이름으로 다르다(UI-SPEC S8 원문).
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: `등록된 지출결의가 없습니다 · 새 지출결의`(쓰기 권한자, 행동 하나) · `진행 중인 지출결의가 없습니다 · 전체 보기` · `승인된 지출결의가 없습니다 · 진행 중 보기` — 모두 `ListEmpty` 한 줄 + 2차 버튼.
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 읽기 표라 편집 키가 없다. 탭 순서 = 상태 select(고르면 바로 GET 제출) → `새 지출결의` → 행마다 문서 링크 하나 → 페이지 링크. 행 안 다른 초점 대상 없음(접힌 줄은 aria-hidden).
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 이동은 전부 `<a>` — 행 = 「프로젝트 · 항목」 `next/link`(폰은 `phoneRowLink`로 행 전체), 빈 화면 행동 = `ListEmpty` href 2차, 페이지 = `ui/pagination` 링크 갈래. 보기 바꾸기는 select(GET 폼).
