## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 글자 추가 0. `…`은 기존 대기 표기 그대로이고 쉬는 동안 자리만 잡는다(::after 내용이라 textContent · 접근 이름에 들어가지 않음)
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 상태 낱말은 `lineStatusWord`(현재 표 · 행 시트와 같은 함수)가 정하고 화면이 따로 판정하지 않는다
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 행동 갈래 변경 없음(서버 `listLineDoors` 판정 그대로). 이전 차수 읽기 표에는 행동 열이 없다(UI-SPEC S1 :350, E2E 머리글 단언)
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 1차 `일괄 저장` 불변, 행 셀 3차 하나 불변
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 위험 동작 추가 · 변경 없음
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 새 글자 없음. 같은 상태 열이 한 화면에서 두 모양이던 것을 하나로(E2E: 두 표 상태 글자 크기 · 굵기 · 색 같음)
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 빈 화면 변경 없음
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 셀 3차는 그대로 tabIndex -1 · Ctrl+E 경로 불변. `지출결의 열기`도 이제 `aria-describedby` = 그 줄 항목 칸(E2E `D-66 잠금` 단언)이라 줄마다 같은 이름의 링크를 줄로 구별한다
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: `RowAction` 링크 · 버튼 모두 `describedBy`를 받는 같은 계약이 됐다. 새 컴포넌트 없음
