# 05-09 작성 중 삭제 · 되돌리기 · 문서 화면 회수 결과 줄 · 본인 승인 차례 토스트 — 점검표

기준: BRIEF.md · frontend.md 화면 사용성 원칙 · CHECKLIST.md §1 · SYSTEM.md §7-6(토스트) · UI-SPEC S3 「머리 줄」(435–437행) · Copywriting 「SUCCESS — 토스트」(305행) · 「Error — 행동 실패」(307행) · Assumptions #10

지금 화면(고치기 전): ① 작성 중 지출결의를 지울 길이 없다 — 잘못 만든 작성 중 문서가 목록 「진행 중」에 계속 남는다. ② 문서 화면 `회수` 확인 창 결과 줄이 `팀장 승인 기록은 남음`에서 끝나 다시 제출 때 첫 단계부터인지 알 수 없다. ③ 팀장 본인이 기안한 문서의 제출 토스트가 `결재 요청됨 → {본인}`이라 다음 행동(본인 승인)이 보이지 않는다.

## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 새 글자는 토스트 결과 `지출결의 삭제`(+3차 `되돌리기`) · `지출결의 제출 · 본인 승인 차례` · 실패 한 줄 `지출결의 삭제 실패 · 다시 시도` · 오류 토스트 `되돌리기 실패`(+3차 `되돌리기`) · 회수 확인 결과 줄 꼬리 ` · 다시 제출 때 첫 단계부터`뿐 — 전부 UI-SPEC 305 · 307행 · Destructive 회수 원문, 명사형.
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 삭제는 문서 version을 화면이 이미 가진 값으로 보내고 사용자에게 묻지 않는다. 되돌리기(복원)는 그 사이 같은 줄에 새 작성 중 문서가 생겼으면 서버가 그 문서를 열어 준다(사용자가 고를 일 없음 — 통합 「부분 UNIQUE」 사례).
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: `지출결의 삭제`는 작성 중(번호 없음) 폼에만 렌더 — 반려 · 회수 폼(`resubmitting`)과 문서 화면에는 없다(page.tsx `actions={resubmitting ? undefined : …}`). 본인 승인 차례 행동 줄에 `반려` 0(E2E 단언).
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 머리 줄 `지출결의 삭제`는 2차(`Button variant="secondary"`), 1차는 폼 바 `지출결의 제출` 하나(0509-draft-head-1280.png).
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 삭제는 폼 바(1차 제출)와 떨어진 머리 줄 오른쪽에 둔다. 되돌리기로 복구되는 일이라 확인 창 없이 즉시이고 UI-SPEC 274 · 435행이 2차로 정했다(위험 색 1차가 아님 — CLAUDE.md §7 「확인 창 대신 되돌리기」). 받은 승인을 지우는 문서 화면 회수만 04.1 확인 창.
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 토스트 글자 = 누른 버튼 라벨 `지출결의 삭제`(DR-21) 한 번. 회수 결과 줄은 기존 `팀장 승인 기록은 남음` 뒤에 다시 제출 조각만 붙인다(같은 말 반복 없음).
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 마지막 작성 중 문서를 지워 목록이 비면 기존 빈 화면(`새 지출결의` 버튼) 그대로이고 토스트는 그 아래 겹친다(0509-deleted-toast-1280.png).
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 머리 줄 버튼 · 토스트 3차 `되돌리기`는 버튼이라 Tab으로 닿고 Enter로 눌린다. 회수 확인은 04.1 확인 창 `Ctrl+Enter`(E2E `page.keyboard.press("Control+Enter")`).
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 토스트 3차는 `ui/toast` `actionLabel` 한 모양(제출 되돌리기와 같은 버튼), 머리 줄 행동은 `DetailScreen` `actions.secondary` 자리의 `Button`.
