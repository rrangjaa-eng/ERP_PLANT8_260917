지금 화면(착수 전): `/cards`는 `ListScreen title="법인카드"` 안 `ListEmpty` 한 줄(`등록된 법인카드 사용 내역이 없습니다 · 결재함 보기`)뿐이다 — 카드 사용을 적을 길 · 목록 · 합계가 없고, 빈 화면 버튼이 엉뚱한 화면(결재함)으로 간다.

## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 패널 글자는 칸 이름 · 서버 계산 한 줄(`공급가 N · 규칙 없음` — 값) · 막힘 이유 한 줄(UI-SPEC 「막힘 — 카드 사용 폼」 원문: `카드 · 결제 합계 2칸 비어 있음 · 카드 고르기` · `연결 없음 · 연결 고르기` · `{이름} {MM-DD} 소속 없음 · 소속 발령은 관리자` · `카드 전표 카드에 없음 · 증빙 종류 고르기` · `환율 없음 · USD 환율 적기`) · 바꿔 채운 증빙 종류를 숨기지 않는 가맹점 힌트 `기본 증빙 {종류} · 카드에 없음`(UI-SPEC 원문) · 반올림 잔차가 있을 때만 계산 한 줄 끝 `· 반올림 차이 N`뿐. `팀 비용` 아래 힌트 없음(M-5 — 팀 이름은 값 텍스트 · E2E가 연결 묶음 안 `<p>` 0개를 단언). 목록은 필터 라벨(`월` · `카드` · `연결` · `등록`) · 합계 면(`합계 ({월} · N건)` · `결제 합계` · `공급가` — 값) 뿐이고 설명문 없음. 빈 화면 세 갈래 · 로드 오류 한 줄 `카드 사용 목록 불러오지 못함` + 2차 `다시 시도`는 UI-SPEC 원문(명사형 — C13)
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 사용일 기본 오늘(서버 KST) · 날짜 칸 `max` = 오늘(Q6 — 미래를 고르지 못한다) · 통화 기본 KRW, USD면 환율 칸이 설정 최근 환율로 채워 열림(O-7) · 가맹점을 고르면 증빙 종류가 거래처 기본값(옵션 밖이면 `카드 전표`) · 카드는 직전 등록의 카드(지금 옵션 안일 때) · 아니면 한 장이면 텍스트로 채움 · 연결은 직전 등록의 연결 종류(M-4 — 서버 `cardUsageFormDefaults`, 처음 쓰는 사람만 빔 · E2E 두 갈래) · 월 필터 기본 이번 달 · 증빙 종류 기본 `카드 전표`(옵션에 있을 때만) · 팀은 고르는 칸 없이 사용일 소속(서버 `teamAtDate`). 공급가 · 부가세는 입력 칸이 없고 서버 계산 한 줄(D-607)
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 카드 옵션은 서버가 고를 수 있는 카드만(소지자 본인 · 사용일 소속 팀 카드). 쓸 카드가 0장이면 패널 · 1차를 그리지 않고 빈 화면 `쓸 수 있는 법인카드가 없습니다 · 카드 등록은 관리자`(버튼 없음). 증빙 종류 옵션은 카드 규칙인 종류만. 칸이 덜 찼으면 1차 비활성 + 이유 한 줄(PanelForm `blockedReason`). 등록 필터(`경영관리 등록`)는 `cards.proxy` · `expenses.payments` write 권한자에게만 그린다 · 카드 필터 선택지는 그 사람의 목록 범위 안 카드만
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 목록 필터 줄 끝 1차 `카드 사용 등록`(빈 목록이면 DR5 — 머리 1차 숨김, 빈 화면 3차 하나). 패널 행동 줄 2차 `취소 Esc` → 1차 `카드 사용 등록 Ctrl+Enter` 하나
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 이 플랜에 삭제 · 되돌릴 수 없는 동작 없음(행 `삭제`는 06-09). 등록 `되돌리기` 없음(C12 — E2E가 패널 안 `되돌리기` 0개를 단언)
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 카드 열을 두지 않고 그룹 머리글(`{별칭} · {발급사} {뒤 4자리}`)이 말한다. 결제 합계 2행은 `공급가 N` 하나(원화 건)
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 이번 달 0건 = `이번 달 카드 사용이 없습니다` + 3차 `카드 사용 등록`(`?new=1`). 카드 0장 갈래만 버튼 없음(할 수 있는 행동이 관리자 몫 — UI-SPEC 원문). 필터 0건은 빈 목록이 아니라 `조건에 맞는 카드 사용이 없습니다` + `필터 지우기`(머리 1차 남음 — ListScreen DR5, E2E 단언)
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 패널은 열리면 첫 칸 포커스 · Tab 순서 = 칸 순서 · `Ctrl+Enter` 제출 · `Esc` 닫기(PanelForm · SidePanel 계약 — 바뀐 칸 없음 → 바로 닫힘 · 포커스 `카드 사용 등록`, 결제 합계를 적은 뒤 → 「입력 버리기」를 E2E가 단언). 목록 필터는 네이티브 select라 Tab · 화살표로 고르고 고르면 GET 이동. 등록 뒤 첫 칸 포커스로 다음 영수증을 바로 적는다(E2E toBeFocused)
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 새 버튼 모양 없음 — 1차 링크는 ListScreen, 패널은 PanelForm 행동 줄, `가맹점 바꾸기`는 05 거래처 고르기와 같은 Button tertiary + `ui/pick-dialog`(noun 거래처)
