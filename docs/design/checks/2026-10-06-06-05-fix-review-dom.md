# 06-05 독립 검토 · DOM 감사 수정(카드 사용 목록 S8 · 등록 패널 S9) — 점검표

지금 화면(고치기 전):
- 「소속 없음」 막힘은 표시 투영(`team.value`)의 팀 이름 유무로 정한다(P3-7).
- 패널 닫기와 1차는 필터를 버리고 `/cards`로 간다(P3-3).
- 증빙 종류를 비우면 `카드 전표`가 옵션에 있어도 `카드 전표 카드에 없음` 이유가 선다(P3-4).
- 320에서 외화 행 2행이 nowrap이라 문서가 34px 넘친다(D1).
- 가맹점만 고르고 Esc를 누르면 「입력 버리기」 없이 닫힌다(D2).
- 폰 연결 라디오는 글자만 눌린다(O1).
- 긴 카드 이름이 필터 select를 넓힌다(O2).
- 쓸 카드가 0장이면 쓸 수 없는 필터 줄이 선다(O3).

고칠 계획:
- 막힘은 발령 유무(`teamAssigned`)로 정한다.
- 닫기와 1차 href는 지금 필터 쿼리를 쓴다.
- 증빙 칸이 비면 옵션에 카드 전표가 있을 때 빈 칸 갈래로 보낸다.
- 2행은 묶음(`통화 금액` · `@환율` · `공급가 N`)마다 nowrap, 묶음 사이에서만 꺾는다.
- 가맹점 숨은 칸이 바뀌면 PanelForm에 바뀐 칸을 알린다.
- 라디오 라벨을 행 높이 블록으로 만든다.
- 카드 필터 select 폭에 상한 `--field-w-short`를 둔다.
- 카드 0장 빈 화면에서는 필터를 넘기지 않는다.
