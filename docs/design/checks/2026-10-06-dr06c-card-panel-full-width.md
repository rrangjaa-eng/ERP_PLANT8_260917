# 카드 사용 등록 패널 칸 전폭 (PR #180 /design-review) — 점검표
화면: app/(app)/cards/card-usage-form.tsx
기준: BRIEF.md · frontend.md 화면 사용성 원칙 · CHECKLIST.md §1 · SYSTEM.md §6-3 옆 패널 배치

지금 화면(고치기 전, CI=true 1280 · 768 DOM 실측): 패널 본문 432px인데 `Form.Field` 칸이 내용 폭으로 줄었다 — 증빙 종류 select 113px · 통화 select · 결제 합계 362px. 카드 · 가맹점 · 연결 · 프로젝트 · 견적 줄 줄은 라벨이 왼쪽(96px 열)에 섰다. 원인: 폼이 `TextField` 줄 클래스(`row`)를 빌려 쓰면서 `data-ui="field-row"` 훅을 빠뜨려, PC 미디어 규칙(`display: flex` · `align-items: flex-start`)이 남고 옆 패널의 덮기 규칙(`Form.module.css` `.panel [data-ui="field-row"]`)이 닿지 않았다. 고친 것: 그 줄들에 훅만 더했다(새 CSS 0줄).
