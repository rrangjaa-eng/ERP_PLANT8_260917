## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 새 글자는 막힘 이유(`지급 완료 {번호} · 새 지출결의 없음` · `카드 사용 {N}건 연결됨 · 지출결의는 다른 줄` · `지출결의 {번호} 연결됨 · 카드 사용은 다른 줄`)와 상태 2행(`증빙 {N}일 경과` · `실행가 초과 {액}`)뿐 — 모두 UI-SPEC 문구 그대로, 잠김 · 경고 한 줄
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 상태 키 · 막힘 · 문(구매 요청/지출결의)은 서버(`pickLineLinkedStatus` · `rowActionBlock` · `resolveLineDoor`)가 정하고 화면은 받은 값만 그린다. 사람이 문을 고르지 않는다
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 한쪽 연결 줄의 반대쪽 행동은 렌더 + `aria-disabled` + 이유(UI-SPEC S14 partial), 온라인구매 줄은 `지출결의 올리기`를 그리지 않고 `구매 요청`만
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 행 행동 자리는 05 3차 하나(갈래에 따라 글자만 바뀜), 막힘 줄의 다음 한 수는 이유 옆 3차 `카드 사용 등록` 하나
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 삭제 위치 · 모양은 04 그대로, 카드 붙잡은 줄은 05 연결 줄과 같은 `취소` 확인 창 꼴만 탄다
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 상태 열은 낱말 하나, 2행은 기한 · 초과액만(상태 낱말 반복 없음), 막힘 이유는 행 행동 자리에만
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 빈 표 갈래는 04 `quoteTableEmptyState` 그대로(이 플랜이 바꾸지 않음)
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: `Ctrl+E`가 현재 줄의 열린 문(`구매 요청` / `지출결의 올리기`)으로 간다 · 힌트 줄 `지출결의·구매 요청 Ctrl+E`
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 행 행동은 모두 05 `RowAction`(3차), `구매 요청` · `카드 사용 등록`도 같은 컴포넌트
