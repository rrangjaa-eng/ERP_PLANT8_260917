## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 새 글자 없음. 막힘 이유는 서버 문자열 그대로(온라인구매 줄은 서버 판정 함수 `cardDualLinkDecision`이 만든 `지출결의 {번호} 연결됨 · 카드 사용은 다른 줄` — UI-SPEC S14 문구), 자리만 행동 옆 → 행동 아래로
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 다음 한 수를 보일지는 서버(`listLineDoors`가 `cardOptionsForUsage` 결과로 거름)가 정하고 화면은 받은 값만 그린다
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 쓸 카드가 없는 사람에게 `카드 사용 등록`을 싣지 않는다(통합 「[감사 D-2]」가 `blocked` = 이유만 단언), 막힌 행동은 `aria-disabled` + 이유(기존 E2E 「한쪽 연결 다음 한 수」 녹색 — 접근 설명이 이유로 끝남)
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 행 행동 자리 3차 그대로, 막힌 줄의 다음 한 수 하나(이유 아래)
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 이 변경은 위험 동작을 건드리지 않음(삭제 위치 · 모양 04 그대로)
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 이유는 행동 칸에 한 번(버튼 `aria-describedby`가 같은 글자 id를 가리킬 뿐 글자를 다시 쓰지 않음)
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 빈 표 갈래 무변경
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 카드 쪽으로 막힌 줄에서 `Ctrl+E` → 다음 한 수 `/cards?new=1&line={id}`(E2E 「[감사 D-3]」 녹색). Enter(셀 편집) · 방향키 · 여러 줄 `Ctrl+E`(막힌 줄은 빠짐)는 그대로라 충돌 없음, 미저장 편집이 있으면 기존과 같이 이동하지 않고 한 줄만
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 행동 · 다음 한 수 모두 05 `RowAction`(3차) 그대로, 이유 글자는 이전과 같은 역할 토큰(`--status-danger` · `--text-aux`)
