## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 새 글자 없음. 금액 숨김 1차 이유는 06-04 `AMOUNT_HIDDEN`(`지급 총액 볼 권한 없음 · 노출 설정은 관리자` — 문서 화면 1차 · 서버 거부와 같은 글자)을 그대로 쓴다
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 바뀐 것 없음(지급일 기본 오늘 · 합계 서버 계산 그대로)
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 금액 숨김 계정은 모든 행이 막혀 1차가 비활성인데 이유가 `고른 건 없음`(고르면 된다는 뜻)이라 할 수 없는 행동을 권했다 → 실제 원인(금액 권한)으로 바꿈. E2E 「금액 숨김 지급 권한자」가 accessible description으로 단언
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 머리 1차 `지급 완료 N` 하나 그대로, 빈 화면은 2차 링크 하나씩(DR5)
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 해당 없음 — 위험 동작을 더하지 않았다
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 1차 이유 한 자리에만 `AMOUNT_HIDDEN`, 행 선택 칸 이유는 aria-describedby(보이지 않는 연결)라 화면 글자로 겹치지 않는다
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: `지급할 건이 없습니다 · 지급 완료 보기` · `조건에 맞는 건이 없습니다 · 필터 지우기` 한 줄 + 행동 하나 그대로
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 빈 화면 링크는 Tab 도달 · Enter 이동(링크 기본). `필터 지우기` 뒤 포커스는 BODY(CI=true 실측) — 05 목록 빈 화면 링크(`진행 중 보기` · `전체 보기`)와 같은 Next 같은 쪽 이동 동작이고, SYSTEM §10은 모달 · 시트 닫힘 복귀만 정한다(같은 쪽 이동 뒤 포커스 규칙 없음)
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 빈 화면 두 행동은 화면 이동이라 `<a>`(SYSTEM §10 「페이지 이동이면 `<a>`」 · ListEmpty href 갈래 · 05 목록 빈 화면과 같음). href는 URLSearchParams 인코딩(검토 I-1: 원시 공백 · 한글 href만 프리페치가 끝나지 않았다) — E2E가 링크 role · href · networkidle 단언
