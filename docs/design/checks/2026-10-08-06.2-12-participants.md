- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 권리 · 잠금 · 후보 유무는 서버 불린만 그린다(클라이언트 계산 0). 확인 창 없이 바로 떼고 되돌리기로 푼다(§7-8)
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: `canEdit` 거짓(참여자 본인 · 완료 · 권리 없음)이면 동작 열 자체를 그리지 않는다(두 열). 담당 PM 행 동작 칸은 비어 있다. 후보 0 · 권리 없음 · 잠금이면 `참여자 더하기`를 그리지 않는다(Task 2)
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 섹션 안 1차 버튼 없음 — 행 동작 `떼기`(danger 글자 링크) · 표 아래 3차 `참여자 더하기` 하나. 화면 1차(`일괄 저장`)는 그대로
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: `떼기`는 `RowAction danger`(위험 색 글자 · 맨 끝 동작 열 · 붉은 면 없음, §7-19). 확인 창 대신 `되돌리기`
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 이름 뒤 글자 태그는 고정 낱말 셋(`담당 PM` · `퇴직` · `보관됨`)뿐, 팀 칸과 겹치지 않는다. 폰 접힌 줄은 StaticTable이 p2 팀을 한 번만 보인다
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 참여자 0이어도 담당 PM 행 하나인 표가 선다(`ListEmpty`는 ERROR 한 곳). 첫 행동 3차 `참여자 더하기`는 Task 2
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 읽기 표 + 행 `떼기`(button) · `되돌리기`(button). 떼면 포커스가 `되돌리기`로, 되돌리면 그 행 `떼기`로 간다(04.2 공휴일 `focusDate` 선례)
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 표 안 행동은 모두 `RowAction`(cards `삭제` · `되돌리기`와 같은 모양)

## Task 2 (S3 배선 · 표 아래 3차 · 섹션 상태) — 위 항목을 이 변경 기준으로 다시 확인
- [x] 안내 문구 · 같은 말 두 번 없음 — 근거: 새 글자는 `참여자 더하기`(3차) · 시각 숨김 `참여자 N명 더함` · 서버 거부 원문 · `더하지 못함 · 다시 시도`뿐. `더할 수 있는 사람 없음`은 S3 `emptyDefault` 한 곳(섹션에 같은 문구 · 비활성 이유 없음). 빈 문장 `ListEmpty`는 ERROR 한 곳
- [x] 할 수 없는 선택지는 숨겼다 — 근거: `memberAddPlacement(canEdit ∧ hasCandidates)`가 거짓이면 3차를 렌더하지 않는다(권리 없음 · 잠금 · 후보 0 — 이유 문구 · 비활성 버튼 없음). 클라이언트는 서버 불린만 쓴다
- [x] 주 버튼 하나 · 빈 화면은 첫 행동 — 근거: 참여자 0(담당 PM 행만)이어도 표 아래 3차 하나가 모든 폭에 선다(`memberAddAll`). 참여자가 있으면 같은 버튼 하나에 `memberAddPcOnly`(폰 <700 CSS 숨김)만 바꿔 PC/폰 이중 렌더가 없다
- [x] 키보드만으로 끝난다 — 근거: 3차(button) → 검색 칸 포커스 → `↓` `Space` 반복 → `Enter` → 닫힘. 더한 뒤 포커스는 폭마다 하나(PC 3차 → 없으면 섹션 제목 h2 `tabIndex=-1`, 폰 「더보기」 토글)이고 `Esc`는 연 요소로 돌아간다(`focusAfterPicker`, matchMedia는 포커스만 정하고 렌더에는 쓰지 않는다)
- [x] 새 색·서체·radius 없음 — 근거: 추가 CSS는 `.memberAddAll` `.memberAddPcOnly`뿐(`--s-3` `--touch-min`). `ui/` 무변경(06.2-07 변형을 쓰기만), tokens.css diff 0
- [x] 폰 320 가로 넘침 없음 · 터치 44 — 근거: 폰에서 3차(참여자 0일 때)는 `min-height: var(--touch-min)`. 폰·320 실측은 Task 3 E2E · 오케스트레이터 DOM 감사
