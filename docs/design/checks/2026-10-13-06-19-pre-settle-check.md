# 06-19 완료 전 점검 섹션(S18) · 정산 결재 올리기 막힘 — 점검표
화면: app/(app)/projects/[id]/, ui/status-tag/status-map.ts
기준: BRIEF.md · frontend.md 화면 사용성 원칙 · CHECKLIST.md §1 · 06-UI-SPEC.md S18 · Copywriting 「표시 — 완료 전 점검 섹션」 「표시 — 점검 행」 「막힘 — 정산 결재 올리기」 「Empty — 완료 전 점검」

지금 화면(고치기 전): 정산 프로젝트 상세에 점검 섹션이 없고, `정산 결재 올리기`는 미결 지출결의 · 미매칭 줄 · 매출 미입력과 무관하게 살아 있다 — 기안은 대표 승인 때(A8)에야 막힌다.

## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 섹션 부제 없음(r3 · C13). 글자는 그룹 머리글(`미결 지출결의 N건` 등 건수 명사) · 버튼 막힘 이유 `완료 전 점검 N건` · 오류 `점검 결과 없음` · 전부 빔 `미결 없음` 한 줄뿐이다
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 막힘 건수 · 그룹 · 행 낱말은 서버 DTO(`getPreSettleCheck`)가 계산하고 화면은 읽기만 한다. 사용자 입력 칸 없음
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 막힘이면 `정산 결재 올리기`가 aria-disabled + 이유 + 3차 `점검 보기`(Button `disabledReason` · `nextStep`). 섹션은 정산 상태에서만 서고, 빈 그룹은 접힌다
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 섹션에 1차 버튼을 더하지 않는다. 행 행동은 3차(`지출결의 열기` 링크), 머리 줄은 기존 2차 `정산 결재 올리기` 그대로
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 이 섹션에 위험 동작 없음(읽기 표 + 이동 3차). 막힘 건수만 `--status-danger`
- [x] 보는 범위(R-6) · 금액 노출을 화면이 추론하지 않는다 — 근거: 범위 밖 미결 지출결의는 서버가 건수만 실어 그룹 끝 `그 밖 N건`(--text-muted · 행동 없음) 한 줄, 금액 · 실행가 열은 서버가 금액 키를 실은 행이 있을 때만 선다(정보 항목 노출 밖이면 열 자체가 없다 — 빈 칸 `—` 열을 두지 않는다). E2E 「보는 범위(R-6)」가 `그 밖 1건`과 기안자 문서 번호 부재를 단언
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 막힘 건수는 그룹 머리글과 버튼 이유 두 자리지만 UI-SPEC S18이 정한 두 자리(머리글 = 그룹 건수, 버튼 = 막힘 합)다. 섹션 부제로 다시 말하지 않는다
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 세 그룹이 비면 `미결 없음`(--status-success) 한 줄 — 할 일이 없는 상태라 행동 버튼이 없다(UI-SPEC 「Empty — 완료 전 점검」)
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 막힌 버튼은 aria-disabled라 탭 순서에 남고 바로 옆 3차 `점검 보기`가 섹션 제목(h2, tabIndex -1)으로 포커스를 옮긴다(E2E `toBeFocused`). 행 3차는 링크라 Tab · Enter
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 이동(`지출결의 열기` · `구매 요청` · `지출결의 올리기`)은 링크 3차, 화면 안 동작(`점검 보기` · `다시 시도`)은 버튼 3차 — 기존 S14 행 행동 · 매출 섹션과 같은 갈래

## 사용자 결정(§1)
- [x] §1의 결정을 하나도 어기지 않았다(웜톤 · 견적 엑셀식 · 옆 패널 · 스킨 A …) — 근거: 새 바탕 · 패널 · 모달 없음. 견적 표는 건드리지 않고 그 아래에 읽기 표 섹션만 더한다(DetailScreen.Section + ui/table Table)
