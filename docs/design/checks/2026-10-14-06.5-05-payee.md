## 지금 화면 기준으로 어긋난 것(고치기 전)
- (Task 1 · V4) 계좌 없는 거래처로 계좌이체 지출결의를 써도 1차가 열려 제출 · 결재 · 지급 대상까지 가서 마지막 이체에서야 막힌다(G21).
- (Task 2 · V12) 지급처 칸 이름이 「거래처」라 직원에게 주는 돈을 지출결의로 쓸 수 없고, 프로젝트 비용 폼에는 지급처를 고르는 버튼 자체가 없다(팀 비용만). 목록 열 · 문서 행 · 뼈대 라벨도 「거래처」.

## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: (Task 1) 더한 글자는 막힘 한 줄 `지급처 계좌 없음 · 계좌 등록은 경영관리`(또는 `· 계좌 등록` 링크) 하나 — 기존 1차 옆 막힘 자리(BlockLine)에 서고 새 설명문 0. (Task 2) 새 설명문 0 — 「거래처」 낱말만 「지급처」로 바꾸고(칸 · 버튼 · 대화상자 · 목록 열 · 문서 행 · 뼈대 · 줄 채움 결과 줄), 직원 행 부제 `직원 · {팀}` · 계좌이체 문서의 꼬리 ` · 계좌 없음`만 더했다(UI-SPEC V12 행 계약 그대로).
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: (Task 1) 계좌 유무는 서버가 판정(domain/expenses/payee.ts hasUsableAccount) — 사용자가 고를 것 없음. (Task 2) 거래처 · 직원을 고르는 별도 갈래(라디오 · 탭) 없이 한 검색 한 목록(mergePayeePickRows) — 종류를 먼저 고르는 결정이 없다. 직원 팀은 서버가 오늘 소속으로 채운다.
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: (Task 1) 고칠 권한이 없는 기안자에게는 3차를 세우지 않고 담당을 적는다(BlockLine — href 없음 · 칸 대상 아님 → 글자만). E2E 「지급처 계좌 없음 (06.5 V4)」이 `#expense-next-step` 0개를 단언. (Task 2) 보관 · 퇴사(오늘 KST 이하) 직원은 후보에 아예 없다(listPayeeUserCandidates — 통합 「직원 후보」가 단언).
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 1차 `지출결의 제출` 그대로, 막히면 aria-disabled(기존 S6 계약). 대화상자 1차는 `이 지급처로` 하나.
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 해당 없음 — 삭제 · 종결 자리 변경 0.
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: (Task 1) 고칠 수 있는 사람의 문장은 `지급처 계좌 없음 · ` + 링크 `계좌 등록` — 담당 글자를 함께 쓰지 않는다(UI-SPEC V4). (Task 2) 결과 머리는 `지급처 {N}` 하나(종류별 건수 없음) · 넘침 줄은 PickDialog 한 줄 그대로(E2E R-1이 각 1개 단언).
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 해당 없음 — 빈 화면 변경 0(빈 목록 문구는 pickEmptyText noun `지급처`).
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: (Task 1) 링크가 있으면 첫 포커스 · 비활성 1차 누름이 기존 focusBlockTarget으로 `#expense-next-step` 링크에 간다. 링크는 새 탭(target="_blank" rel="noopener") — 작성 중 폼을 잃지 않는다. (Task 2) 직원 행도 기존 option 행(↓ · Enter) — E2E가 role="option" · radio 0 단언, 기존 키보드 고르기(pickVendorByKeyboard) 녹색.
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: (Task 1) 이동은 기존 3차 모양 링크(buttonLinkClassName("tertiary")) — ①·④ 이동과 같은 모양. (Task 2) 지급처 `바꾸기`는 견적 줄 `바꾸기`와 같은 3차 버튼 — 접근 이름만 `지급처 바꾸기`(R-2).
