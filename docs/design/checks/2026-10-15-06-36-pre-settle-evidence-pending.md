# 06-36 완료 전 점검 — 증빙 대기 그룹(G-06-E · 카드 ② 「경고만」) — 점검표

지금 화면(고치기 전): 결재 통과 · 증빙 없는 지출결의(`증빙 없음` · `선결제 · 증빙 없음`)가 `미결 지출결의` 그룹에 섞여 건수 `--status-danger`로 세어지고, `정산 결재 올리기` 버튼이 `완료 전 점검 N건`으로 비활성이다.
지금 화면(고치기 전): 결재 통과 · 증빙 대기 문서만 남아도 `미결 없음` 한 줄이 서지 않아, 막힘이 없는데도 막힌 것처럼 읽힌다.

## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 더한 글자는 그룹 이름 `증빙 대기` 하나와 건수 `{n}건`뿐이다(카드 ② 문구 「증빙 대기 건」). 설명문 · 부제 · 도움말 없음. 행 낱말은 기존 `증빙 없음` · `선결제 · 증빙 없음` 그대로
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 어느 그룹에 서는지는 서버 DTO(`evidencePending`)가 결재 상태 + 증빙 갈래로 계산하고 화면은 읽기만 한다. 사용자 입력 칸 · 선택지 없음
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 증빙 대기 그룹은 강행 대상이 아니라 `강행 허용` 꼬리 · `allowed` 칸이 없다(`GroupHeading`에 `allowed={false}` + 경고 갈래). 건수가 0이면 그룹 전체를 접는다
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 머리 줄 1차 `정산 결재 올리기` 하나 그대로이고, 막힘이 없으면 aria-disabled가 풀려 살아 있다(E2E G-06-E). 행 3차 `{번호} 지출결의 열기` 링크는 `미결 지출결의` 표와 같은 `openExpenseAction`
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 이 변경에 위험 동작 없음(읽기 전용 그룹)
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 그룹 머리글 `증빙 대기 {n}건`과 행 상태 글자 `증빙 없음`은 다른 말이다(그룹 = 막지 않음, 행 = 어떤 증빙 상태인지). 표 caption은 머리글과 같은 `증빙 대기`이나 스크린리더용 표 이름이다(`미결 지출결의` 선례와 같음)
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 해당 없음 — 증빙 대기 0이면 그룹이 서지 않고, 세 막는 그룹도 비면 기존 `미결 없음` 한 줄 그대로
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 행 3차는 기존 `RowAction` 링크라 Tab 순서에 서고 Enter로 열린다. 새 입력 칸 · 단축키 없음
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 증빙 대기 행의 `지출결의 열기`는 `미결 지출결의` 행과 같은 `expenseColumns` · `openExpenseAction`(링크 3차)을 그대로 쓴다. 새 컴포넌트 0
