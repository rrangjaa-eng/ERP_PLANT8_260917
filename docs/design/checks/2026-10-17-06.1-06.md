## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 새 글자는 거부 · 잠김 줄뿐(`확인 필요 · 패널에서 확인 필요 풀기` · `카드 미등록 · 카드 등록은 관리자` · `결재 중 · 떼기 없음` · `승인됨 · 떼기는 증빙 무효 담당` · `결재 중 문서 · 결재 끝까지 떼기 없음` · `사유 없음 · 사유 적기` · `붙이지 못함 · 다시 시도` · `떼지 못함 · 다시 시도`)과 되돌릴 수 없는 결과 줄(`비용이 예상 {금액}으로` · `붙은 증빙 {n}건은 증빙 목록으로`) — 설명문 · 도움말 0. 잠김 줄은 05 첨부 영역이 이미 그리면 붙은 증빙 블록에서 다시 그리지 않는다(섹션당 하나)
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 후보 순위 · 고를 수 있음 · 이유는 서버(SQL 순위 · 05 규칙표 권리 · 짝)가 정하고 1위가 고를 수 있으면 `preselect`로 현재 행 — 사람은 Enter 한 번. 붙이기 입력에 금액 · version 칸 없음(D-6520). 떼기 창은 사유 하나만
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: `붙이기`는 `canAttach`(붙일 수 있는 상태 ∧ 볼 수 있는 문서 하나 이상)일 때만, 확인 필요 · 카드 미등록이면 `aria-disabled` + 이유. 후보 행은 서버 `selectable` 거짓이면 고를 수 없는 행 + 이유. 붙은 증빙 행 끝 행동은 서버 권리(`evidenceRecordRights`) 그대로 — 권리 없으면 버튼 자리 자체가 없다
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 고르기 모달 1차 `이 문서에 붙이기`(PickDialog 기본 kbd Enter) 하나 · 떼기 창 1차 `증빙 떼기`/`무효 처리` 하나. 목록 · 문서 화면 1차는 그대로(새 1차 없음)
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 문서 「증빙」 섹션 `떼기` · `무효 처리`는 행 끝 `RowAction danger` + 사유 받는 ConfirmDialog. 목록 행에는 떼기를 두지 않았다(편차 — SUMMARY)
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 상태 1행 `붙음` + 2행은 문서 번호 링크(또는 `작성 중 문서`)만 — 「붙은 문서:」 같은 머리말 없음. 붙은 증빙 표 caption 「붙은 증빙」 하나, 행은 `{종류} · {거래처}` · 날짜 · 합계
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 붙은 증빙이 0건이면 블록 자체를 그리지 않는다(빈 표 · 빈 문구 없음). 후보 0건 · 다 막힘은 PickDialog 기본 빈 줄 · `붙일 수 있는 문서 없음`
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 행 `붙이기` → 모달 검색 칸 포커스 → 방향키로 행 · Enter로 붙이기 → 닫히면 PickDialog가 여는 요소로 포커스 복귀(E2E `evidence-attach.spec.ts` S7 행 1이 검색 칸 포커스 · Enter 붙이기를 잰다). 떼기 창은 ConfirmDialog 기본(사유 textarea → 1차)
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 목록 행 행동은 기존 `보관` · `되살리기`와 같은 `RowAction`, 문서 화면 떼기는 05 첨부 영역 무효 처리와 같은 `RowAction danger`. 문서 이동만 링크(상태 2행 번호 — 기존 목록의 번호 링크와 같은 갈래)
