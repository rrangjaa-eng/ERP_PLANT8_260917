## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 패널의 글자 줄은 셋뿐 — 잠김 줄(서버 amountLock 글자 그대로) · 서버 거부 FormAlert(서버 문자열 · 충돌은 꼬리 3차 `새로 고침`) · 1차 막힘 이유 `바뀐 칸 없음`. 입력 아래 줄은 설명이 아니라 서버가 셈한 값(`세액 n · 합계 n`)
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 공급가 칸은 파일 값으로 채워 열리고 입력은 그 칸 하나 — 세액 · 합계는 서버 미리 보기(previewEvidenceAmountAction)가 셈한다(E2E tracer: 990,000 → `세액 110,000 · 합계 1,100,000`). 확인 필요면 1차가 곧 풀기라 따로 고르지 않는다
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 잠긴 기록은 공급가 input 0 · 1차 0(E2E 잠김 결재 중 · 승인됨 · 작성 중), 1024 미만은 읽기 시트(input 0 · 1차 0 — E2E 768 · 375), 바뀐 칸이 없으면 1차 aria-disabled + `바뀐 칸 없음`(네이티브 disabled 0)
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 패널 행동 줄 1차 하나(`증빙 금액 저장` 또는 `확인 필요 풀기` — DA-13) + 2차 `취소`(1280 스크린샷)
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 패널에 위험 동작 없음(떼기 · 보관은 표 행 행동 그대로 — 06.1-05 · 06)
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 상태 줄은 확인 필요 · 카드 미등록 · 보관됨일 때만 — 미공개 · 팀 공개 · 본부 공개 · 붙음은 아래 `공개` · `붙은 문서` 줄과 같은 말이라 뺐다(E2E tracer `dt 상태` 0). 잠김이면 공급가를 글자로만 한 번
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 빈 목록 화면은 바뀐 것 없음(06.1-05 그대로 — evidence-list-audit 21 통과). 패널은 행이 있어야 열린다
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 거래처 칸 격자 Enter → 패널(E2E tracer) · 공급가 입력 → `Ctrl+Enter` 저장 · `Esc` 닫기(dirty면 `입력 버리기` — E2E) · 닫힌 뒤 포커스 = 연 거래처 칸(E2E tracer toBeFocused). 칸은 격자 로빙 밖(tabIndex -1 — 탭 정지 1개)
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 붙은 문서 번호는 3차 링크 모양(buttonLinkClassName tertiary), 충돌 꼬리 `새로 고침`은 3차 Button(ConflictLine과 같은 꼴). 행 이름 칸은 겉모양 없는 행 열기(ui/table 접힌 줄 탭과 같은 role=button 꼴) — 링크 모양을 주려면 CSS 파일(플랜 밖)을 고쳐야 해 /design-review 후보로 남김
