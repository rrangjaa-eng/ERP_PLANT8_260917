## 지금 화면 기준으로 어긋난 것(고치기 전)
- 증빙 목록 공개 칸은 셀 하나씩 열어 고르는 것만 된다 — 수십 줄의 공개 범위를 정하려면 줄 수만큼 열고 고르고 닫는다(엑셀 라벨 열을 붙일 길 없음). 힌트 줄에 `Ctrl+V`가 없다(실제로 안 되므로 맞다).
- 증빙 목록을 거르개 그대로 파일로 받을 길이 없다(260907 Receipts 목록 내려받기 — RP-16).
- 쇼케이스 편집 표 절에 select 붙여넣기 결과 표본이 없다(SP-6104가 화면보다 먼저 서야 한다).
- 고칠 계획: 공개 칸 `Ctrl+V` = 줄마다 그 줄 선택지 라벨과 글자 대조(공유 `ui/table` 규칙 무변경 · 순수 함수 `resolvePublishPaste`) → 맞으면 dirty, 모르면 오류 셀 + 요약 조각, 잠긴 줄은 건너뜀 + 요약 조각. 필터 줄 선택 칸 뒤 2차 `파일 받기`(≥1024). 쇼케이스 `SelectPasteSample` 정적 표본.

## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 새 글자는 오류 셀 이유 `목록에 없는 값 · {글자}`(공유 select 붙여넣기와 같은 글자) · 합계 행 요약 조각 `공개 칸 n개 모르는 값` · `잠긴 줄 n칸 건너뜀` · 거부 `오류 n칸 · 전부 거부`(06.1-05 DA-18 글자) · 실패 토스트 `파일 받기 · 실패 · 다시 시도`뿐 — 전부 오류 · 상태 한 줄 명사형. 0인 조각은 그리지 않는다(E2E `evidence-paste` 요약 단언).
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 붙여넣기는 라벨 글자로 값을 찾고 이미 같은 값인 칸은 dirty로 세지 않는다(N = 실제로 바뀐 칸 — E2E 첫 케이스 N=2). `파일 받기`는 지금 거르개를 그대로 쓰고 열 · 형식을 묻지 않는다(확인 창 없음).
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 잠긴 줄(확인 필요 · 붙음 등)은 붙여넣기가 값을 바꾸지 않는다(E2E 잠긴 줄 값 불변 단언). 없는 · 보관 팀 라벨은 값이 되지 않고 오류 셀(단위 · E2E `기획9팀 공개`). 1024 미만은 편집 · 붙여넣기 · `파일 받기`가 없다(E2E 768 두 케이스).
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 1차는 그대로 `공개 범위 저장 {N}` 하나 — `파일 받기`는 2차(secondary)이고 필터 줄 왼쪽(선택 칸 뒤), 1차는 오른쪽 끝(캡처 evidence-paste-1280).
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 이 플랜은 위험 행동을 더하지 않는다. 행 `보관`(danger) 자리 그대로.
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 오류 이유는 그 칸 아래 한 번, 합계 행은 칸 수만 센다(`오류 n칸`) — 같은 이유 글자를 합계 행에 되풀이하지 않는다.
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 빈 화면(목록 0) 변화 없음 — 필터 줄 자체가 `list.hasAny`일 때만 서므로 `파일 받기`도 빈 화면에 없다.
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 공개 칸 포커스 → `Ctrl+V` → `Ctrl+S`(E2E 두 케이스 키보드 경로). 힌트 줄에 `붙여넣기 Ctrl+V` 한 칸 더함(실제로 되는 키만). `파일 받기`는 네이티브 button이라 Tab → Enter.
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: `파일 받기`는 06.5 `이체 파일 받기` · 행동 로그 `Excel 내보내기`와 같은 `Button variant="secondary"`.
