## 시작 상태(코드 전)
- M-1 되돌리기가 일부만 거부돼도 결과 줄은 `되돌리기 실패 · {사유}` 하나 — 되돌려진 건수가 보이지 않고, 막힌 행 오류 줄도 지운다.
- L-1 `이번 주로` · 되돌리기 응답이 끊기면 `… · 다시 시도` — 서버가 이미 저장했으면 옛 version으로 다시 보내 전부 충돌, 목록도 다시 받지 않는다.
- L-2 건마다 거부(영업일 · 지남 · 밀림 아님 · version 충돌)로 전부 막혀도 `다시 시도` — 같은 입력이라 같은 이유로 또 거부된다.
