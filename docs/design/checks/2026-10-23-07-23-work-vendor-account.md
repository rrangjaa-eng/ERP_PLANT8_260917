## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 새 문구 0. 칸을 숨길 뿐 「계좌 권한 없음」 같은 설명을 더하지 않았다(할 수 없는 선택지는 숨김).
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 이름 = 검색어 · 갈래 협력사 기본값 그대로. 권한 없는 사람에게 계좌를 넣을지 고르게 하지 않는다.
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 이번 변경의 본체. E2E `R-1 — 계좌 쓰기 없음` 이 세 라벨 count 0을 DOM으로 본다. 서버도 `계좌 수정 권한 없음` 으로 거부.
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: PanelForm 1차 `거래처 등록` 하나 그대로(VendorForm 무변경).
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 패널에 위험 동작 없음(무변경).
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 문구 변경 0.
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 해당 없음(빈 목록 화면 무변경).
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 칸이 줄 뿐 순서 · 포커스 무변경. E2E가 첫 포커스 이름 · 저장 뒤 포커스 지급처 칸을 그대로 통과.
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 무변경.
