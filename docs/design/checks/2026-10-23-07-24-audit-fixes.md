PO 0 칸 `PO 없음`은 값 자리 낱말(예산 근거 표시).
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 충돌 뒤 `새로 불러오기`가 현재 값 · `예산` 칸(새 값으로 다시 채움) · 맨 위 줄을 바꾸고 사유는 그대로 둔다(E2E 4폭 — `예산` 칸 8,700,000 · 사유 `충돌 확인` 유지). 저장 실패 뒤 입력이 남아 다시 누르기만 하면 된다.
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 저장 중에는 `예산 저장` aria-disabled · `취소` disabled · Esc · 닫기(x) · 가림막이 무시된다(SidePanel 가드 submitting — E2E 4폭: Esc 두 번 + x 뒤에도 패널 · 편집 남음). 실패하면 둘 다 다시 켜진다(E2E aria-disabled 없음 · 취소 enabled).
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 바뀌지 않음 — 편집 때만 1차 `예산 저장` 1개. `새로 불러오기` · `더 보기`는 3차.
