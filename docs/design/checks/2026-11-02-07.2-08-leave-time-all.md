## S17 반반차 시작 시각 — 고치기 전
- 반반차도 반차와 같은 `시간` 오전/오후 select를 받았다(D-7258은 시각이 오전/오후를 대신). 표시 자리는 `반반차 오전`.
- 표시 글자가 네 곳에서 따로 만들어졌다(목록 labels.ts · 문서 종류 줄 [id]/page.tsx · 인쇄 print/leaves · 제목/결재함 domain kindWord).

## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 새 문구는 오류 한 줄 `시작 시각 형식 오류 · 14:00처럼`뿐(기존 막힘 줄 자리, 칸에 aria-invalid). 힌트 · 자리 표시 설명 0.
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 시작 시각 기본값 `09:00`(DEFAULT_START_TIME) — 안 바꿔도 제출된다. 반려 뒤 다시 신청은 저장된 시각이 채워진다.
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 반반차에서 오전/오후 select DOM 0, 종일 · 반차에서 시각 칸 DOM 0(leaveFieldsOf 한 곳).
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: `/leave/new` 1차는 기존 `연차 신청` 하나 그대로(형식 오류면 비활성 + 막힘 줄).
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 이 작업에 위험한 동작 없음(칸 하나 · 표시 글자).
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 형식 오류는 막힘 줄 한 자리(서버 거절일 때만 칸 아래 Form.Error, shownSubmitErrors가 같은 글자면 칸 오류를 숨긴다). 반반차 표시는 `반반차 14:00` — half 글자를 덧붙이지 않는다.
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: S17은 빈 상태 해당 없음(UI-SPEC S17 EMPTY 해당 없음).
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 네이티브 `input type=time` — Tab으로 들어가 숫자 입력, Ctrl+Enter 제출 · Esc 취소 기존 그대로(폼 keydown).
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 새 행동 없음. 시각 칸은 날짜 칸과 같은 `textInput` 클래스 · `Form.Field width="short"`.

## S20 사람별 연차 잔여 — 고치기 전
- `/leave`는 내 연차만 있었다. 경영관리 · 팀장이 사람마다 남은 연차를 보려면 관리자 사람 상세를 한 명씩 열어야 했다.

## S20 원칙
- [x] 안내 문구: 새 설명문 0 — 근거: 화면 글자는 열 이름 · 링크 `내 연차` · `전체` · 결과 `{N}명` · 퇴직자 `퇴직` · EMPTY `조건에 맞는 사람이 없습니다`뿐(UI-SPEC S20 결정·문구 점검 「문구는 열 이름뿐」).
- [x] 결정 최소: 고를 것은 연도 하나 — 근거: 기본은 올해, 범위(전사/자기 팀)는 서버가 정한다(peopleLeaveScopeOf) — 사람이 고르지 않는다.
- [x] 할 수 없는 선택지는 숨겼다 — 근거: 범위가 null인 계정(사원 · 기본 시드 대표 · 본부 책임자)은 선택 링크 줄 DOM 0, `?view=all` 직접 주소는 not-found 화면(E2E 「`전체` 링크 DOM 0 · 404」).
- [x] 주 버튼 하나 — 근거: 「전체」 보기는 읽기 전용이라 머리 1차 없음(입력 0). 내 연차 보기의 `연차 신청` 1차는 그대로.
- [x] 위험한 동작 없음 — 근거: 읽기 전용 표(행 탭 = 시트 열기뿐).
- [x] 같은 말 두 번 없음 — 근거: 폰 접힌 줄은 라벨 없이 `{팀} · {n}일`, 시트 부제는 퇴직자일 때 `퇴직`만(팀은 시트 항목 한 자리). 두 잔고를 더한 열 0.
- [x] 빈 화면은 첫 행동 먼저 — 근거: EMPTY `조건에 맞는 사람이 없습니다` + 3차 `연도 바꾸기` 링크 하나(ListEmpty).
- [x] 키보드만으로 끝난다 — 근거: 링크 둘 · 연도 select는 Tab, 폰 접힌 줄은 Table의 role=button(Enter · Space) 그대로.
- [x] 같은 종류의 행동은 같은 모양 — 근거: 선택 링크는 둘 다 같은 `.viewLink`(3차 링크 값 = `.link`와 같은 토큰), 현재 항목만 강한 글자 700 + 두꺼운 밑줄(§6-1 DC-11 「aria-current + 밑줄」).
