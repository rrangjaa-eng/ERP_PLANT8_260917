## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 새 글자는 버튼 `엑셀 올리기` · 결과 줄(`건너뜀 N줄 · 합계 N 차이 · 엑셀 금액과 다름 N줄 · 엑셀 올림 N줄`) · 거절 줄 4종(서버가 돌려준 문장 그대로) · 3차 `되돌리기` · `다시 올리기` · `건너뜀 보기`뿐이다. 입구 옆 설명 · 자리 표시 설명 · 도움말 0, 승인 차수의 이유는 새 글자 없이 기존 잠김 한 줄이 말한다
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 열은 머리글 이름으로 자동 인식(열 지정 · 미리보기 · 덮어쓰기 선택 0), 수량 · 일수 없으면 1, 소분류는 줄 추가와 같은 기본값, 검산 · 불일치는 서버가 센다. 사용자가 고르는 것은 시트가 둘 이상일 때의 시트 하나뿐이다
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 승인 차수 · 정산 · 완료 · 구조 권리 없음이면 입구를 렌더하지 않는다(E2E `승인 차수 — 입구 DOM 0`), 1024 미만은 CSS display:none
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 머리 줄 1차는 그대로 `일괄 저장 N`(엑셀 줄이 dirty로 합산 — E2E `일괄 저장 N 합산`), `엑셀 올리기`는 2차 secondary
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 위험한 동작 없음 — 저장 0 · `되돌리기`는 이번에 붙인 미저장 줄만 뺀다. 거절 줄만 `--status-danger`
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 결과 줄은 표 위 한 줄 하나이고 합계 행 바닥 줄에는 같은 글자를 넣지 않는다(E2E `tfoot 엑셀 올림 0`). 거절 이유 다음 한 수는 3차 `다시 올리기` 하나
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 해당 없음(S10 empty) — 빈 표의 첫 행동 버튼은 기존 그대로이고 엑셀 입구는 머리 줄 2차다
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 입구 · `되돌리기` · `다시 올리기` · `건너뜀 보기`(summary)는 네이티브 버튼 · summary라 Tab · Enter · Space, 시트 고르기는 PickDialog의 Enter 1차(첫 시트 미리 선택). 표 안 키 구성은 건드리지 않았다
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 3차는 기존 복원 줄 `.restoreAction`(밑줄 · 강조색 글자 버튼)을 그대로 쓰고 새 모양을 만들지 않았다. `건너뜀 보기` summary도 같은 클래스
