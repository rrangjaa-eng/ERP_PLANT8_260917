## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 설명문을 더하지 않았다. 링크 글자 「인쇄」 한 단어뿐(expense-document.tsx와 같음).
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 결정 추가 없음. 링크는 view.instanceId 있을 때만 서고 새 탭 인쇄 라우트로 바로 간다.

- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 1차는 폼의 다시 제출 그대로. 인쇄는 2차(secondary 버튼 모양).
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 위험 동작(종결)은 기존 그대로, 인쇄 링크를 그 앞에 둠.

- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 빈 화면 아님(해당 없음).
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 링크는 Tab 이동 가능한 a 요소.
