## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: 종이에는 설명문이 없다(라벨 일곱 · 값 · 결재란뿐, 잔고 값은 연차 상세 화면 잔고 행과 같은 함수의 글자). 새 화면 글자는 오류 경계 「인쇄물 만들기 실패 ·」와 준비 전 한 줄이고 지출결의서 · 확인증과 같은 공용 컴포넌트다. 입구 「인쇄」는 라벨 한 낱말이다
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 열면 자동으로 인쇄 창이 뜨고(07.4-01 갈래 A) 소속 · 상신일 · 잔고 · 결재란은 모두 서버가 정한다. 사용자가 고를 것은 프린터뿐이다
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 결재 인스턴스가 없으면 「인쇄」 링크를 만들지 않고(`view?.instanceId`), 폰(<700)에서는 PcOnly가 CSS로 숨긴다. 승인 · 반려 · 회수 · 재택 문서의 잔고 값은 「—」로 비운다(칸을 숨기지 않고 행 수 7을 고정)
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 인쇄 라우트 화면 바의 1차는 「인쇄 · PDF 저장」 하나(07.4-01 PrintBar 그대로). 연차 상세의 1차 버튼 수는 바뀌지 않고 「인쇄」는 머리 줄 2차다
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 위험 동작 추가 0
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 기안자 행을 두지 않고 결재란 첫 칸 「기안」이 같은 정보를 맡는다. 상신일은 제목 곁말에만, 기안 칸 일시는 같은 지금 차수 값이다. 상태 글자는 번호 줄에만 있다
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 404는 지출결의서 · 확인증과 같은 「페이지 찾을 수 없음」 + 「첫 화면으로」 버튼(공용 PrintNotFound). 그 밖 빈 화면 추가 0
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 화면 바는 버튼 둘(닫기 → 인쇄 · PDF 저장)이고 종이는 읽기 전용이다. 입구는 링크 하나(Tab 한 번 · Enter)
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 입구 「인쇄」는 이동 링크이고 지출결의 상세와 같은 2차 버튼 클래스(btn secondary)를 그대로 쓴다
