- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 열 · 거르개 · 검색 칸 집합은 서버가 「보이는 활성 칸」으로 정한다(사용자가 열을 고르지 않음), 열 3 · 거르개 2 상한은 상수(UI-SPEC A8)
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 안 보이는 · 보관 칸은 열 · 거르개에서 서버가 빼고, 거르개 옵션은 활성 선택지만, 칸 0개면 거르개 DOM 0
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 「거래처 등록」 1차 그대로, 거르개는 제출 버튼 없이 select 변경 즉시 이동
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 행 동작 열(수정 · 숨김 · 삭제) 무변경, 이 플랜은 위험 동작을 더하지 않음
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 거르개 라벨 = 칸 이름, 첫 옵션은 「전체 {칸 이름}」이라 select 안 글자와 라벨이 겹치지만 값 빈 옵션의 이름이 곧 「전체」 뜻이다(프로젝트 목록 필터와 같은 꼴)
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 거래처 0건 · 필터 결과 0건 EMPTY는 기존 그대로(필터 지우기 링크가 거른 추가 칸 거르개 판정에 들어감)

- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 갈래는 기존 링크 묶음, 추가 칸 거르개는 같은 필터 줄 select(프로젝트 목록 필터 select와 같은 부품 `Select`)
