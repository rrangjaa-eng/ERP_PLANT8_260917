## 원칙
- [x] 안내 문구: 화면의 모든 설명문을 셌다. 남긴 것은 오류·되돌릴 수 없는 일·잠김뿐이고 명사형 한 줄이다 — 근거: S2는 칸 라벨(관리자가 정한 칸 이름) · 칸 오류 한 줄(서버 문구 그대로) · 기존 이유 자리 「등록 실패 · {첫 칸 이름} N칸」만 더했다(이유 자리 칸 이름에 추가 칸 라벨도 쓴다 — 새 문장 0). S3 읽기 행은 라벨 + 값 · 값 없음 「—」 · 보관 선택지 `{값} (보관됨)` 상태 글자 하나. 설명문 · placeholder · 구획 제목 추가 0(구분선 묶음은 머리 글자 없음)
- [x] 결정 최소: 알 수 있는 값은 기본값으로 채웠고, 시스템이 계산할 것을 묻지 않는다 — 근거: 칸 집합 · 순서는 서버(`listProjectFieldDefinitions` = 이 사람의 입력 칸 · 정렬 순서)가 정하고, 고치기 칸은 저장값으로 채워 열린다. 안 고친 칸은 보내지 않아 저장값이 남는다(빈 필수 칸을 안 건드리면 통과 — D-7507). 복사 등록은 추가 칸 값을 옮기지 않아 고를 일이 없다
- [x] 할 수 없는 선택지는 숨기거나 비활성화했다 — 근거: 안 보이는 칸 · 보관 칸은 서버가 정의 · 값 모두에서 빼 DOM 0(E2E 시드 계급 · 통합 「응답에 X · Z 값 없음」), `project.value`가 꺼진 계급은 칸 0 · 응답 키 0, `projects.info` 쓰기 없는 사람은 고치기 입력 0(E2E 읽기 계급). 보관 선택지는 저장값일 때만 목록 끝 활성 옵션(FormData 예외 — SYSTEM §7-15 · DECISIONS 07.5)
- [x] 주 버튼 하나: 이 화면의 다음 행동이 주 버튼 하나로 보인다 — 근거: 1차 버튼 수 실측 4폭 모두 1(`measurements-state-form*.json` `primaryButtons`), 정보 면은 기존 「일괄 저장 N Ctrl+S」 하나에 추가 칸 dirty가 N으로 합쳐질 뿐 새 버튼 0(`saveButtons` 실측 「일괄 저장 2」)
- [x] 위험한 동작(삭제 등)은 떨어뜨려 두고 위험 색이다 — 근거: 이 플랜은 위험 동작을 더하지 않는다. 등록 패널 닫기의 「입력 버리기」 확인은 추가 칸만 채워도 기존 DR1 창이 그대로 뜬다(E2E 「프로젝트 등록 · 1칸」)
- [x] 같은 말을 두 번 하지 않는다(라벨과 칸 안 글자, 태그와 줄 등) — 근거: 칸 안 글자(placeholder) 0, 라벨은 칸 이름 한 번, 오류는 칸 아래 한 줄 + 이유 자리 요약(기존 기본 칸과 같은 이중 구조)
- [x] 빈 화면은 설명보다 첫 행동 버튼이 먼저다 — 근거: 칸 0개면 구분선 묶음 · 읽기 행 · 고치기 폼 DOM 0(`CustomFieldGroup` · `CustomInfoRows` · `CustomInfoFields`가 그리지 않음 — E2E 시드 계급 판정), 빈 화면을 새로 만들지 않음
- [x] 키보드만으로 끝난다(표는 엑셀 키 구성) — 근거: 등록 패널은 Tab 순서 = 기본 칸 → 추가 칸(정렬 순서) → 행동 줄, 오류 시 첫 오류 칸 포커스(추가 칸 포함 — 실측 `focused: cf_…`). 정보 면 고치기는 형제 칸과 같은 키: Enter 제출 막기 · Esc 두 단계(저장 중 무시) · Ctrl+S 저장(E2E 2). 고친 추가 칸은 형제 칸과 같은 dirty 보관(새로 고침 → 복원 줄 → 같은 값 · 일괄 저장 1)이고 저장 요청 중 값을 보인 채 readOnly(select는 바꾸기 무동작 — PO 통화 칸과 같다) — 시각 변경 0(E2E 「새로 고침 뒤 복원 · 저장 요청 중 readOnly」)
- [x] 같은 종류의 행동은 같은 모양이다(링크·버튼 섞지 않음) — 근거: 추가 칸은 공용 `CustomFieldInput`(TextField · Select · 네이티브 date/number) 하나로 거래처 폼 · 등록 패널 · 정보 면이 같은 부품, 고친 칸 표시는 형제 칸과 같은 `.periodInputDirty`(box-shadow 계산값이 행사명과 같음 — 실측 `rgb(14, 122, 102) 0px 0px 0px 1px inset` 4폭)
