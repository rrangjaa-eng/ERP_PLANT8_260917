## 패스 메모

### 패스 1 — 정보 구조: 「신호는 한 자리」

같은 사실을 두 자리에 쓰지 않는다(§8-5). 경품 표 = **가액 · 당첨 수를 고치는 자리**라 고친 값의 결과(확인증 없음 · 파기 대상 · 미제출)가 같은 줄에 선다. 제출 섹션 = **사람을 맞추는 자리**라 초과 · 같은 연락처 · 같은 이름 · 제외가 선다.

```

│ 행사 이름 [닫힘]                                                      │ ① 무엇 · 상태(태그)
│ 당첨일 · 담당 · 마감    닫힘 · 10-15 18:00 · 박서연이 닫음              │
╞═ 경품(편집 표) ═══════════════════════════════════════════════════╡ ② 고칠 것
│    경품명          1개 가액  전달  당첨 수  제출                        │
```

- 신청됨(경영관리): 머리 → 경품 편집 표 → 1차 `QR 생성`. QR · 제출 섹션 없음 — 지금 계약 그대로 좋다.
- 기획본부 I′3(N7 a): 머리 · QR · 경품 읽기 표(경품명 · 전달 · **당첨 수** · 제출). 가액 · 미제출 · 제출 섹션 없음.
- I4(경영관리): 머리(제목 · 태그 · 2차) → 고칠 칸 → 읽기 전용 → 행동 줄. 「대조 제외」는 여기(DR-1).
- E′2: 제목 · 부제(행사 이름이 유일한 닻) → `받은 경품을 골라 주세요` → 행. 할 일이 3순위지만 행 버튼이 행동을 이끈다 — 괜찮다(독립 §1).
- 섹션 순서(QR → 경품 → 제출)는 상태와 상관없이 고정으로 둔다 — 닫힘에서 제출 섹션을 위로 올리자는 독립 M4는 비채택(교차 대조 표).
