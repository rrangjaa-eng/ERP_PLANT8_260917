## 불변식 (이 리뷰의 잣대)

1. 배포는 사람 손이 가지 않는다 — 스테이징은 main 병합으로, 프로덕션은 버튼 하나로(D-05). 실패는 워크플로 빨강으로 보인다.
2. 시크릿·프로젝트 ID·실제 이메일은 리포·문서·이미지에 없다(D-03).
3. 로그인 실패는 계정 단위(잠금)와 IP 단위(429) 둘 다에서 막히고, 어느 쪽도 다른 사람의 로그인을 막지 않는다(AUTH-01, D-09).
4. 세션은 30일 sliding이며 브라우저를 닫아도 유지된다(D-07) — DB만이 아니라 쿠키까지.
5. 스모크에 실패한 리비전은 트래픽을 받지 않고, 롤백은 실제로 이전 리비전으로 간다(20A).
6. 두 환경 합계 월 $30 안팎이고 GitHub Actions 무료 분(2,000/월)을 넘기지 않는다(D-06, OPS-02).
