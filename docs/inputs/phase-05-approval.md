## 1. 결재선 — 기본 4단의 실제 모습

| 단계 | 담당 (계급 × 조직 범위) | 지금 자리가 차나 |
|---|---|---|
| 1 | 기안자 **팀**의 팀장 | **참** |
| 2 | 기안자 **본부**의 책임자 | **빔 — 건너뜀** |
| 3 | **경영관리본부** 담당 | **참** |
| 4 | **대표** | **참** |

출처: 문답 (자리가 차는 단계 = 팀장·경영관리·대표).

**실제로 도는 모습**

| 기안자 | 실제 단계 | 왜 |
|---|---|---|
| 기획1팀·기획2팀 직원 | 팀장 → 경영관리 → 대표 (3단) | 기획본부 책임자 자리가 비어 있음 |
| 기획1팀·기획2팀 팀장 | (자기 차례 — 아래 3 참조) → 경영관리 → 대표 | |
| 경영관리본부 직원 | 경영관리 → 대표 (2단) | 경영관리본부에 팀이 없어 1단도 빔 |
| 대표 | 경영관리 → (자기 차례) | |

**나중에 기획본부 책임자를 임명하면** 설정을 고칠 필요 없이 2단이 저절로 살아난다 — 결재선이 사람이 아니라 계급 × 조직 범위로 정의되기 때문이다(EXP-03, Eng OV-2).

## 2. 빈 자리 규칙

| 항목 | 값 | 출처 |
|---|---|---|
| 빈 자리 | 건너뛴다 | 확정 (EXP-03) |
| **아무도 안 남으면** | **대표가 받는다** | 문답 |

결재 없이 통과하는 지출 문서가 생기지 않는다. 돈은 반드시 한 사람 이상의 승인을 거친다.

## 3. 자기 승인 (기안자 = 단계 담당)

| 문서 | 처리 | 출처 |
|---|---|---|
| 지출결의 | **본인이 직접 누른다.** '본인 승인' 딱지가 남는다 | 문답 |
| 연차 | **건너뛴다** | 문답 |
| 정산 결재 | 지출결의와 같게 (경영관리 기안 → 대표 승인이라 겹칠 일 없음) | 파생 |

**요구사항과의 관계**: EXP-03은 "기안자가 단계 담당 본인이면 그 단계를 건너뛴다(**설정**)"이다. 위 결정은 그 설정의 **기본값을 문서 종류별로 다르게 둔다**는 뜻이므로 요구사항과 충돌하지 않는다. 설정 키를 문서 종류별로 쪼개야 한다는 것만 Phase 5 계획에서 반영한다.

## 5. 연차

| 종류 | 차감 | 출처 |
|---|---|---|
| 종일 | 1일 | 확정 (LEAV-01) |
| 반차 | 0.5일 | 확정 (LEAV-01) |
| 반반차 | 0.25일 | 확정 (LEAV-01) |
| 재택 | **차감 없음 · 기록만 · 횟수 제한 없음** | 문답 |

| 항목 | 값 | 출처 |
|---|---|---|
| 부여 기준 | **회계연도 (1월 시작)** | 문답 |
| 이월 | **없음** | 문답 |
| 일수 설정 | 관리자가 연 1회 설정 | 확정 (LEAV-01) |
| 잔여 초과 신청 | **막지 않고 경고만.** 신청 창·결재 옆판에 남은/결재중/이번신청 일수를 보여 결재자가 판단 | 문답 |
| 결재 경로 | 같은 결재 모듈 (`domain/approvals`) | 확정 (LEAV-01, ROADMAP Phase 5 기준 6) |

**미정 — 입사 첫해 처리**: 회계연도 기준을 택하면 그해 중간 입사자의 첫해 일수를 어떻게 줄지가 남는다(비례 부여 여부, 월차 유무). 260907은 근로기준법 검토 끝에 "입사한 해 월차 최대 11일, 입사 다음 회계연도 말 소멸"로 정했으나 현 요구사항에는 없다. **사용자가 Phase 5 계획 때 확정한다.** 퇴직 정산도 같은 자리에서 판정한다.

## 6. 지출결의

| 항목 | 값 | 출처 |
|---|---|---|
| 기본 단위 | 견적 줄 1개 = 문서 1개 | 확정 (EXP-01) |
| 분할 지급 | **회차별 문서를 둔다. 회차 합계는 실행가를 넘을 수 없다** | 문답 |
| 중복 방지 | 같은 줄에서 두 번 눌러도 문서가 겹치지 않음 (idempotency key) | 확정 (EXP-01) |
| 금액 | 0보다 커야 하고 음수 불가 | 확정 (EXP-14) |
| 입력 단위 | **공급가액만** 사람이 적는다 | 확정 (EXP-15, PNL-09) |
| 번호 부여 | **제출 시** (`26001-0001`) | 확정 (ADMN-09) + phase-04 §5 |
| 한 화면 완결 | 작성 · 증빙 첨부 · 제출까지 화면 하나 | 확정 (EXP-02) |
